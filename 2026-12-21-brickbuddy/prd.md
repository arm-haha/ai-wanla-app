# PRD — BrickBuddy (ถ่ายกองตัวต่อ รู้เลยต่ออะไรได้)

## ปัญหา
บ้านที่มีเด็กแทบทุกบ้านมี "ลังตัวต่อรวมมิตร" ที่ชุดเดิมกระจายหมดแล้ว คู่มือหาย ชิ้นปนกันหลายยี่ห้อ ลูกเทออกมาแล้วนั่งงงว่า "จะต่ออะไรดี" สุดท้ายต่อแค่กำแพงสี่เหลี่ยมแล้วเลิกเล่น พ่อแม่ก็คิดไอเดียไม่ทัน ช่วงปิดเทอมปีใหม่ลูกอยู่บ้านทั้งวัน อยากให้เล่นของที่มีอยู่แล้วแทนจอมือถือ ไม่อยากซื้อชุดใหม่ราคาหลักพัน และตอนเก็บก็ไม่รู้จะแยกกล่องยังไงให้หาง่ายครั้งหน้า

## ผู้ใช้
พ่อแม่ลูกเล็ก 4–12 ขวบ (คนถ่ายรูปคือผู้ปกครอง), เด็กโตที่ชอบสร้างของเอง, ครูอนุบาล/ประถมที่มีลังตัวต่อในห้อง, ผู้ใหญ่สายต่อของแต่งโต๊ะ (ที่วางมือถือ กล่องดินสอ), คนที่ได้ลังตัวต่อมือสองมาแบบไม่มีคู่มือ

## Must-have (core demo / Reel)
1. **Pile Scan → Build Ideas** ⭐ wow moment — เทกองบนพื้นเรียบ ถ่าย 1 รูป → คะแนนรูป 0–100 + ทิป (เกลี่ยชั้นเดียว แยกชิ้นที่ติดกัน) (`scan_quality`) → AI ตรวจชิ้น (`AiPileScan`) → การ์ด "ต่อได้ทันที" 6 แบบเรียงตาม ต่อได้เลย > % ครบ > ใช้ชิ้นทดแทนน้อย > เร็วกว่า, กรองตามอายุและเวลาที่มี (`suggest_builds`, `match_build`)
2. **Inventory Count** — นับรวม แยกตามรูปทรง 14 ชนิด × 12 สี จำนวนปุ่ม (studs) สีเด่น 3 สี ชิ้นที่ AI ไม่มั่นใจไม่นับ แตะแก้ได้ (`inventory`)
3. **Smart Substitution + Your-Colour Steps** — ขาดชิ้นไหนหาชิ้นทดแทนให้อัตโนมัติ (2×4 = 2×2 สองชิ้น, 1×4 = 1×2 สองชิ้น ฯลฯ) โดยใช้ชิ้นตรงรุ่นก่อนเสมอ; เลือกสีหลัก/สีเน้น/สีฐานจากสีที่มีมากที่สุดในกอง (`assign_colors`); คู่มือทีละชั้น ฐาน → อิฐ (ไม่เกิน 4 ชิ้นต่อขั้น) → หลังคา → ชิ้นพิเศษ → รายละเอียด พร้อมทิปภาษาเด็ก (`build_steps`)
4. **Find-It Highlight** — ขั้นนี้ต้องใช้ "อิฐแดง 2×4" → ไฮไลต์วงกลมเรืองแสงบนรูปกองที่ช่อง A1 และ D3 ไม่ต้องคุ้ยหาทั้งลัง (`find_piece`, `grid_cell`)
5. **Age & Safety Guard** — อายุ < 3 = หยุด (ชิ้นเล็กเสี่ยงติดคอ), < 13 ผู้ปกครองเปิดกล้อง, AI เจอถ่านกระดุม/แม่เหล็กในกอง = หยุด, เจอเหรียญ = เตือน, หน้าคนในรูป = เบลอ, ไม่คัดลอกคู่มือชุดลิขสิทธิ์ (`age_check`, `safety_guard`)

## Nice-to-have (retention / viral)
6. **Daily Build Challenge** — ชาเลนจ์หมุนวันละธีม (สัตว์ 4 ขา, ยานพาหนะ, ตึกสูงไม่ล้ม, ใช้แค่ 2 สี, ของจิ๋ว ≤ 10 ชิ้น, หน้าคนในบ้าน) จำกัดชิ้นและเวลา ช่วง 20 ธ.ค.–3 ม.ค. เป็น "ของขวัญปีใหม่" (`daily_challenge`)
7. **Creation Score** — ถ่ายผลงานเสร็จ → ดาว 1–5 จากจำนวนชิ้น สี ความสมมาตร ความสูง และตรงธีม แบดจ์ rainbow / symmetry_star / sky_high / challenge_done ข้อความชมเสมอ ไม่มีคำติ (`creation_score`)
8. **Sort Helper + Stability Check** — แบ่งเก็บลง N กล่องตามสีหรือขนาดให้จำนวนใกล้กัน (`sort_plan`); เช็กตึก/หอคอยว่า "แข็งแรง / โยก / ล้มแน่" จากความสูง ขนาดฐาน และการวางเหลื่อม (`stability`)
9. **Build Diary** — แกลเลอรีผลงาน สตรีครายวัน ชิ้นที่ใช้รวม ดาวสูงสุด แบดจ์สะสม (`diary_summary`)
10. **Share Card / Reel + Quota** — การ์ดก่อน (กองรก) / หลัง (ผลงาน) 1080×1350, กริดขั้นตอน, แบดจ์ (`share_card`) + Reel 9:16 15–30 วิ 6 ช็อต (`reel_plan`); ฟรีสแกน 3 ครั้ง/วัน (`quota`)

## หน้าจอ / Flow
Home → Age gate (ใครเล่น + ผู้ปกครองยืนยัน) → กล้อง (ไกด์ "เกลี่ยเป็นชั้นเดียว") → Scan QA → **Inventory + ไอเดีย 6 การ์ด** (wow) → เลือกไอเดีย → Steps (Find-It ทุกขั้น) → ถ่ายผลงาน → ดาว + แบดจ์ → Diary → Share / Reel · เมนูรอง: Challenge วันนี้, แยกกล่อง, เช็กตึก

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**น้องภูมิ 7 ขวบ นนทบุรี** (คุณแม่ฝนถ่ายรูป) รูปกองคุณภาพ 90/100
- Inventory: 61 ชิ้น 12 ชนิด 183 ปุ่ม สีเด่น เหลือง/น้ำเงิน/แดง (หน้าต่างใส 1 ชิ้นและอิฐเขียว 1×1 AI ไม่มั่นใจ → ไม่นับ)
- ต่อได้ทันที 11 จาก 14 ไอเดีย; การ์ดบนสุด: เป็ดน้อย · ตุ๊กตาหิมะ · รถแข่งจิ๋ว · เรือใบ · หุ่นยนต์ · จรวด
- ไดโนเสาร์: ต่อได้ โดยใช้ 1×2 สองชิ้นแทน 1×4 (×2) · บ้าน: ขาดหน้าต่าง 1 ชิ้น (94%) · ป้าย 2027: 87% ขาด 1×2 ×2, 1×1 ×2
- เป็ดน้อย 5 ขั้น สีหลักเหลือง สีเน้นแดง ตาสีเดิม; Find-It "อิฐแดง 2×4" → ช่อง A1, D3
- ผลงานเป็ด 7 ชิ้น 3 สี สมมาตร 0.9 → 4 ดาว แบดจ์ symmetry_star + challenge_done · สตรีค 3 วัน

## Design tokens
พื้นครีมอุ่น #FFF8EC, แดงตัวต่อ #D0312D, เหลือง #F6C21C, น้ำเงิน #1E5AA8, เขียว #2E8B3E, กราฟิตเข้ม #1B1B1B, เรืองแสงไฮไลต์ #7CF7FF; ฟอนต์ Kanit; การ์ดมุมมน 24 มีปุ่มวงกลมนูนแบบตัวต่อที่หัวการ์ด; แอนิเมชันสแกน = จุดสีวิ่งนับชิ้น, ตัวเลขนับขึ้น; Find-It = วงแหวนเรืองแสงเต้นเป็นจังหวะ

## Reel shot list (20 วิ · เห็นแค่มือเด็ก/ผู้ปกครอง ไม่ต้องเห็นหน้า)
- **0–3 วิ:** เทลังตัวต่อลงพื้นเสียงดังกราว ข้อความ "กองนี้ ต่ออะไรได้บ้าง?"
- **3–6 วิ:** ตัดต่อเร่งตอนสร้างแอปด้วย AI จากแพ็กนี้ (โชว์ prompts.md)
- **6–9 วิ:** ถ่ายรูป จุดสีวิ่งนับ "61 ชิ้น ✓" การ์ดไอเดีย 6 ใบเด้งขึ้น (beat drop)
- **9–15 วิ:** แตะ "เป็ดน้อย" → ขั้นที่ 1 → วงแหวนเรืองแสงชี้ชิ้นในกอง → มือหยิบ ต่อสปีด x4
- **15–18 วิ:** เป็ดเสร็จหมุนโชว์ ★★★★ "สุดยอดนักสร้าง!"
- **18–20 วิ:** CTA "คอมเมนต์ BRICK รับแพ็กฟรี"
- ตัวอักษรเล็กท้ายคลิป: "ชิ้นเล็กไม่เหมาะกับเด็กต่ำกว่า 3 ปี · ไม่เกี่ยวข้องกับแบรนด์ใด"

## Build plan (ประมาณ 1 วันด้วย AI codegen)
1. **ชม. 0–1:** P0 scaffold PWA + tokens + port `brickbuddy.py` เป็น TS ให้ `tests.py` ผ่านทุกข้อ (36 tests)
2. **ชม. 1–2:** P1–P2 Age gate + กล้อง + Scan QA
3. **ชม. 2–4:** P3–P4 A1 vision → Inventory (แตะแก้จำนวน) → Build match + substitutions + การ์ดไอเดีย
4. **ชม. 4–5:** P5–P6 Colour roles + Steps + ภาพประกอบ isometric ต่อขั้น (SVG จากกริดปุ่ม) + Find-It overlay
5. **ชม. 5–6:** P7–P9 Challenge, Creation score, Sort helper, Stability
6. **ชม. 6–7:** P10–P12 Diary, Share/Reel, Quota/Guard, QA บนมือถือจริง + ถ่าย Reel ตาม shot list

## Risks & traps
| ความเสี่ยง / กับดัก | ผลกระทบ | วิธีลด |
|---|---|---|
| AI นับชิ้นผิด/สีเพี้ยน (ชิ้นทับกัน, แสงเหลือง) | ไอเดียต่อไม่ครบจริง เด็กผิดหวัง | scan_quality บังคับเกลี่ยชั้นเดียว, ตัดชิ้น confidence < 0.5, หน้า Inventory แตะ +/− แก้ได้, เผื่อชิ้นทดแทน |
| **กับดัก:** ให้ AI "วาดภาพผลงาน" แบบ image gen | ภาพสวยแต่ต่อจริงไม่ได้ ชิ้นไม่ตรงกับที่มี → ดราม่า | ภาพขั้นตอนเรนเดอร์จากกริดปุ่มจริง (deterministic) ไม่ใช้ image gen; AI ทำแค่ตรวจชิ้น + ตั้งชื่อ/เล่าเรื่อง |
| ลิขสิทธิ์/เครื่องหมายการค้า | โดนร้องเรียน | ไม่ใช้ชื่อแบรนด์ ไม่คัดลอกคู่มือชุด, guard `official_set_copy`, ไอเดียทั้งหมดเป็นแบบต้นฉบับ |
| เด็กเล็กกลืนชิ้นส่วน / ถ่านกระดุม / แม่เหล็ก | อันตรายถึงชีวิต | age gate < 3 = stop, A1 ตรวจ hazards → stop, ข้อความ 1669 เมื่อกลืน, คำเตือนท้าย Reel |
| ภาพในบ้านติดหน้าเด็ก/ข้อมูลส่วนตัว | ความเป็นส่วนตัว | เบลอหน้าก่อนส่ง, ลบรูปกองหลังวิเคราะห์ ≤ 1 ชม., เก็บแค่ inventory JSON |
| ไอเดียซ้ำจนเบื่อ | retention ต่ำ | ชาเลนจ์รายวัน, เพิ่มแคตตาล็อกตามฤดู (ปีใหม่ สงกรานต์ วันเด็ก), แบดจ์สะสม |

## Guardrails
- ตัวต่อชิ้นเล็กไม่เหมาะกับเด็กต่ำกว่า 3 ปี; ผู้ปกครองดูแลขณะเล่นเสมอ
- เจอถ่านกระดุม/แม่เหล็กในกอง → หยุดและให้เก็บออกก่อน; กลืนชิ้นส่วน → โทร 1669
- ไม่ใช้ชื่อแบรนด์ ไม่คัดลอกคู่มือชุดลิขสิทธิ์
- คะแนนผลงานเป็นคำชมเท่านั้น ไม่มีการเปรียบเทียบเด็กกับเด็ก ไม่มีลีดเดอร์บอร์ดสาธารณะ
- ทุกตัวอย่างในแพ็กเป็นบุคคลสมมติ

## Metrics
- % การสแกนที่ได้ไอเดีย "ต่อได้ทันที" ≥ 3 แบบ (เป้า 80%)
- เวลาจากเปิดแอปถึงเริ่มขั้นที่ 1 (เป้า < 60 วินาที)
- % ไอเดียที่ทำจนจบทุกขั้น (เป้า 55%)
- D7 retention จากชาเลนจ์รายวัน (เป้า 30%)
- จำนวน share card / Reel ที่ติดลายน้ำ BrickBuddy
