# PRD — SnapLingo (ถ่ายของรอบบ้าน ได้คำศัพท์อังกฤษ/จีนให้ลูก)

## ปัญหา
อยากให้ลูกเรียนคำศัพท์จากของจริงรอบบ้าน แต่เปิดแอปท่องจำแล้วเด็กไม่สนใจ และผู้ปกครองไม่รู้จะออกเสียงอังกฤษหรือจีนยังไง แถมหลายแอปขอถ่ายหน้าเด็กซึ่งผู้ปกครองไม่สบายใจ

## ผู้ใช้
ผู้ปกครองของเด็กอายุประมาณ 4–10 ปี, คนที่อยากสอนคำศัพท์จากของในครัว/ห้องนอน, คนที่อยากมีกิจวัตรสั้น ๆ ก่อนนอนโดยไม่ต้องมีใบหน้าเด็กในรูป

## Must-have (core demo / Reel)
1. **Object labels** ⭐ wow moment — ถ่ายของ → ป้ายไทย + อังกฤษ + จีน ทันที (เช่น กาต้มน้ำ · kettle · 水壶)
2. **Pronunciation** — IPA/พินอิน และคำอ่านภาษาไทย (เคท-เทิล, สุ่ย-หู)
3. **Flashcards** — ส่องหน้าเป็นไทย กลับหลังเป็นอังกฤษหรือจีน
4. **Mini quiz** — ทาย 3 ตัวเลือก ต่อคำที่เพิ่งเจอ
5. **Streak / sticker rewards** — ต่อเนื่องถ้ารอบนั้นถูกอย่างน้อย 50% ได้สติกเกอร์ที่วัน 3 / 7 / 14 / 30

## Nice-to-have (retention)
6. **16-word house library** — ครัว ห้อง ของใช้ประจำวัน
7. **Parent mode** — ผู้ปกครองเป็นคนถ่ายและเปิดควิซ เด็กไม่ต้องมีบัญชี
8. **EN/ZH switch** — สลับภาษาบนแฟลชการ์ดและควิซ
9. **Share Card + Quota** — การ์ดผลมีลายน้ำ ฟรี 3 ครั้ง/วัน
10. **Safety Guard** — แนะนำให้ถ่ายเฉพาะของ ถ้ามีใบหน้าเด็กต้องมีผู้ปกครองยินยอม

## หน้าจอ / Flow
Home (ถ่ายของ + สตรีคล่าสุด) → Snap (กรอบของบนโต๊ะ) → **ป้าย 3 ภาษา** → แฟลชการ์ด → ควิซสั้น → สติกเกอร์ต่อเนื่อง → การ์ดแชร์

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**พี่แอน 34 ปี** ผู้ปกครองของ **น้องเต้า 7 ปี** กรุงเทพฯ. ถ่ายของในครัวคุณภาพ **89** เจอ **กาต้มน้ำ แก้ว ช้อน** → ป้าย kettle / 水壶 shuǐhú อ่านว่า สุ่ย-หู → ควิซภาษาอังกฤษตอบถูก **2/3 (67%)** → ต่อเนื่องจาก 3 เป็น **4 วัน** (ได้ดาวไปแล้วตอนครบ 3)

## Design tokens
พื้นเหลืองอ่อน #FEF9C3, ฟ้าคำศัพท์ #0284C7, เขียวถูก #16A34A, แดงผิด #DC2626, กรม #1F2937; ฟอนต์ Kanit; มุมมน 20; ป้าย 3 ภาษาใหญ่ตัดกลางจอ ถ่ายขึ้น Reels ชัด (รูปของ → ป้ายเด้ง)

## Guardrails
- **ไม่ใช่หลักสูตรโรงเรียน** — คำและเสียงเป็นตัวอย่าง แอปไม่ตรวจการพูดจริง
- ถ่ายเฉพาะตัวของ ไม่บังคับใบหน้าเด็ก ถ้ามีใบหน้าเด็กต้องมีผู้ปกครองยินยอม
- ความมั่นใจ < 0.6 ไม่นับคำ ต้องถ่ายใหม่หรือเลือกเอง
- ตัวอย่างและภาพปกเป็นเด็ก/ผู้ปกครองสมมติและของวาด ไม่ใช้เด็กจริง

## Shot list Reel (30 วิ · ใช้ของจำลอง/ภาพประกอบเท่านั้น ห้ามใบหน้าเด็ก ห้ามบ้านจริงที่ระบุได้)
- **0–3 วิ:** เด็กชี้กาต้มน้ำ (วาด ไม่ใช่เด็กจริง) ขึ้นข้อความ "ของในบ้าน สอนคำศัพท์ได้ไหม?"
- **3–10 วิ:** ตัดต่อเร่งตอนใช้ AI สร้างแอปจากแพ็กนี้
- **10–22 วิ:**
  1. ถ่ายกาต้มน้ำ ป้าย kettle + 水壶 เด้งขึ้น
  2. เปิดวิธีอ่าน "เคท-เทิล" / "สุ่ย-หู"
  3. พลิกแฟลชการ์ด แก้ว → cup
  4. ควิซตอบถูก 2/3
  5. สติกเกอร์ต่อเนื่อง 4 วัน
- **22–30 วิ:** "คอมเมนต์ LINGO รับแพ็กฟรี"
- ปิดท้ายมีข้อความเล็ก "ถ่ายเฉพาะของ ไม่ใช่หลักสูตรโรงเรียน"
