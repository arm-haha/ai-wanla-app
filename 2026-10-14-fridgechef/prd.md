# PRD — FridgeChef (ตู้เย็นเชฟ)

**ช่อง:** AI วันละแอป · **วันที่:** 2026-10-14 · **สถานะ:** พร้อม gen วันนี้
**ฮุค Reel:** เปิดตู้เย็นถ่ายรูปเดียว… AI บอกเลยว่าคืนนี้ทำเมนูไหนได้ ไม่ต้องออกไปซื้อเพิ่ม 🍳

---

## 1) ปัญหา
- คำถามที่คนไทยถามทุกวัน: **"กินอะไรดี?"** + ตู้เย็นมีของแต่คิดเมนูไม่ออก
- ของสด (หมูสับ ผักใบ ข้าวเหลือ) เสียทิ้งเพราะลืม → เสียเงินแบบไม่รู้ตัว
- แอปสูตรอาหารทั่วไปเริ่มจาก "เมนู" แล้วให้ไปซื้อของ — ไม่ได้เริ่มจาก "ของที่มี"

## 2) ทำไมไวรัล
- ทุกคนมีตู้เย็น → ดูแล้วอินทันที ไม่ต้องอธิบาย
- Before/after ชัด: ตู้เย็นรก → 3 เมนู → จานจริงหน้ากล้อง
- ตัวเลขเงินที่ช่วยได้ (฿60 วันนี้ / ฿225 ทั้งเดือน) = แชร์ได้ โชว์ได้
- คอนเทนต์ต่อยอดได้ไม่จบ: "ตู้เย็นหอพัก", "ตู้เย็นแม่", "ตู้เย็นคนโสด" (ให้คนส่งรูปตู้เย็นมาท้า)

## 3) เป้าหมาย / ตัวชี้วัด
| เป้า | วัดจาก |
|---|---|
| เข้าใจใน 15 วิ | ผู้ชม Reel เห็น สแกน → เมนู ภายใน 11 วิแรก |
| ลองแล้วได้ผลทันที | demo fixture กดครั้งเดียวได้ 3 เมนูตรง `expect_locked` |
| กลับมาเปิดซ้ำ | Radar + Wrapped + ลิสต์ซื้อของ → เปิด ≥3 วัน/สัปดาห์ |
| แชร์ | การ์ด rescue / wrapped ส่งออก PNG 1080×1920 |

## 4) Persona
- **ปุ๊ก (สมมติ) 21 ปี** นักศึกษาอยู่หอ ตู้เย็นเล็ก เตาไฟฟ้า 1 หัว + ไมโครเวฟ งบกินวันละ ~150
- รอง: คนทำงานกลับบ้านค่ำ, แม่บ้านอยากใช้ของให้หมดก่อนจ่ายตลาด

## 5) ฟีเจอร์
### Must-have (คอร์เดโม — 5 ข้อ)
1. **Fridge Snap → Ingredient Chips** (⭐ wow moment): ถ่าย/อัปรูปตู้เย็น → กรอบสแกนวิ่งบนรูป → chips ของที่เจอเด้งเข้าถาด แก้/ลบ/เพิ่มได้ ความมั่นใจ < 0.60 แสดงเป็น "มะนาว ใช่ไหม?" และยังไม่นับจนกดยืนยัน
2. **Menu Match 3 เมนู**: จัดอันดับเมนูไทยจากของที่มี + เครื่องปรุงพื้นฐาน (staples) แสดง % ตรง, badge "ทำได้เลย ✅ / ขาดอีก 1 อย่าง", pill "ช่วยของใกล้เสีย ฿X" ฟิลเตอร์ ไม่เผ็ด / ไม่กินหมู / มังสวิรัติ / ≤ X นาที
3. **Cook Mode**: การ์ดขั้นตอนตัวใหญ่ จับเวลาในตัวทุกขั้นที่ต้องรอ แตะจอใหญ่เพื่อไปต่อ (มือเปื้อนก็กดได้) จอไม่ดับ (Wake Lock)
4. **Use-First Radar**: วงแหวนสีของแต่ละชิ้น แดง=ใช้วันนี้ เหลือง=ใช้เร็ว เขียว=สบาย เทา=เช็กก่อนกิน เมนูที่ใช้ของแดงได้คะแนนบวก
5. **ลิสต์ซื้อของ (Missing → List)**: เลือกเมนูที่อยากทำพรุ่งนี้ → รวมของที่ขาด แยกร้าน (7-Eleven / ตลาด) พร้อมราคาประมาณ กดส่งเข้า LINE เป็นข้อความ

### Nice-to-have (รีเทนชัน)
6. **🎲 กินอะไรดี สุ่มเลย**: ลูกเต๋าสุ่มจากเมนู "ทำได้เลย" (seeded, แอนิเมชัน 6 เฟรม)
7. **Waste Wrapped รายเดือน**: ทำกินเองกี่มื้อ ช่วยของรอดกี่อย่าง ประหยัดกี่บาท เมนูประจำ สตรีค → การ์ดแชร์
8. **Pantry staples memory**: ตั้งค่าเครื่องปรุงที่มีเสมอ (น้ำปลา ซีอิ๊ว ซอสหอยฯ ฯลฯ)
9. **Share Card**: rescue / wrapped / "ตู้เย็นฉันทำได้ 3 เมนู"
10. **พิมพ์แทนถ่าย**: ไม่มีกล้อง/ไม่มี key AI ก็พิมพ์ "ไข่ หมูสับ กะเพรา" แล้วได้ chips เหมือนกัน

## 6) กติกาคอร์ (deterministic — mirror `reference/fridge.py`)
- `days_left = shelf_life_days − (today − added_on)`; status: ≤1 today · 2–3 soon · ≥4 ok · <0 check (ไม่ใช้ในเมนู)
- chips ใช้ได้ = confirmed (conf ≥ 0.60 หรือผู้ใช้ยืนยัน) และ status ≠ check
- `match_pct = round(100 × required_ที่มี / required_ทั้งหมด)`
- `rescue_bonus`: days_left ≤1 → +12, ≤3 → +6 (ต่อชิ้นที่ใช้)
- `score = match_pct + Σrescue_bonus + 2×optional_ที่มี − 25×required_ที่ขาด − round(0.5×time_min)`
- เรียง score มาก→น้อย, time_min น้อย→มาก, id; ค่าเริ่มต้น max_missing = 1, top 3
- rescues = ของที่ใช้และ days_left ≤ 2; rescue_value = Σ price ของชิ้นนั้น
- Dice: LCG `x = (1664525·x + 1013904223) mod 2^32` 6 รอบ เลือก `pool[x mod n]` เฟรมสุดท้ายคือผล
- Wrapped: รวม history ของเดือน, top recipe = นับมากสุด (เสมอ → id เรียงอักษร), streak = วันติดกันยาวสุด

## 7) ตัวเลขเดโมที่ล็อก (ตู้เย็นปุ๊ก 2026-10-14)
- detections 13 · confirmed 12 · "มะนาว ใช่ไหม?" (0.41)
- Radar ใช้วันนี้ 4 อย่าง: ข้าวสวย ใบกะเพรา หมูสับ ต้นหอม · at-risk 9 อย่าง ฿130
- Top 3: **กะเพราหมูสับไข่ดาว (138)** · ข้าวผัดไส้กรอก (137) · ข้าวต้มหมูสับ (134)
- เมนู 1 ช่วยของ 3 อย่าง ฿60 · Cook Mode 6 ขั้น จับเวลารวม 450 วิ
- ยืนยันมะนาว → เมนูใหม่ ยำไส้กรอกแซ่บ + ยำวุ้นเส้นหมูสับ (ขาด 1)
- ลิสต์ซื้อของ (กะเพราไก่ + กะหล่ำผัด + ยำไส้กรอก) = อกไก่ หอมใหญ่ กะหล่ำ รวม ~฿80
- Dice seed 20261014 → ไข่เจียวหมูสับฟู ๆ
- Wrapped ต.ค.: 9 มื้อ · ช่วยของ 12 อย่าง · ประหยัด ฿225 · เมนูประจำ ไข่เจียวหมูสับ · สตรีค 3 วัน

## 8) หน้าจอ
1. **Home**: หัว "วันนี้ตู้เย็นทำอะไรได้บ้าง?" ปุ่มใหญ่ 📸 ถ่ายตู้เย็น · ลองข้อมูลตัวอย่าง · การ์ด Radar ย่อ
2. **Scan**: รูปเต็มจอ + กรอบสแกนวิ่ง + bbox ไฮไลต์ → chips ลอยลงถาดล่าง
3. **Chips Review**: chips ตามหมวด แตะแก้จำนวน/วันซื้อ, "ใช่ไหม?" สีจาง, ปุ่ม + เพิ่มเอง
4. **Menu Match**: 3 การ์ดใหญ่ (emoji, ชื่อ, %, เวลา, badge, pill ช่วยของ) + แถบฟิลเตอร์ + "ดูทั้งหมด"
5. **Recipe Detail**: ของที่ใช้ (ติ๊กเขียว) / ที่ขาด (แดง + ปุ่มใส่ลิสต์) → ปุ่ม เริ่มทำเลย
6. **Cook Mode**: การ์ดขั้นละหน้า ตัวเลขนับถอยหลังใหญ่ วงแหวนเวลา เสียงเตือน → จบแล้วบันทึก + การ์ด rescue
7. **Radar**: grid วงแหวนสี 4 กลุ่ม
8. **Shopping List**: แยกร้าน ติ๊กได้ ปุ่มส่ง LINE / คัดลอก
9. **Dice**: ลูกเต๋า 3D-ish หมุน 6 เฟรม → การ์ดเมนู
10. **Wrapped + Settings**: การ์ดเดือน, staples, diet, เตา, เปิด/ปิด AI vision

## 9) UI
- พื้น `#F7FAFC` (ไอเย็นตู้เย็น) · ink `#0F172A` · ice `#38BDF8` · tomato `#EF4444` · basil `#22C55E` · yolk `#FBBF24`
- ฟอนต์ไทย: IBM Plex Sans Thai / Noto Sans Thai, ตัวเลขใหญ่หนา
- Chips โค้งมน emoji ซ้าย วงแหวนสี expiry รอบ emoji · แอนิเมชัน spring ตอน chips เด้ง
- การ์ดแชร์ 1080×1920 เหมาะกับ Story/Reel cover

## 10) เทค
- Next.js 14 App Router + TS + Tailwind + shadcn/ui + framer-motion · PWA · Vercel
- local-first: localStorage `fridgechef:v1` (schema `LocalStore`) ไม่ต้องล็อกอิน
- AI (optional) `/api/ai/vision` และ `/api/ai/recipes` อ่าน `process.env.AI_API_KEY`; ไม่มี key → โหมดพิมพ์ + เดโม
- Vision output ต้องผ่าน allowlist `IngredientKey` (ของที่ไม่รู้จัก → `unknown_items_th` ให้ผู้ใช้พิมพ์เอง)
- html-to-image สำหรับการ์ด · Screen Wake Lock API ใน Cook Mode

## 11) ความเป็นส่วนตัว / ความปลอดภัย
- รูปตู้เย็นไม่เก็บบนเซิร์ฟเวอร์ ส่งไป AI ครั้งเดียวแล้วทิ้ง ย่อเหลือ ≤1MB ก่อนส่ง
- ข้อความเตือนถาวร: "วันหมดอายุเป็นค่าประมาณ ดม/ดูก่อนกินเสมอ" และ "เช็กส่วนผสมถ้าแพ้อาหาร"
- ของสถานะ check ไม่ถูกแนะนำในเมนู · สูตรจาก AI ต้องมี disclaimer เรื่องความสุกของเนื้อสัตว์
