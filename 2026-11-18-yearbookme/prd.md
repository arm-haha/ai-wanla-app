# PRD — YearbookMe (เซลฟี่เดียว กลายเป็นรูปรุ่นยุค 80s/90s/Y2K)

## ปัญหา
อยากได้รูปรุ่นย้อนยุคไปลงรีลหรือทำของที่ระลึก แต่แอปฟิลเตอร์ทั่วไปทำให้ทุกคนหน้าเหมือนกัน ไม่มีกรอบปีบุ๊ก คำคม หรือหน้ารุ่นรวมเพื่อน และคนมักเอาเซลฟี่เพื่อนมาแปลงโดยไม่ถาม ซึ่งทั้งเสียบรรยากาศและเสี่ยงเรื่องความยินยอม

## ผู้ใช้
คนอายุ 18–35 ที่ชอบรีลย้อนยุค, นักศึกษาใกล้จบ, กลุ่มเพื่อนที่อยากทำของที่ระลึก, คนจัดปาร์ตี้ธีม 80s/90s/Y2K, พี่ ๆ ที่อยากทำสมุดให้รุ่นน้อง (ใช้รูปของตนเองเท่านั้น)

## Must-have (core demo / Reel)
1. **Era Studio** ⭐ wow moment — เซลฟี่เดียว → ลุค 80s / 90s / Y2K พร้อมคะแนนความเข้า 0–100 ป้าย "เข้าสุด / ใช้ได้ดี / ลุคทดลอง" สีเกรด เมล็ดฟิล์ม กรอบ และพร็อประยะยุค
2. **Group Yearbook Page** — จัดพอร์ตเทรตของเพื่อนที่ยินยอมแล้วเป็นหน้ารุ่น (ชื่อ ชื่อเล่น บทบาท เช่น "เพื่อนที่ขาดไม่ได้") กริด 2×2 หรือ 3×2
3. **Caption Quotes + Autograph** — คำคม 4 โทน (หวาน ขำ ภูมิใจ โหยหา) ตามยุค + การ์ดเซ็นให้เพื่อน
4. **Print / Share** — ส่งออก A4 รูปเดี่ยว, A4 สี่รูป, สติกเกอร์ 5×5 ซม. และการ์ดแชร์ 1080×1350 / 1080×1920
5. **Consent Guard** — รับเฉพาะรูปของตนเอง; บล็อกรูปบุคคลสาธารณะ, รูปที่มีคนอื่นโดยไม่ยินยอม, อายุ < 13, และอายุ 13–17 ที่ยังไม่มีผู้ปกครองยินยอม

## Nice-to-have (retention)
6. **Era Library** — ดูรายละเอียด 3 ยุค: โทนสี ทรงผม เสื้อผ้า พร็อป ใช้ออฟไลน์ได้
7. **Prop Kit** — เลือกพร็อป 1–2 ชิ้นต่อยุค (ที่คาดผมนีออน, เดนิม, มือถือฝาพับ ฯลฯ)
8. **Role Stickers** — แปะบทบาทบนหน้ารุ่น (ประธานรุ่น ชมรมปีบุ๊ก คนรับไมค์ ฯลฯ)
9. **Share Card + Quota** — การ์ดผลลุคมีลายน้ำ; ฟรี 3 ครั้ง/วัน
10. **Safety Guard** — ข้อความความยินยอมทุกผลลัพธ์ ไม่โชว์ว่าเป็นสมุดรุ่นจริง

## หน้าจอ / Flow
Home (ช่องถ่ายเซลฟี่ + ลุคล่าสุด) → Snap (กรอบหัวถึงไหล่ + เตือนแสง) → Consent Gate → Scanning (face detect → consent check → era score) → **Era Studio (3 ลุคเลื่อนเทียบ)** → คำคม/ลายเซ็น → หน้ารุ่นกลุ่ม → พิมพ์/แชร์

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**น้องมายด์ 22 ปี** กรุงเทพฯ ถ่ายเซลฟี่ในห้องเพื่อทำรีลงานรับปริญญา. Scan Quality **88**; เจอ 1 ใบหน้า (ของตนเอง มั่นใจ 0.96) Consent **ผ่าน**. Era Studio: 90s **88** เข้าสุด · 80s 39 · Y2K 47 → เลือก **Class of '97** กรอบขาวปีบุ๊ก ฟิล์มโทนเย็น. คำคมโทนหวาน: "เพื่อนที่ขาดไม่ได้ของรุ่นนี้ — ไว้เจอกันอีกสิบปีนะ". หน้ารุ่นจำลอง 4 คน (มายด์ เฟิร์น ตัง เกรซ ทุกคนยินยอม) กริด 2×2 โรงเรียนสมมติ Ficto University. พิมพ์ A4 รูปเดี่ยว + แชร์การ์ด

## Design tokens
พื้นครีมปีบุ๊ก #F4EFE6, กรมท่า #1E3A5F, ทองจาง #C4A574, นีออนชมพู #FF2E97 (80s), เงินโครม #E5E7EB (Y2K), หมึก #1F2937; ฟอนต์ Kanit + เสมือนเซอริฟในกรอบปีบุ๊ก; มุมมน 16; ถ่ายขึ้นจอ Reels ชัด ตัดก่อน/หลัง

## Guardrails
- **รูปของตนเองเท่านั้น** — ไม่แปลงถ้ารูปไม่ใช่ของใช้, มีคนอื่นโดยไม่ยินยอม หรือน่าจะเป็นบุคคลสาธารณะ
- **เด็ก** — อายุต่ำกว่า 13 ใช้ไม่ได้; 13–17 ต้องมีผู้ปกครองยินยอม
- **ไม่ใช่สมุดรุ่นจริง** — ชื่อโรงเรียนในตัวอย่างเป็นสมมติ ห้ามอ้างว่าเป็นของสถาบันจริง
- คะแนนลุคและสูตรสีเป็นค่าตัวอย่าง ปรับได้ใน `ERAS`
- ประมวลผลบนเครื่องเป็นค่าเริ่มต้น; ลบรูปต้นฉบับหลังแปลงถ้าอัปโหลด (ขอบเขต ≤ 1 ชม. ค่าที่ตั้งเอง) ไม่เอาไปเทรน
- ตัวอย่างและภาพปกทั้งหมดเป็นบุคคลสมมติ/ภาพวาด ไม่ใช้รูปคนจริง

## Shot list Reel (30 วิ)
- **0–3 วิ:** เซลฟี่ธรรมดาในห้อง แสงนุ่ม ขึ้นข้อความ "เซลฟี่เดียว… เป็นรูปรุ่นได้เลย?"
- **3–10 วิ:** ตัดต่อเร่งตอนใช้ AI สร้างแอป / เลื่อน 3 ยุคผ่านมือ
- **10–22 วิ:**
  1. ถ่ายเซลฟี่ → เข็มคะแนนวิ่งไปหยุดที่ 90s 88 "เข้าสุด"
  2. สไวป์เทียบ 80s / 90s / Y2K ในจอเดียว
  3. เลือกคำคม "เพื่อนที่ขาดไม่ได้ของรุ่นนี้ — ไว้เจอกันอีกสิบปีนะ"
  4. จัดหน้ารุ่น 2×2 แล้วกดพิมพ์ A4
  5. โชว์ Consent Guard "ใช้ได้เฉพาะรูปของตนเอง"
- **22–30 วิ:** "คอมเมนต์ YEARBOOK รับแพ็กฟรี"
- ใช้ภาพประกอบ/ตัวละครสมมติเท่านั้น ไม่ใช้รูปคนจริง เด็กจริง หรือโลโก้โรงเรียนจริง
