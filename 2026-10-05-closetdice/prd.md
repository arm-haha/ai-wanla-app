# ClosetDice — PRD (AI วันละแอป · Day 6/10)

**วันที่:** 2026-10-05 (Asia/Bangkok) · **ช่อง:** AI วันละแอป · **สถานะ:** MVP วันเดียว  
**เอกสารคู่กัน:** `prompts.md`, `schemas.json`, `examples.json`, `README.md`

## 1) สรุปหนึ่งบรรทัด

ถ่ายรูปเสื้อผ้าในตู้ → AI ตัดพื้นหลัง + ติดแท็กให้อัตโนมัติ → กด **ทอยลูกเต๋า** → ได้ชุดแต่งตัววันนี้แบบ flat-lay สวยพร้อมแชร์ ตามอากาศและโอกาส

**ฮุค Reel:** 「เสื้อผ้าเต็มตู้แต่ไม่มีอะไรใส่? ทอยลูกเต๋าทีเดียว ได้ชุดเลย」

## 2) ปัญหา

- คนไทยวัยทำงาน/นักศึกษาเสียเวลา 10–20 นาทีทุกเช้ายืนหน้าตู้ "ไม่มีอะไรใส่" ทั้งที่ตู้เต็ม
- ใส่ชุดเดิมวนซ้ำ 20% ของตู้ ที่เหลือลืมว่ามี
- อากาศไทยเปลี่ยนเร็ว (ร้อน 34°C / ฝนตกบ่าย) — เลือกผิดแล้วทรมานทั้งวัน
- แอปตู้เสื้อผ้าที่มีอยู่ส่วนใหญ่ภาษาอังกฤษ กรอกข้อมูลเยอะ เลิกใช้ใน 3 วัน

## 3) ทำไมไวรัลบน Reels

- **Relatable 100%:** ทุกคนเคยยืนหน้าตู้ — คอมเมนต์ "นี่ฉันทุกเช้า" มาเอง
- **Visual wow 2 จังหวะ:** (1) รูปเสื้อยับบนเตียง → กลายเป็นสติกเกอร์ตัดพื้นหลังสวย (2) ลูกเต๋าหมุน → ชุด flat-lay ร่วงลงมาประกอบเป็นลุค
- **มีความเกม:** ทอยใหม่ได้, ล็อกชิ้นที่ชอบแล้วทอยที่เหลือ → คนดูอยากลองเอง
- **Save-worthy:** "เซฟไว้ทำตู้ตัวเองวันหยุด"
- **Series ได้:** "ให้ลูกเต๋าแต่งตัวผม 7 วัน" → คอนเทนต์ต่อยอดยาว

## 4) เป้าหมาย / ไม่ใช่เป้าหมาย

**เป้าหมาย MVP**
- ตู้เดโม 14 ชิ้นโหลดได้ใน 1 แตะ (ถ่าย Reel ได้ทันที ไม่ต้องถ่ายเสื้อจริง)
- เพิ่มเสื้อผ้าจริงได้ด้วยกล้อง/อัปโหลด + cutout + แท็ก (mock หรือ API)
- ทอยลูกเต๋าได้ชุดที่ "เข้ากันพอดู" ภายใน 1.5 วินาที
- แชร์การ์ดชุดเป็นรูปได้บนมือถือจริง

**ไม่ใช่เป้าหมาย**
- ไม่ทำ virtual try-on บนตัวคน (เสี่ยง ช้า และเรื่องรูปร่าง)
- ไม่ขายของ / affiliate ใน MVP
- ไม่มีล็อกอิน ไม่มีโซเชียลฟีด
- ไม่เคลมว่า AI "รู้แฟชั่นดีกว่าคุณ"

## 6) User stories

1. ในฐานะผู้ใช้ใหม่ ฉันกด「ลองตู้เดโม」แล้วทอยได้เลย โดยไม่ต้องถ่ายอะไร
2. ฉันถ่ายรูปเสื้อบนเตียง แล้วได้ภาพตัดพื้นหลัง + หมวด + สี ให้แก้ได้ก่อนบันทึก
3. ฉันเลือก "ฝนตก · ไปออฟฟิศ" แล้วทอย → ไม่ได้รองเท้าผ้าใบสีขาว/กางเกงขาสั้น
4. ฉันชอบเสื้อตัวนี้ → ล็อกไว้ แล้วทอยเฉพาะชิ้นที่เหลือ
5. ฉันกด「ใส่ชุดนี้วันนี้」→ ลงปฏิทิน และสัปดาห์นี้แอปจะไม่สุ่มชุดเดิมซ้ำ
6. ฉันแชร์การ์ด flat-lay พร้อมแคปชันลง IG Story / LINE
7. (nice) ฉันดูว่าชิ้นไหนไม่ได้ใส่เกิน 30 วัน → "ชิ้นถูกลืม"

## 8) กติกาสุ่ม (Outfit Engine)

ไฟล์ `lib/dice.ts` (pure, เทสต์ได้)

1. **Template ตามโอกาส:** `top+bottom+shoes` หรือ `dress+shoes`; เพิ่ม `outer` ถ้าอากาศ `ac_cold` หรือ `rain` (เสื้อคลุม/กันฝน); `accessory` 50%
2. **กรองแข็ง (hard filter):**
   - `formality` ต้องอยู่ในช่วงของ occasion (เช่น office 2–4, gym 0–1)
   - `weather` ตรง `season_ok` ของชิ้น (เช่น rain → ไม่เอา suede, ไม่เอารองเท้าผ้าใบขาว ถ้าแท็ก `rain_ok:false`)
   - ไม่อยู่ใน wear log ภายใน `no_repeat_days` (ระดับ "ทั้งชุด" เทียบ signature; ระดับชิ้นแค่ลดคะแนน)
   - ชิ้น `in_laundry:true` ออก
3. **ให้คะแนน (soft score 0–100):**
   - สี: neutral (ขาว/ดำ/เทา/ครีม/น้ำตาล/กรม/เดนิม) เข้ากับทุกอย่าง +; สีสด ≥2 ชิ้นต่างโทน −; monochrome +
   - vibe ตรงกัน (minimal/street/sweet/smart/sporty/vintage) +
   - ใส่ล่าสุดเมื่อ ≤3 วัน −
   - ชิ้นถูกลืม (≥30 วัน) + เล็กน้อย (กระตุ้นใส่)
4. สุ่มแบบ weighted จาก top-K=20 combo (seeded random ให้รีเพลย์ได้)
5. ถ้าไม่มี combo ผ่าน → ข้อความ "ตู้ยังไม่พอสำหรับโอกาสนี้ ลองเพิ่มรองเท้า 1 คู่" + ปุ่มผ่อนกฎ
6. **Lock:** ชิ้นล็อกถูกบังคับอยู่ใน combo; ทอยใหม่สุ่มเฉพาะ slot ที่ไม่ล็อก
7. ตั้งชื่อลุคจาก vibe+สี เช่น "Minimal ครีม-กรม ☁️" (template ไทย ไม่ต้องใช้ LLM)

## 9) Tagging Engine

`lib/tagger.ts` pluggable:
- `mock_demo` — ภาพเดโมรู้แท็กล่วงหน้า (fixture) / ภาพจริง: สุ่มแท็ก + ดึงสีเด่นด้วย canvas (k-means 3 สี) → map ชื่อสีไทย
- `vision_api` (optional ผ่าน env) — ส่งภาพ + prompt (ดู `prompts.md` §E) ได้ JSON ตาม `ClothingTagResult`
- ผู้ใช้แก้แท็กได้ทุกช่องก่อนบันทึก (สำคัญ: AI ผิดได้)

`lib/cutout.ts` pluggable:
- `mock_demo` — ใช้ PNG โปร่งใสของชุดเดโม
- `client_bg_removal` (optional) — `@imgly/background-removal` ในเบราว์เซอร์
- `none` — ใช้รูปเดิมใส่กรอบมน (fallback)

## 10) หน้าจอ

1. **Home / Today** — การ์ดอากาศ (ชิปเลือกเอง; ออปชัน fetch Open-Meteo กทม.), ปุ่มลูกเต๋าใหญ่กลางจอ, ชุดล่าสุด
2. **Dice Result** — flat-lay canvas, คะแนนเข้ากัน, ชื่อลุค, 🔒 ต่อชิ้น, ปุ่ม「ทอยใหม่」「ใส่ชุดนี้วันนี้」「แชร์」
3. **Closet** — grid ตามหมวด (เสื้อ/ล่าง/เดรส/ชั้นนอก/รองเท้า/แอคเซส), filter สี, toggle "ซักอยู่"
4. **Add Item (Snap)** — กล้อง/อัปโหลด → progress "กำลังตัดพื้นหลัง…" → preview → ฟอร์มแท็ก → บันทึก
5. **Item Detail** — แท็ก, จำนวนครั้งที่ใส่, ใส่ล่าสุด, ลุคที่เคยเข้าคู่
6. **OOTD Calendar** — เดือน, thumbnail, แตะดูรายละเอียด
7. **Share Sheet** — เลือกขนาด story/feed, เลือกพื้นหลัง 4 แบบ, แคปชัน
8. **Settings** — no_repeat_days, ล้างข้อมูล, โหลดตู้เดโม, export/import JSON
9. (nice) Stats, 7-Day Challenge, Packing, Vote

## 11) Core flows

**Flow A — เดโม Reel (≤20 วิ):** Home → 「ลองตู้เดโม」 → เลือก ฝน+ออฟฟิศ → 🎲 → ลุคร่วง → 🔒 เสื้อ → 🎲 → ล่างเปลี่ยน → 「แชร์」

**Flow B — เพิ่มของจริง:** Closet → ＋ → ถ่ายรูป → cutout → แท็กเติมอัตโนมัติ → แก้สี "กรม" → บันทึก → กลับ grid เห็นชิ้นใหม่เด้ง

**Flow C — ใช้ทุกวัน:** เปิดแอปเช้า → อากาศตั้งไว้แล้ว → 🎲 1–3 ครั้ง → ใส่ชุดนี้ → ปฏิทินเพิ่ม 1 ช่อง (streak)

## 12) UI / แบรนด์

- พื้น off-white **#FAF7F2**, ลาเวนเดอร์ **#8B5CF6** / อ่อน **#C4B5FD**, เนย **#FCD34D**, หมึก **#1E1B2E**, เขียวผ่าน **#22C55E** (คะแนนดี)
- ฟอนต์: IBM Plex Sans Thai / Noto Sans Thai; หัวข้อหนา 700
- ลูกเต๋า: กล่องมน 3D ลาเวนเดอร์ จุดสีเนย (CSS 3D transform หรือ framer-motion) — หมุน 0.9s + เด้ง
- flat-lay: พื้นการ์ดครีมมีเงานุ่ม, ชิ้นวางแบบ fixed layout (เสื้อบนซ้าย, ล่างกลาง, รองเท้าล่างขวา, แอคเซสลอยมุม) หมุนเล็กน้อย −6°…6° ให้ดูธรรมชาติ
- ปุ่มใหญ่ ≥48px, มือถือ 390px เป็นฐาน

## 13) Tech

- Next.js 14 App Router + TypeScript + Tailwind + shadcn/ui + framer-motion
- รูป: เก็บ dataURL ย่อ (≤600px, webp) ใน IndexedDB (`idb-keyval`); metadata ใน localStorage
- Share card: `html-to-image` หรือ canvas เอง → PNG → `navigator.share({files})` fallback ดาวน์โหลด
- อากาศ (optional): Open-Meteo ไม่ต้อง API key → map เป็น weather enum; ถ้าล้มเหลวใช้ชิปเลือกเอง
- Deploy Vercel + manifest PWA
- ไม่มี backend ใน MVP

## 16) Acceptance criteria

- [ ] 「ลองตู้เดโม」โหลด 14 ชิ้นพร้อม PNG โปร่งใสใน <1s
- [ ] ทอย 20 ครั้งติดกันกับตู้เดโม (ฝน+ออฟฟิศ) ไม่มีชุดผิดกฎแข็งเลย
- [ ] ล็อก 1 ชิ้นแล้วทอย → ชิ้นนั้นไม่เปลี่ยน 10/10 ครั้ง
- [ ] เพิ่มของจริงด้วยรูปจากกล้องมือถือได้ แท็กแก้ได้ บันทึกแล้วอยู่หลังรีเฟรช
- [ ] "ใส่ชุดนี้วันนี้" → ปฏิทินแสดง และไม่สุ่มชุดเดิมซ้ำใน 7 วัน
- [ ] การ์ดแชร์ story/feed สร้าง PNG และแชร์ได้บน iOS Safari + Android Chrome
- [ ] UI ไม่เละที่ 360–430px, ตัวอักษรไทยไม่ถูกตัด
- [ ] มีข้อความ「AI ช่วยแนะนำ — สไตล์สุดท้ายเป็นของคุณ」

## 17) ความเสี่ยง / กับดัก

| ความเสี่ยง | ผลกระทบ | ทางแก้ |
|---|---|---|

| เคลมแฟชั่นเกินจริง / body shaming | ดราม่า | ไม่พูดถึงรูปร่าง ไม่ให้คะแนนตัวคน ให้คะแนน "ความเข้ากันของสี" เท่านั้น |
