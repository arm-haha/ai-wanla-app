# PRD — DashDoc (ไฟโชว์หน้าปัด ขับต่อได้ไหม)

## ปัญหา
ไฟเตือนขึ้นหน้าปัดแล้วไม่รู้ว่าอันไหนอันตราย: จอดเลย ขับต่อได้ หรือแค่ลมยางอ่อน? คู่มือรถหนา สัญลักษณ์เยอะ คนส่วนใหญ่เลยเสี่ยงฝืนขับ (เครื่องพังเพราะไฟน้ำมันเครื่อง) หรือตื่นตระหนกเกินเหตุ แล้วไปอู่ก็ไม่รู้ว่าราคาที่ถูกเสนอแพงไหม และลืมต่อ พ.ร.บ./ภาษี/เปลี่ยนน้ำมันเครื่อง

## ผู้ใช้
คนขับรถส่วนตัวทุกเพศวัย, มือใหม่หัดขับ, ผู้หญิงที่ไม่ถนัดเรื่องรถ, ลูก ๆ ที่ดูแลรถให้พ่อแม่, คนขับ Grab/ส่งของ, ครอบครัวที่ขับทางไกลช่วงเทศกาล

## Must-have (core demo / Reel)
1. **Light Scan + Urgency Meter** ⭐ wow moment — ถ่ายหน้าปัด → ตรวจไฟเตือน (17 ดวง) + สีที่เห็น + กะพริบ/ค้าง → Urgency 0–100 → แดง/เหลือง/เขียว + "ขับต่อได้ ~50 กม. ไปอู่ใกล้สุด"
2. **Do-This-Now** — ขั้นตอนทันที (ไฟฉุกเฉิน จอดข้างทาง ดับเครื่อง) + เช็กเฉพาะไฟ: ฝาถังน้ำมัน น้ำมันเครื่อง น้ำหล่อเย็น ลมยาง
3. **Fair Price Check** — ช่วงราคาซ่อมรายการที่น่าจะเป็น (฿ ตามพื้นที่/ประเภทรถ) + ใส่ราคาที่อู่เสนอ → ถูก/สมเหตุสมผล/แพง + คำถามที่ควรถามช่าง
4. **Mechanic Card** — รุ่นรถ ปี เลขไมล์ ไฟเตือน อาการ งบประมาณ → ส่ง LINE ให้อู่ทันที

## Nice-to-have (retention)
5. **Car Diary + Reminders** — บันทึกเช็กระยะ (น้ำมันเครื่อง ยาง แบต น้ำมันเบรก น้ำหล่อเย็น กรองอากาศ พ.ร.บ. ภาษี ประกัน) เตือนตามกม./วัน สถานะ ok/soon/due/overdue
6. **Emergency Kit** — เบอร์ฉุกเฉิน/ประกัน/รถยก/อู่ (placeholder กรอกเอง) + คู่มือยางแบน จั๊มสตาร์ท เครื่องร้อน + เช็กลิสต์ของในรถ
7. **Symptom Add-on** — เลือกอาการ (ควัน กลิ่นไหม้ เบรกนิ่ม ฯลฯ) → escalate ระดับทันที
8. **Light Library** — ดูความหมายไฟทั้ง 17 ดวง ค้นด้วยสี/ชื่อ ใช้ออฟไลน์
9. **Share Card + Quota** — การ์ดผลสแกน 1080×1350 / 1080×1920 มีลายน้ำ; ฟรี 3 สแกน/วัน
10. **Safety Guard** — แสดงข้อความความปลอดภัยทุกผลลัพธ์ ไฟแดง = หยุดทันที

## หน้าจอ / Flow
Home (สแกน + ไดอารี่ล่าสุด + เตือนใกล้ถึงกำหนด) → Snap (กรอบหน้าปัด + เตือนแสงสะท้อน) → Scanning (panel detect → symbol classify → color check) → Symptom chips → **Verdict (Urgency Meter + ขับต่อได้ไหม)** → Do-This-Now → Price & Quote Check → Mechanic Card → Diary / Reminders → Emergency Kit

## Guardrails
- **ไม่ใช่ช่าง ไม่ใช่การวินิจฉัย** — แสดง disclaimer ทุกผล; ไฟแดง/อาการรุนแรง = จอดทันที ไม่มีปุ่ม "ขับต่อ"
- **ถ้าไม่แน่ใจ ให้เลือกด้านปลอดภัย** — ความมั่นใจ < 0.6 ไม่นับเป็นผลและถามย้ำ; สีแดงจริงบนไฟเหลืองหรือเช็กเครื่องกะพริบ = ยกระดับเป็นแดง
- **ค่ากม./วัน/ความเร็วเป็นค่าตัวอย่าง** ต้องให้ช่างรีวิว และปรับตามคู่มือรถแต่ละรุ่น
- **ราคาเป็นช่วงประมาณการ** ไม่ใช่ราคาอู่/ไม่จัดอันดับอู่จริง
- ไม่แนะนำให้เปิดฝาหม้อน้ำตอนร้อน/ไม่ให้ซ่อมเองในที่อันตราย; คู่มือยางแบน/จั๊มสตาร์ทเตือนจอดที่ปลอดภัยก่อน
- เบอร์ฉุกเฉินสาธารณะต้องตรวจกับแหล่งทางการ; เบอร์อื่นเป็น placeholder
- ประมวลผลบนเครื่องเป็นค่าเริ่มต้น; รูปหน้าปัดลบทันทีหลังสแกนถ้าอัปโหลด (ขอบเขต ≤ 1 ชม. ค่าที่ตั้งเอง) ไม่เอาไปเทรน; เลขทะเบียน/เลขไมล์เก็บในเครื่อง
- ตัวอย่างและภาพปกทั้งหมดเป็นบุคคล/รถสมมติ/ภาพวาด
