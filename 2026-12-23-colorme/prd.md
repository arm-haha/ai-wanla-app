# PRD — ColorMe (รูปไหนก็ได้ กลายเป็นหน้าระบายสี)

## ปัญหา
ปิดเทอมปลายปี (ธ.ค.–ม.ค.) ลูกอยู่บ้านทั้งวัน เบื่อแล้วก็ขอดูจอ พ่อแม่อยากได้กิจกรรมบนกระดาษที่เด็กชอบจริง ๆ แต่สมุดระบายสีที่ขายมีแต่ภาพเดิม ๆ ลายการ์ตูนที่เด็กไม่ได้ผูกพัน และโหลดจากเน็ตก็เจอแต่ไฟล์เบลอ ลิขสิทธิ์ไม่ชัด รายละเอียดเยอะเกินวัย (เด็ก 4 ขวบระบายช่องจิ๋ว ๆ ไม่ไหว) ขณะที่ในมือถือพ่อแม่มีรูปที่เด็กรักที่สุดอยู่แล้ว — น้องแมวที่บ้าน ตุ๊กตาตัวโปรด ทะเลที่เพิ่งไปมา ถ้ารูปพวกนี้กลายเป็นหน้าระบายสีได้ในไม่กี่วินาที เด็กจะอยากระบายเองโดยไม่ต้องบังคับ

## ผู้ใช้
พ่อแม่ลูกเล็ก 3–12 ปี, ปู่ย่าตายายที่เลี้ยงหลาน, ครูอนุบาล/ประถมที่อยากได้ใบงานจากรูปในห้องเรียน (ใช้รูปที่ได้รับอนุญาต), ผู้ใหญ่ที่ชอบระบายสีคลายเครียด (โหมด calm จากรูปสัตว์เลี้ยง/ที่เที่ยวของตัวเอง)

## Must-have (core demo / Reel)
1. **Photo → Coloring Page** ⭐ wow moment — เลือกรูป → `photo_check` (แสง/ความคม/ขนาดตัวหลัก/พื้นหลังรก) → A1 ทำความสะอาดรูป (ลด/ลบพื้นหลัง, บอก subject, ตรวจ safety → `AiPhotoClean`) → ย่อเป็น working grid บนเครื่อง → `pick_palette` (สีเทียน 13 สี + `despeckle` ลบจุดฝุ่น) → `quantize` → `merge_small` รวมช่องเล็กกว่าเกณฑ์ → **ลดรายละเอียดอัตโนมัติ** (เพิ่ม min_area ×2 สูงสุด 4 รอบ) จนจำนวนช่อง ≤ เพดานของวัย → `outline` เป็นเส้นคม หนาตามวัย (`make_page`, `level_for_age`)
2. **Colour-by-Number** — เลขประจำสีเรียงตามสีเทียน (เลขคงที่ ไม่สลับไปมา), วางเลขในจุดที่ "ลึกที่สุด" ของช่อง (BFS distance transform → ไม่ทับเส้น), ตารางสีชื่อไทย + hex + จำนวนช่องต่อสี (`label_point`, `legend`); โหมดตัวจิ๋วไม่มีเลข (ระบายอิสระ)
3. **Print A4 Booklet** — เลือก 1–12 หน้า + ปก "สมุดระบายสีของ<ชื่อลูก>" 300 dpi, จำนวนแผ่นพิมพ์สองหน้า, ประมาณหมึก %, โหมดประหยัดหมึก (เส้นบางลงครึ่งหนึ่ง ขั้นต่ำ 2 px), หน้าเฉลยสีสำหรับโหมดเลข (`booklet`, `ink_pct`) → ส่งออก PDF / AirPrint / ร้านปริ้นท์
4. **Scan & Magic Reveal** — ถ่ายรูปหน้าที่ระบายเสร็จ → จัดให้ตรง (4 มุมกระดาษ) → ย่อเป็น grid เดียวกัน → `progress_check`: % ช่องที่ระบายแล้ว (ช่องนับว่าระบายเมื่อ ≥ 60%), % สีอยู่ในช่อง, % ตรงเลข (เฉพาะโหมดเลข แสดงให้ผู้ปกครอง), **ดาว 1–3 ดวง (ขั้นต่ำ 1)** + คำชมภาษาไทย + "ชอบสี…ที่เลือกจัง" → แอนิเมชันภาพก่อน/หลังเลื่อนคู่กัน
5. **Privacy & Safety Guard** — ใช้รูปของเราเอง/ได้รับอนุญาต; A1 ตรวจ nudity / id_document / violent → stop, หน้าเด็กคนอื่น / ตัวการ์ตูนลิขสิทธิ์ → warn; ประมวลผลบนเครื่อง ไม่อัปโหลดรูปต้นฉบับ; การ์ดแชร์ซ่อนหน้าเด็กเสมอ; parent mode ต้องเปิดก่อนแชร์; เตือนพักสายตา 30 นาที; อายุ < 3 → stop (`privacy_check`, `safety_guard`)

## Nice-to-have (retention / viral)
6. **Dot-to-Dot** — โครงร่างตัวหลักจากรูป (polygon 0..100) → จุดเรียงเลขระยะเท่ากัน 10/20/40/80 จุดตามวัย (`dot_to_dot`)
7. **Daily Coloring Quest** — ธีมประจำวัน 14 ธีมหมุนเวียน ("วิวหน้าบ้าน", "ขนมไทย", "ของขวัญปีใหม่"…) + นับวันต่อเนื่อง (เมื่อวานยังนับ) + สติกเกอร์ 3/7/14/30 วัน (`quest`)
8. **Family Gallery & Monthly Art Book** — เก็บผลงานทุกหน้า ดาวรวม สีโปรดประจำเดือน ครบ 8 หน้า → ทำสมุดผลงาน/ของขวัญให้ปู่ย่า (`gallery_summary`)
9. **Calm Mode (ผู้ใหญ่)** — 12 สี เส้นบาง 2 px ช่องละเอียดถึง 200 ช่อง 80 จุด จากรูปสัตว์เลี้ยง/ที่เที่ยวของเราเอง (ระดับ `calm`)
10. **Share Card / Reel + Quota** — การ์ด 1080×1350 3 เลย์เอาต์ (ก่อน/หลัง, reveal + ดาว, ปกสมุด) ซ่อนหน้าเด็ก ลายน้ำ (`share_card`) + Reel 9:16 15–30 วิ 6 ช็อต (`reel_plan`); ฟรี 5 หน้า/วัน (`quota`)

## หน้าจอ / Flow
Home (ภารกิจวันนี้ + ปุ่มใหญ่ "เลือกรูป") → เลือกโปรไฟล์ลูก (ชื่อเล่น + อายุ → ระดับ) → เลือกรูป → Photo QA + Guard → **แปลงร่าง** (wow: เส้นวาดค่อย ๆ ขึ้นบนรูป แล้วสีจางหาย เหลือหน้าระบายสี) → สลับ ระบายอิสระ / ระบายตามเลข / ต่อจุด → เพิ่มลงสมุด → พิมพ์ A4 · หลังระบาย: สแกน → Magic Reveal → แกลเลอรี · เมนูรอง: สมุดผลงานประจำเดือน, สติกเกอร์, การ์ดแชร์, ตั้งค่าผู้ปกครอง

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**น้องข้าวปั้น 6 ขวบ นนทบุรี** + รูปน้องแมว "ส้มจี๊ด" นั่งบนสนามหญ้าใต้ฟ้าใส (รูปสร้างด้วยโค้ด มีจุดฝุ่นสีม่วงและ noise กล้อง) คุณภาพรูป 78/100
- ระดับ kid: พาเลต 6 สี แดง ส้ม เหลือง เขียวอ่อน ฟ้า น้ำตาล → **8 ช่อง** เลข 1–6 เส้น 5 px (จุดฝุ่นม่วงหายหมด ตาเล็ก 2 ช่องถูกรวมเพราะเล็กเกินวัย)
- น้องไข่ตุ๋น 4 ขวบ (tiny): **4 ช่องใหญ่** เส้น 8 px ไม่มีเลข · น้องภูผา 10 ขวบ (big): 19 ช่อง 8 สี มีตาแมว + กอหญ้า · คุณแม่ฝน (calm): เส้น 2 px
- รูปลายทาง 20 แถบ อายุ 4 → ลดรายละเอียดอัตโนมัติเหลือ 1 ช่อง (กันหน้าที่ "ละเอียดเกินวัย")
- สมุด 3 หน้า + ปก = 4 หน้า พิมพ์สองหน้า 2 แผ่น หมึก ~6.3% · โหมดประหยัดหมึก เส้น 2 px
- สแกน: ระบายครบ → 100% ⭐⭐⭐ "เสร็จแล้ว! ผลงานศิลปินตัวจริง ชอบสีฟ้าที่เลือกจัง" · ระบายครึ่งเดียว บางช่องใช้สีอื่น → 50% ⭐⭐ ตรงเลข 75% (ยังชมเหมือนเดิม)
- ภารกิจ 23 ธ.ค. "วิวหน้าบ้าน" ต่อเนื่อง 3 วัน → สติกเกอร์ "ดินสอสีทอง" · แกลเลอรีธันวาคม 8 หน้า 20 ดาว สีโปรด "ส้ม" → ทำสมุดผลงานได้
- ต่อจุดน้องแมว 20 จุด ระยะห่างเท่ากัน 14 หน่วย

## Design tokens
พื้นครีม #FFF8EC, กรมท่า #1F2A44, เหลืองดินสอ #FFC83D, ส้มแมว #F78C28, ฟ้า #78BEF0, เขียวอ่อน #96D250, ชมพูเน้น #FF6B8B; ฟอนต์ Kanit (หัวข้อ) + Sarabun (เนื้อหา); ปุ่มกลมใหญ่ (เด็กกดง่าย ≥ 56 px); เลขในช่องเป็นสีเทาอ่อน; แอนิเมชัน "เส้นวาดเอง" 1.2 วิ + เสียงดินสอสี; ตารางสีเป็นวงกลมสีเทียนพร้อมเลข

## Reel shot list (20 วิ · ใช้มือเด็ก/ผู้ใหญ่ ไม่ต้องเห็นหน้าเด็ก)
- **0–3 วิ:** เด็กนอนเบื่อบนโซฟา (ถ่ายจากด้านหลัง/เห็นแค่มือ) ข้อความ "ปิดเทอม ลูกเบื่อ ติดจอ?"
- **3–6 วิ:** ตัดต่อเร่งตอนสร้างแอปด้วย AI จากแพ็กนี้ (โชว์ prompts.md)
- **6–10 วิ:** เลือกรูปน้องแมวในมือถือ → เส้นค่อย ๆ วาดขึ้น สีจางหาย กลายเป็นหน้าระบายสี (beat drop)
- **10–14 วิ:** กดสลับ "ระบายตามเลข" → เลขเด้งเข้าช่อง → เครื่องปริ้นท์พ่นกระดาษ A4 มีชื่อน้องบนปก
- **14–18 วิ:** มือเด็กระบายสีเทียน (ไทม์แลปส์) → สแกน → ภาพก่อน/หลังเลื่อนคู่กัน + ดาว 3 ดวง
- **18–20 วิ:** CTA "คอมเมนต์ COLOR รับแพ็กฟรี"
- ตัวอักษรเล็กท้ายคลิป: "ใช้รูปของเราเอง · ประมวลผลบนเครื่อง · การ์ดแชร์ซ่อนหน้าเด็ก"

## Build plan (ประมาณ 1 วันด้วย AI codegen)
1. **ชม. 0–1:** P0 scaffold PWA + tokens + port `colorme.py` เป็น TS ให้ `tests.py` ผ่านทุกข้อ (36 tests)
2. **ชม. 1–2:** P1–P2 โปรไฟล์ลูก/ระดับ + เลือกรูป + Photo QA + Guard
3. **ชม. 2–4:** P3–P5 A1 clean (background remove บนเครื่องด้วย MediaPipe/ONNX หรือ API) → ย่อ grid (64–120 px ด้านยาว) → make_page → วาดเส้นแบบเวกเตอร์ (marching squares บน grid → path SVG เรียบ) + วางเลข
4. **ชม. 4–5:** P6–P7 Booklet PDF (jsPDF/pdf-lib A4 300 dpi) + ต่อจุด
5. **ชม. 5–6:** P8–P9 Scan (หา 4 มุมกระดาษ + perspective warp ด้วย OpenCV.js) → progress_check → Magic Reveal; ภารกิจ + แกลเลอรี
6. **ชม. 6–7:** P10–P12 Share/Reel, Quota/Guard, QA กับรูปจริงหลายแบบ + ถ่าย Reel ตาม shot list

## Risks & traps
| ความเสี่ยง / กับดัก | ผลกระทบ | วิธีลด |
|---|---|---|
| **กับดัก:** ใช้ edge detection (Canny) ตรง ๆ กับรูปถ่าย | เส้นยุ่งเป็นขน ช่องปิดไม่สนิท ระบายไม่ได้ | แบ่งช่องจากสีที่ quantize แล้ว (ช่องปิดเสมอโดยนิยาม) + despeckle + merge_small; เส้น = ขอบระหว่างช่อง |
| **กับดัก:** ให้ image model "วาดหน้าระบายสี" เอง | ภาพสวยแต่ช่องไม่ปิด เลขวางไม่ได้ ผลไม่เหมือนเดิมทุกครั้ง แพง | AI ทำแค่ clean/ลดพื้นหลัง + ตรวจ safety; แบ่งช่อง วางเลข ให้ดาว เป็นโค้ด deterministic |
| ละเอียดเกินวัย | เด็กเล็กระบายไม่ไหว เลิกกลางคัน | เพดานช่องต่อวัย + ลดรายละเอียดอัตโนมัติ + เส้นหนาขึ้นตามวัย |
| เลขทับเส้น / ช่องเล็กใส่เลขไม่ได้ | อ่านไม่ออก พิมพ์แล้วดูมั่ว | distance transform หา "จุดลึกสุด", ช่องเล็กเกินใส่ลูกศรชี้ (`fits=false`) |
| รูปเด็กคนอื่น / รูปจากโซเชียล / ลิขสิทธิ์การ์ตูน | ความเป็นส่วนตัว PDPA, ลิขสิทธิ์ | ใช้รูปของเราเอง, บนเครื่อง, ซ่อนหน้าในการ์ดแชร์, เตือนลิขสิทธิ์ ห้ามพิมพ์ขาย |
| คะแนนทำให้เด็กเสียใจ | ดราม่า "แอปบอกลูกระบายผิด" | ดาวขั้นต่ำ 1, คำชมล้วน, % ตรงเลขแสดงเฉพาะผู้ปกครอง, ไม่มีอันดับ |
| หมึกพิมพ์หมด/สิ้นเปลือง | พ่อแม่ไม่อยากพิมพ์ | ประมาณหมึก + โหมดประหยัด + พื้นขาวล้วน ไม่มีพื้นหลังทึบ |

## Guardrails
- ใช้เฉพาะรูปที่ถ่ายเองหรือได้รับอนุญาต ไม่ดึงรูปคนอื่นจากโซเชียล
- ไม่แปลงบัตรประชาชน สลิป เอกสาร รูปโป๊ รูปรุนแรง
- การ์ดแชร์ซ่อนหน้าเด็กเสมอ; แชร์ได้เมื่อเปิด parent mode
- ไม่ให้คะแนนแบบตัดสิน ไม่จัดอันดับเด็ก ดาวขั้นต่ำ 1
- ตัวการ์ตูน/โลโก้ลิขสิทธิ์: ระบายในบ้านได้ ห้ามพิมพ์ขาย
- เด็กต่ำกว่า 3 ขวบ ให้ผู้ใหญ่เล่นด้วยใกล้ ๆ (สีเทียนชิ้นเล็ก)
- ทุกตัวอย่างในแพ็กเป็นบุคคลสมมติ รูปตัวอย่างสร้างด้วยโค้ด

## Metrics
- เวลาจากเลือกรูปถึงเห็นหน้าระบายสี (เป้า < 5 วินาทีบนมือถือกลาง ๆ)
- % หน้าที่ถูกพิมพ์หรือระบายบนจอจนจบ (เป้า 40%)
- % ผู้ใช้ที่สแกนผลงานกลับมาอย่างน้อย 1 ครั้ง (เป้า 25%)
- ภารกิจต่อเนื่อง ≥ 3 วัน (เป้า 20% ของผู้ใช้ปิดเทอม)
- จำนวนการ์ดแชร์ก่อน/หลังที่ติดลายน้ำ ColorMe
