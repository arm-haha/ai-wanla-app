# PRD — CardReady (รูปติดบัตรผ่านชัวร์)

## ปัญหา
ต้องใช้รูปติดบัตรทีไรก็วุ่น: ไปร้านต้องเสียเวลา/เสียเงิน ถ่ายเองก็โดนตีกลับเพราะพื้นหลังไม่เรียบ แสงเหลือง เงาบนหน้า ขนาดผิด หรือพิมพ์แล้วแตก ใบสมัครงาน พาสปอร์ต วีซ่า บัตรนักเรียนต่างมีข้อกำหนดต่างกัน คนส่วนใหญ่ไม่แน่ใจว่าผ่านไหมจนถึงหน้างาน

## ผู้ใช้
คนหางาน/เด็กจบใหม่ (ส่งใบสมัครออนไลน์ด่วน), นักเรียน-นักศึกษา, พ่อแม่ที่ต้องทำเอกสารให้ลูก, คนต่ออายุบัตร/พาสปอร์ต, ฟรีแลนซ์ที่ต้องใช้รูปสมัครงาน/ยื่นวีซ่า

## Must-have (core demo / Reel)
1. **Selfie Snap → Face Detect + Auto ID Crop + BG Remove** ⭐ wow moment — เซลฟี่ห้องหอแสงเหลือง พื้นหลังรก → ครอปตามสัดส่วนบัตร ตัดพื้นหลัง ได้พื้นขาวคมใน ~3 วิ
2. **BG Studio** — พื้น ขาว / ฟ้ากรมการ / แดง + กำหนด hex เอง
3. **Size Presets** — 1 นิ้ว (25×35 mm = 295×413 px @300dpi), 2 นิ้ว (40×60), พาสปอร์ต (35×45), วีซ่า (35×45), ใบสมัครงานไทย (25×35) แสดง mm/px ชัด
4. **Soft Light & Natural Skin** — แสงสม่ำเสมอ ลดสีเหลือง ลดตำหนิเล็กน้อย **ห้าม** ดัดหน้า/ผิวพลาสติก (สูงสุด 0.35)
5. **Print Sheet A4** — จัดหลายใบ (เช่น 8 ใบ) มีเส้นตัด และเช็ก dpi ≥ 300

## Nice-to-have (retention)
6. **Doc Checklist** — บัตรประชาชน / พาสปอร์ต / วีซ่า / สมัครงาน / นักเรียน พร้อมมิเตอร์ผ่าน-ไม่ผ่าน
7. **History Vault** — เก็บรูปเก่าในเครื่อง ไม่อัปโหลดโดยปริยาย
8. **Before/After Share Card** — การ์ดสำหรับ Reels
9. **Batch Mode** — โปรไฟล์ครอบครัว (สูงสุด 8 คน; ตัวอย่างเป็นคนสมมติ)
10. **Export Pack** — JPG/PNG + PDF พิมพ์ A4

## หน้าจอ / Flow
Home (ประวัติ + ปุ่มถ่าย) → Snap (กรอบหน้า + คำแนะนำแสง) → Processing (face detect → crop → bg remove → soft light) → Result (Before/After slider + Pass Score) → Size & BG → Checklist → Print Sheet → Export/Share → Vault / Batch

## Demo fixture (ข้อมูลสมมติเท่านั้น)
น้องมิ้นท์ (Mint) 24 ปี สมัครงานบริษัทในกทม. ถ่ายเซลฟี่ห้องหอแสงเหลือง 3024×4032 พื้นหลังรก → CardReady 1 นิ้ว พื้นขาว 295×413 px @300 dpi, **Pass Score 92**, Soft Light เปิด, Print Sheet A4 8 ใบ (เช็ก 300 dpi ผ่าน), Doc Checklist สมัครงาน 6/6

## Design tokens
พื้นขาว #FFFFFF, ฟ้าอ่อน #E8F3FF, ตัวหนังสือ #1A1A1A, accent มิ้นต์ #2DD4BF, ผ่าน #16A34A, เตือน #F59E0B, ไม่ผ่าน #DC2626; ฟอนต์ Kanit/Noto Sans Thai; มุมมน 16; ดูเป็นมืออาชีพ สะอาด ถ่ายขึ้นจอ Reels

## Guardrails
- **ไม่อ้างการรับรองจากราชการ** — แสดง disclaimer เสมอ ผู้ใช้ต้องตรวจข้อกำหนดล่าสุดของหน่วยงานปลายทาง
- **ไม่แต่งเกินจริง** — ห้ามดัดรูปหน้า ขยายตา ผอมหน้า ผิวพลาสติก แต่งหน้าหนัก; รูปต้องเหมือนตัวจริง (identity check ก่อน/หลัง)
- ห้ามสร้างภาพใบหน้าแทนผู้ใช้ ห้ามใช้เพื่อปลอมเอกสาร; ตรวจจับรูปที่ไม่ใช่หน้าคนจริง
- ประมวลผลบนเครื่องเป็นค่าเริ่มต้น; ถ้าส่งเซิร์ฟเวอร์ลบทันทีหลังเสร็จ (≤ 1 ชม., ค่าที่ตั้งเอง) ไม่เอาไปเทรน
- ไฟล์ export ใส่ metadata "Made with CardReady · not a government certificate"
- ตัวอย่างและภาพปกทั้งหมดเป็นบุคคลสมมติ/ภาพวาด ไม่ใช้ใบหน้าจริง
