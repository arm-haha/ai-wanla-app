# DoodlePop — รูปวาดลูก ขยับได้ (AI วันละแอป · 2026-11-05)

ถ่ายรูปวาดสีเทียนของลูก → ตัดกระดาษ/ลบเงา/ตัดพื้นหลัง → ใส่โครงกระดูกอัตโนมัติ → ตัวละครโบกมือ กระโดด เต้น เดิน หมุน นอนหลับ → นิทานก่อนนอนที่ใช้รูปวาดลูกเป็นภาพประกอบ + เสียงเล่า → แชร์เป็น Reel/GIF/MP4 → แกลเลอรีครอบครัว สรุปพัฒนาการรายปี, สติกเกอร์, สมุดระบายสี, โจทย์วาดรายวัน, ลิงก์ให้ตายาย, เช็กขนาดสกรีนของขวัญ

## ในแพ็ก
- `prd.md` — ปัญหา, must-have / nice-to-have (11 ฟีเจอร์), หน้าจอ, demo fixture, design tokens, guardrails ความปลอดภัยเด็ก
- `prompts.md` — work-order prompts P0–P12 + AI prompts A1–A5
- `schemas.json` — JSON Schema 2020-12 (17 defs)
- `examples.json` — 61 ตัวอย่าง (ข้อมูลสมมติ) validate ผ่านหมด
- `reference/` — `doodlepop.py` logic deterministic, `fixtures.py` (แม่แพร + น้องใบเตย 5 ขวบ + พี่ภูผา 8 ขวบ, รูปวาด 6 รูป), `tests.py` (27 tests), `build.py`
- `social/` — `make_cover.py`, ปก 1080×1350 / 1080×1080, `fb_post.md`

## รัน
```
cd reference && python3 tests.py && python3 build.py   # ต้องมี jsonschema
```

## หมายเหตุ
- น้ำหนัก Scan Score, ความยาวท่า, จำนวนหน้านิทานตามอายุ, ความเร็วเสียงเล่า, โควตาฟรี 3 แอนิเมชัน/วัน เป็นค่าที่ตั้งเอง ปรับได้
- ขนาดสติกเกอร์ใช้กรอบ 370×320 px และจำนวน 8/16/24/32/40 ตามแนวทาง LINE Creators Market (ตรวจสเปกล่าสุดก่อนส่งจริง)
- รูปวาดและข้อมูลเด็กเก็บในเครื่องเป็นค่าเริ่มต้น ไม่ต้องใช้หน้าเด็ก ทุกตัวอย่างเป็นบุคคลสมมติ
