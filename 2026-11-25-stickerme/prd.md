# PRD — StickerMe (เซลฟี่เดียว ได้สติกเกอร์ LINE หน้าตัวเองทั้งเซ็ต)

## ปัญหา
อยากมีสติกเกอร์ LINE เป็นหน้าตัวเองไว้ตอบแชท แต่ทำเองไม่เป็น ไม่รู้จะวาดกี่อารมณ์ ข้อความไทยสั้นแค่ไหน และไฟล์ต้องขนาดเท่าไรถึงอัปโหลดใน LINE Creators ได้ แถมกลัวเอาหน้าคนอื่นมาใช้โดยไม่ได้รับอนุญาต

## ผู้ใช้
วัยทำงาน 18–35 ที่แชท LINE ทุกวัน, คนที่อยากได้สติกเกอร์หน้าตัวเองเป็นของขวัญ, คนที่เคยเซฟสติกเกอร์เพื่อนแล้วอยากทำของตัวเอง, ผู้ปกครองที่อยากทำชุดให้ลูก (ต้องยินยอมเอง)

## Must-have (core demo / Reel)
1. **Emotion Set** ⭐ wow moment — เซลฟี่ → ชุด 16 อารมณ์ (ยิ้ม หัวเราะ รัก ขยิบตา โอเค ยกนิ้ว เศร้า ร้องไห้ โกรธ ตกใจ ง่วง คิด ขอโทษ ฉลอง เหนื่อย ขอร้อง) เป็นภาพประกอบมีลายน้ำ
2. **Thai Text Bubbles** — ติดข้อความสั้น 8 วลี เช่น "เข้าใจแล้ว" "กำลังไป!" "กินข้าวยัง?" "รักนะ" จำกัดความยาวให้อ่านบนสติกเกอร์
3. **Style Packs** — เลือก 8 สไตล์: จิ๋วหัวโต, การ์ตูนเส้นหนา, สีน้ำ, ป๊อปอาร์ต, พิกเซล, ดินปั้น, เส้นบาง, สติกเกอร์เงา
4. **LINE Creators Export Spec** — ตรวจขนาด 370×320, รูปหลัก 240×240, แท็บ 96×74, จำนวน 8/16/24, ไฟล์ PNG พื้นโปร่งใส พร้อมเตือนให้ตรวจคู่มือทางการอีกครั้ง
5. **Own-face Consent Guard** — ต้องยืนยันว่าเป็นใบหน้าของตนเอง ห้ามใช้หน้าคนอื่นหรือเลียนแบบคนดัง ถ้าดูเป็นผู้เยาว์ต้องมีผู้ปกครองยินยอม

## Nice-to-have (retention)
6. **Chat Preview** — ดูสติกเกอร์ 4 ใบในแชทจำลองก่อนส่งออก
7. **Pack size switch** — สลับชุด 8 / 16 / 24 ใบ
8. **Custom bubble** — พิมพ์ข้อความไทยเองได้ ถ้ายาวเกินจะตัดให้สั้น
9. **Share Card + Quota** — การ์ดผลมีลายน้ำ ฟรี 3 ครั้ง/วัน
10. **Safety Guard** — ทุกผลบอกว่าเป็นภาพประกอบ ไม่ใช่ผลิตภัณฑ์ของ LINE

## หน้าจอ / Flow
Home (ถ่ายเซลฟี่ + ชุดล่าสุด) → Snap (กรอบใบหน้า + เตือนแสง/เบลอ) → ยืนยันใบหน้าตนเอง → เลือกสไตล์ → **ชุด 16 อารมณ์ปรากฏ** → ติดข้อความไทย → พรีวิวแชท → เช็กสเปกส่ง Creators → การ์ดแชร์

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**น้องเจน 24 ปี** กรุงเทพฯ อยากได้ชุดจิ๋วหัวโต 16 ใบ. เซลฟี่คุณภาพ **91** เจอใบหน้ามั่นใจ 0.95 สัดส่วนหน้า 0.80 → ยืนยันใบหน้าตนเอง → ได้ชุด 16 ใบ สไตล์จิ๋วหัวโต มีข้อความไทย **8** ใบ เช่น "เข้าใจแล้ว" "รักนะ" ขนาด 370×320 PNG พื้นโปร่งใส รูปหลัก 240×240 แท็บ 96×74 → **พร้อมส่งตรวจใน Creators Studio** (ต้องตรวจคู่มือทางการอีกครั้ง)

## Design tokens
พื้นครีมสติกเกอร์ #FFF7ED, เส้นกรม #1F2937, ชมพูป๊อป #FB7185, เหลือง #FBBF24, ฟ้า #38BDF8, เขียวผ่าน #16A34A; ฟอนต์ Kanit; มุมมน 24; กริดสติกเกอร์ตัดกลางจอ ถ่ายขึ้น Reels ชัด (เซลฟี่วาด → ชุด 16 ใบ)

## Guardrails
- **ภาพประกอบ ไม่ใช่รูปถ่ายจริง และไม่ใช่ผลิตภัณฑ์ของ LINE**
- ใช้ได้เฉพาะใบหน้าของตนเอง ห้ามหน้าคนอื่น ห้ามเลียนแบบคนดังหรือตัวละครที่มีลิขสิทธิ์
- ผู้เยาว์ต้องมีผู้ปกครองยินยอม
- ขนาดและจำนวนใบเป็นค่าตัวอย่าง ต้องตรวจกับคู่มือทางการของ LINE Creators Studio ก่อนอัปโหลด
- ประมวลผลบนเครื่องเป็นค่าเริ่มต้น ลบเซลฟี่หลังสร้างชุดได้ ไม่เอาไปเทรน
- ตัวอย่างและภาพปกเป็นบุคคลสมมติ/ภาพวาด ไม่ใช้ใบหน้าจริง

## Shot list Reel (30 วิ · ใช้ภาพประกอบ/ใบหน้าจำลองเท่านั้น ห้ามใบหน้าจริง ห้ามใบหน้าเด็ก)
- **0–3 วิ:** มือเปิดแชท LINE แล้วเลื่อนหาสติกเกอร์ ขึ้นข้อความ "เซลฟี่เดียว ได้สติกเกอร์หน้าตัวเองทั้งเซ็ต?"
- **3–10 วิ:** ตัดต่อเร่งตอนใช้ AI สร้างแอปจากแพ็กนี้
- **10–22 วิ:**
  1. ถ่ายเซลฟี่ ชุดจิ๋วหัวโต 16 ใบเด้งขึ้นทันที
  2. สติกเกอร์ยิ้มติดข้อความ "เข้าใจแล้ว"
  3. สลับสไตล์จากจิ๋วหัวโตเป็นป๊อปอาร์ต
  4. พรีวิวแชทจำลอง 4 ใบ
  5. เช็กสเปกผ่าน 370×320 พร้อมส่ง Creators
- **22–30 วิ:** "คอมเมนต์ STICKER รับแพ็กฟรี"
- ปิดท้ายมีข้อความเล็ก "ภาพประกอบ ไม่ใช่ผลิตภัณฑ์ของ LINE · ใช้ใบหน้าตนเองเท่านั้น"
