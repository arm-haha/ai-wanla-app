# PRD — SellSnap (ถ่ายของมือสอง ได้โพสต์ขายพร้อมราคา)

## ปัญหา
อยากขายของมือสองบนโซเชียลแต่เขียนโพสต์ไม่เป็น ไม่รู้จะตั้งราคาเท่าไร ถ่ายรูปยังไงให้คนเชื่อ และตอบคนต่อราคาหรือนัดรับซ้ำ ๆ ทุกครั้ง แถมพอขายแล้วก็จำไม่ได้ว่าชิ้นไหนไปแล้ว

## ผู้ใช้
คนอายุ 18–45 ที่ขายของในบ้านบ้างเป็นครั้งคราว, คนย้ายบ้าน, คนที่ไม่อยากเปิดร้านแต่อยากโพสต์ในกลุ่ม, คนที่เคยโดนต่อราคาหรือนัดแล้วไม่มา

## Must-have (core demo / Reel)
1. **Title + Description** ⭐ wow moment — ถ่ายของ → ได้ชื่อโพสต์และคำบรรยายภาษาไทย รวมสี สภาพ และตำหนิ
2. **Price Range Suggestion** — ช่วงราคาเป็นบาทตามหมวดและสภาพ (ค่าตัวอย่าง ไม่ใช่ราคาตลาดจริง)
3. **Condition Grade** — เกรด A–E: เหมือนใหม่ / สภาพดี / ใช้งานได้มีรอย / สภาพพอใช้ / ขายซาก
4. **Photo Tips** — แนะนำให้ถ่ายมุมครบ โชว์ตำหนิ และวางของเทียบขนาด
5. **Buyer-Reply Templates** — ข้อความตอบต่อราคา นัดรับ ขอคนนี้ไว้ ขายแล้ว และกันมิจฉาชีพ
6. **Sold Log** — บันทึกของที่ยังขาย / จอง / ขายแล้ว รวมยอดเป็นบาท

## Nice-to-have (retention)
7. **Category library** — 9 หมวด เช่น โคมไฟ เก้าอี้ กระเป๋า อิเล็กทรอนิกส์ เสื้อผ้า ของในครัว หนังสือ ของเล่น
8. **Meetup safety** — เตือนให้นัดที่สาธารณะ และไม่โอนเงินล่วงหน้า
9. **Share Card + Quota** — การ์ดโพสต์มีลายน้ำ ฟรี 3 ครั้ง/วัน
10. **Safety Guard** — ทุกผลบอกว่าไม่ใช่ตลาดกลางและราคาเป็นค่าประมาณ

## หน้าจอ / Flow
Home (ถ่ายของ + ของที่ยังขาย) → Snap (กรอบสินค้า + เตือนแสง/เบลอ) → อ่านหมวด/สี/ตำหนิ → **ชื่อโพสต์ + เกจราคา** → เกรดสภาพ → ทิปถ่ายรูป → เทมเพลตตอบ → สมุดขาย → การ์ดแชร์

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**พี่บอส 31 ปี** กรุงเทพฯ ขายโคมไฟตั้งโต๊ะสีครีม. ถ่ายสินค้าคุณภาพ **90** หมวดโคมไฟ สภาพ **B สภาพดี** มีรอยขีดเล็กที่ฐาน → ชื่อโพสต์ "โคมไฟตั้งโต๊ะ สีครีม สภาพดี" ราคาแนะนำ **฿450–750** กลาง ฿600 → ทิป 3 ข้อ (โชว์ตำหนิ, เทียบขนาด, ถ่าย 3 มุม) → ตอบต่อราคาได้ที่ ฿570 → นัดรับแถวลาดพร้าว

## Design tokens
พื้นครีมกระดาษ #FFFBEB, เขียวราคา #16A34A, เหลืองแท็ก #F59E0B, กรมตัวอักษร #1F2937, แดงเตือน #DC2626; ฟอนต์ Kanit; มุมมน 20; การ์ดโพสต์ตัดกลางจอ ถ่ายขึ้น Reels ชัด (รูปของ → ชื่อโพสต์ + ฿450–750)

## Guardrails
- **ไม่ใช่ตลาดกลาง ไม่ใช่ราคาตลาดจริง** — ช่วงราคาเป็นค่าตัวอย่าง
- นัดรับในที่สาธารณะ อย่าโอนเงินหรือส่งของล่วงหน้า
- ความมั่นใจ < 0.6 ไม่นับหมวด/สภาพ ต้องถ่ายใหม่หรือเลือกเอง
- ไม่ดึงเบอร์ บัญชีธนาคาร หรือแชทจริงจากรูป
- ตัวอย่างและภาพปกเป็นสินค้า/บุคคลสมมติ ภาพวาด ไม่ใช้ของจริงหรือคนจริง

## Shot list Reel (30 วิ · ใช้ของจำลอง/ภาพประกอบเท่านั้น ห้ามสินค้ามีโลโก้จริง ห้ามคนจริง)
- **0–3 วิ:** กองของในบ้าน ขึ้นข้อความ "จะขายของมือสอง แต่จะตั้งราคาเท่าไร?"
- **3–10 วิ:** ตัดต่อเร่งตอนใช้ AI สร้างแอปจากแพ็กนี้
- **10–22 วิ:**
  1. ถ่ายโคมไฟ ได้ชื่อโพสต์ทันที
  2. เกจราคาวิ่งไปหยุดที่ ฿450–750 ป้ายสภาพ B
  3. โชว์ทิป "ถ่ายตำหนิใกล้ ๆ"
  4. แตะเทมเพลตต่อราคา ฿570
  5. ย้ายรายการไปสมุดขายแล้ว
- **22–30 วิ:** "คอมเมนต์ SELL รับแพ็กฟรี"
- ปิดท้ายมีข้อความเล็ก "ราคาเป็นค่าตัวอย่าง ไม่ใช่ตลาดกลาง"
