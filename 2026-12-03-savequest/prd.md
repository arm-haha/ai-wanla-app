# PRD — SaveQuest (ออมเงินแบบเกม เห็นกระปุกโต)

## ปัญหา
ตั้งใจจะออมแต่ไม่เห็นความคืบหน้า ตัวเลขในบัญชีไม่กระตุ้น แผน 52 สัปดาห์ในสเปรดชีตทำแล้วเลิก และไม่มีอะไรให้แชร์ตอนถึงครึ่งทาง คนเลยกลับไปใช้เงินกับของเล็ก ๆ ทุกวันโดยไม่รู้ว่าเป้ายังไกลแค่ไหน

## ผู้ใช้
คนอายุ 18–35 ที่อยากเที่ยว/ซื้อของใหญ่, คนเริ่มทำงานที่อยากมีกองฉุกเฉิน, คู่ที่ออมด้วยกัน, คนที่เคยลองสเปรดชีตแล้วเลิก, พี่น้องที่อยากมีกระปุกร่วม

## Must-have (core demo / Reel)
1. **Goal Jar Studio** ⭐ wow moment — ตั้งเป้า + รูปความฝัน → กระปุกโตตาม % ที่ออม ป้าย "กระปุกโตถึง 42%" ระดับ empty/growing/halfway/almost/full
2. **Daily Challenge** — ชาเลนจ์รายวัน 8 แบบ (งดกาแฟร้าน ทำข้าวกล่อง งดเดลิเวอรี่ ฯลฯ) เก็บได้เป็นบาทและ XP
3. **52-Week / Random-Number Plans** — แผน 52 สัปดาห์ (สัปดาห์ที่ n × ฐาน) หรือสุ่มตัวคูณ 1–52 ตาม seed คงที่
4. **Streaks** — นับวันออมต่อเนื่อง มีโทเคนแช่แข็งได้ 1 ช่องว่าง ป้าย "ไฟลุก" เมื่อครบ 7 วัน
5. **Milestone Share Card** — การ์ด 25/50/75/100% พร้อมสตรีค ขนาด 1080 สำหรับแชร์

## Nice-to-have (retention)
6. **Goal Library** — เป้าพร้อมใช้ 7 แบบ (เที่ยวญี่ปุ่น กองฉุกเฉิน แกเจ็ต งานแต่ง ค่าเทอม ดาวน์รถ/บ้าน ตั๋วคอนเสิร์ต)
7. **Round-Up Log** — ปัดเศษค่าใช้จ่ายขึ้นเป็นขั้น ฿10/฿50/฿100 แล้วเก็บส่วนต่าง
8. **Team Jar** — กระปุกร่วมหลายคน เห็นสัดส่วนแต่ละคน
9. **Share Card + Quota** — การ์ดมีลายน้ำ; ฟรี 3 รูปเป้า/วัน
10. **Safety Guard** — ข้อความทุกผลว่าไม่ใช่ธนาคารและไม่ใช่คำแนะนำการลงทุน

## หน้าจอ / Flow
Home (กระปุกใหญ่ + % + สตรีค + ชาเลนจ์วันนี้) → ตั้งเป้า (เลือกจากคลังหรือกำหนดเอง + ถ่ายรูปความฝัน) → **Jar Studio (กระปุกโต + ไมล์สโตนถัดไป)** → แผน 52 สัปดาห์หรือสุ่ม → ชาเลนจ์/ปัดเศษ → กระปุกร่วม → การ์ดแชร์

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**น้องมิ้น 27 ปี** กรุงเทพฯ ตั้งเป้าเที่ยวญี่ปุ่น ฿45,000 เริ่ม 3 มี.ค. ถึง 3 ธ.ค. 2026. ออมไปแล้ว ฿18,900 → กระปุก **42%** ระดับ growing "กระปุกโตถึง 42%". ไมล์สโตนถัดไป 50% อีก ฿3,600. แผน 52 สัปดาห์ ฐาน ฿100 สัปดาห์ที่ 18 ออม ฿1,800 (สะสม ฿17,100) ส่วนแผนสุ่ม seed `u01-2026` ได้ตัวคูณ 38 ออม ฿3,800. ชาเลนจ์ที่ระบบเสนอวันนี้คือ "งดเดลิเวอรี่ ฿120" วันนี้เธอทำ "งดกาแฟร้าน" สำเร็จ เก็บได้ ฿85 สตรีค **12 วัน** ป้ายไฟลุก. รูปเป้า Scan Quality **90**.

## Guardrails
- **ไม่ใช่ธนาคาร ไม่รับฝากเงินจริง และไม่ใช่คำแนะนำการลงทุน** — แสดง disclaimer ทุกผล
- จำนวนเงินเป็นค่าที่ผู้ใช้กรอก หรือค่าตัวอย่างใน `GOALS` / `CHALLENGES`
- แผน 52 สัปดาห์เป็นสูตรตัวอย่าง (สัปดาห์ที่ n × ฐาน) ไม่รับประกันว่าจะถึงเป้าถ้าฐานต่ำกว่าที่ `week52_fit_base()` คำนวณ
- รูปเป้าเป็นแรงบันดาลใจ ไม่ใช่ใบจองทัวร์หรือราคาจริง
- ประมวลผลบนเครื่องเป็นค่าเริ่มต้น ไม่ส่งยอดเงินออกนอกเครื่องโดยไม่ขอ
- ตัวอย่างและภาพปกทั้งหมดเป็นบุคคลสมมติ/ภาพวาด ไม่ใช้รูปคนจริง

## Shot list Reel (30 วิ)
- **0–3 วิ:** กระปุกแก้วใบเล็กเกือบว่าง ขึ้นข้อความ "ออมมาตั้งนาน… ทำไมยังไม่เห็นผล?"
- **3–10 วิ:** ตัดต่อเร่งตอนใช้ AI สร้างแอป / ใส่รูปภูเขาไฟฟุจิจำลองเป็นเป้า
- **10–22 วิ:**
  1. ยอดออมวิ่งจาก ฿0 กระปุกพองจนหยุดที่ 42% "กระปุกโตถึง 42%"
  2. ปัดไปแผน 52 สัปดาห์ สัปดาห์ที่ 18 ฿1,800 แล้วสลับโหมดสุ่มได้ ฿3,800
  3. กดชาเลนจ์ "งดกาแฟร้าน" เหรียญ +฿85 สตรีค 12 วัน
  4. โชว์ไมล์สโตน "อีก ฿3,600 จะถึง 50%" แล้วเด้งการ์ดแชร์
  5. โชว์ Safety Guard "ไม่ใช่ธนาคาร"
- **22–30 วิ:** "คอมเมนต์ SAVE รับแพ็กฟรี"
- ใช้ภาพประกอบ/ตัวละครสมมติเท่านั้น ไม่ใช้รูปคนจริง ใบเสร็จจริง หรือแบรนด์ธนาคารจริง
