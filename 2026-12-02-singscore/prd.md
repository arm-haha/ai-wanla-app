# PRD — SingScore (ร้องคาราโอเกะให้คะแนน + โค้ชเสียง)

## ปัญหา
อยากรู้ว่าตัวเองร้องเพี้ยนตรงไหน แต่แอปคาราโอเกะทั่วไปผูกกับเพลงลิขสิทธิ์ แถมไม่ได้บอกว่าควรวอร์มอัพยังไง หรือคีย์ที่ฮัมอยู่คือคีย์อะไร

## ผู้ใช้
คนอายุ 18–40 ที่ชอบร้องในห้องคาราโอเกะหรือที่บ้าน, คนที่อยากซ้อมเสียงโดยไม่ต้องโหลดเพลง, คู่เพื่อนที่อยากแข่งคะแนนกันเล่น ๆ, คนที่เคยเจ็บคอเพราะไม่วอร์ม

## Must-have (core demo / Reel)
1. **Pitch / timing score** ⭐ wow moment — ฮัมแบบฝึก → คะแนนเสียง 0–100 จากส่วนเบี่ยง cents, คะแนนจังหวะจาก ms และคะแนนรวม (น้ำหนัก 60/40)
2. **Key finder** — บอกคีย์และโหมดจากแบบฝึกหรือจากโน้ตที่ฮัม
3. **Warm-ups** — 4 ท่าต้นฉบับ: ลิปทริลล์, ไซเรนฮัม, ฮัมโด–ซอล, ลากสระ (รวม 100 วินาที)
4. **Duet battle card** — เทียบคะแนนรวมสองคน เป็นการ์ดแข่งสนุก
5. **Practice log** — บันทึกแบบฝึก คะแนน และความรู้สึก ดูคะแนนดีสุด

## Nice-to-have (retention)
6. **Original exercise library** — ScaleRun in C/G/F, BreathPulse, HumFifth, VowelHold Ah (ไม่มีเพลงลิขสิทธิ์)
7. **Band labels** — great / good / ok / try_again
8. **Own-track mode** — ผู้ใช้โหลดแทร็กของตนเองได้ในแอปจริง แต่แพ็กนี้ไม่แถมเพลง
9. **Share Card + Quota** — การ์ดคะแนนมีลายน้ำ ฟรี 3 ครั้ง/วัน
10. **Safety Guard** — เจ็บคอหรือฝืนเสียง = หยุด, ย้ำว่าไม่มีเนื้อเพลงลิขสิทธิ์ในแพ็ก

## หน้าจอ / Flow
Home (เลือกแบบฝึก + คะแนนล่าสุด) → วอร์มอัพ → ฮัม/ร้องแบบฝึกต้นฉบับ → **คะแนนเสียง+จังหวะ** → ดูคีย์ → การ์ดดูเอท → บันทึกการฝึก

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**พี่ต้อม 27 ปี** กรุงเทพฯ ฮัม **ScaleRun in C** ส่วนเบี่ยงเสียง **36 cents** จังหวะ **52 ms** ความมั่นใจ 0.95 → คะแนนเสียง **82** จังหวะ **74** รวม **79** ระดับ good คีย์ **C major**. เพื่อนสมมติ **น้องนีน่า** ได้รวม **72** → การ์ดดูเอท "พี่ต้อม นำ 7 แต้ม". วอร์มอัพแนะนำลิปทริลล์เป็นท่าแรก

## Design tokens
พื้นไนท์คลับ #111827, นีออนชมพู #F472B6, ม่วง #A78BFA, เหลืองคะแนน #FBBF24, ขาว; ฟอนต์ Kanit; มุมมน 20; ตัวเลขคะแนนรวมใหญ่ตัดกลางจอ ถ่ายขึ้น Reels ชัด (ฮัม → 79)

## Guardrails
- **ไม่มีเนื้อเพลงลิขสิทธิ์ในแพ็ก** — แบบฝึกเป็นสเกล/ฮัมต้นฉบับ ผู้ใช้ต้องใช้เสียงตนเองหรือแทร็กที่ตนมีสิทธิ์
- ไม่ใช่ครูสอนร้อง ไม่ใช่แพทย์ เจ็บคอหรือฝืนเสียงให้หยุด
- ความมั่นใจ < 0.6 ไม่ให้คะแนน ต้องฮัมใหม่
- คะแนนเป็นสูตรตัวอย่าง ไม่เทียบมาตรฐานประกวด
- ตัวอย่างและภาพปกเป็นบุคคลสมมติ ภาพวาด ไม่ใช้คนจริงหรือปกอัลบั้มจริง

## Shot list Reel (30 วิ · ใช้แบบฝึกต้นฉบับ/ภาพประกอบเท่านั้น ห้ามเปิดเพลงลิขสิทธิ์ ห้ามโชว์เนื้อเพลง ห้ามคนจริงที่ระบุได้)
- **0–3 วิ:** ไมค์ในห้อง ขึ้นข้อความ "ร้องไปแล้ว… แต่ได้น้อยไปแค่ไหน?"
- **3–10 วิ:** ตัดต่อเร่งตอนใช้ AI สร้างแอปจากแพ็กนี้
- **10–22 วิ:**
  1. กดวอร์มอัพลิปทริลล์ 30 วินาที
  2. ฮัมสเกลรัน C เข็มคะแนนวิ่งไป 79
  3. แยกเสียง 82 / จังหวะ 74
  4. ป้ายคีย์ C major
  5. การ์ดดูเอท นำเพื่อน 7 แต้ม
- **22–30 วิ:** "คอมเมนต์ SING รับแพ็กฟรี"
- ปิดท้ายมีข้อความเล็ก "แบบฝึกต้นฉบับ ไม่มีเนื้อเพลงลิขสิทธิ์ · เจ็บคอแล้วหยุด"
