# PRD — RipeRight (ถ่ายผลไม้ รู้เลยสุกพอดีไหม)

## ปัญหา
ซื้ออะโวคาโดมาผ่าครึ่งแล้วยังแข็ง ซื้อแตงโมลูกใหญ่กลับบ้านแล้วจืด มะม่วงวางลืมจนเละ ทุเรียนลูกละหลายร้อยก็ยังเลือกไม่เป็น ไม่รู้ว่าราคาต่อกิโลที่แม่ค้าบอกแพงไหม และซื้อผลไม้หลายอย่างพร้อมกันแล้วสุกพร้อมกันกินไม่ทัน ทิ้งเสียเงิน

## ผู้ใช้
คนทำงานที่แวะซื้อผลไม้ตลาดเย็น/ซูเปอร์, แม่บ้านที่ซื้อผลไม้ให้ทั้งบ้าน, สายรักสุขภาพที่กินอะโวคาโด/กล้วยทุกวัน, คนซื้อทุเรียนหน้าร้านที่กลัวโดนลูกอ่อน

## Must-have (core demo / Reel)
1. **Ripeness Meter** ⭐ wow moment — ถ่ายผลไม้ 1 รูป → AI แยกชนิดและอ่าน สีผิว / จุดกระ (`AiCueExtract`) → ผู้ใช้แตะเพิ่ม ความนิ่มเมื่อกด / กลิ่น (ไม่บังคับ) → มิเตอร์เข็มกวาด 0–100 + ป้าย ยังดิบ / ใกล้สุก / สุกพอดี / สุกเกิน + "กินได้ในอีก X วัน" (8 ผลไม้ไทย)
2. **Knock Test** — แตงโม/ทุเรียน: เคาะ 3 ครั้งใกล้ไมค์ → วัดความถี่เด่น (Hz) และเสียงก้อง (ms) → ทุ้มก้อง = สุก, แหลม = ดิบ, ตื้อทึบ = สุกเกิน แล้วรวมเข้ามิเตอร์ (ความมั่นใจเพิ่ม)
3. **Price Check** — ใส่ราคารวม + น้ำหนัก → ฿/กก. เทียบช่วงอ้างอิง ปรับตามในฤดู/นอกฤดู → ถูกผิดปกติ / ถูก / สมเหตุสมผล / แพง / แพงมาก
4. **Ripen Control** — อยากเร่ง (ถุงกระดาษ + กล้วย ×0.7 วัน) / ปกติ / อยากชะลอ (ตู้เย็นเฉพาะที่สุกแล้ว; กล้วยห้ามแช่ตอนยังไม่สุก; แตงโมไม่สุกต่อหลังตัด)
5. **Basket Eat Plan** — สแกนทุกลูกในตะกร้า → ตาราง 5–7 วันว่าวันไหนกินอะไร อะไรต้องรอ อะไรเลยช่วงอร่อยแล้ว + "กินอันนี้ก่อน"

## Nice-to-have (retention)
6. **Market Pick Checklist** — 4 คำถามต่อผลไม้ (เช่น แตงโม: จุดเหลืองที่ก้น, ลายชัด, เสียงทุ้ม, หนักมือ) → เลือกเลย / พอได้ / ข้าม
7. **Season Calendar** — เดือนนี้ผลไม้อะไรในฤดู (ถูกและหวานกว่า) + แจ้งเตือนต้นฤดูทุเรียน/มังคุด
8. **Fruit Diary** — หลังผ่าแล้วกด "พอดี / ดิบไป / สุกไป" → ความแม่นของการทาย % + เงินที่ใช้ไป (ใช้ปรับน้ำหนักส่วนตัวในอนาคต)
9. **Share Card** — การ์ด 4:5 "มิเตอร์ความสุก" ของลูกนั้น มีลายน้ำ + CTA
10. **Quota + Safety Guard** — ฟรี 5 สแกน/วัน; เห็นรา → stop "ทิ้งทั้งลูก"; ทุเรียน + แอลกอฮอล์ → warn; ไม่ใช่ผลไม้ → ให้ถ่ายใหม่

## หน้าจอ / Flow
Home (กล้อง) → ผลสแกน + มิเตอร์ → (แตงโม/ทุเรียน) Knock Test → เช็กราคา → เร่ง/ชะลอสุก → เพิ่มลงตะกร้า → Eat Plan → Pick Checklist / Season / Diary

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**พี่ต้อม 31 ปี กรุงเทพฯ** ซื้อผลไม้ตลาดเย็นวันที่ **14 ธ.ค. 2026**
- **อะโวคาโด**: สี 0.40 กระ 0.05 กด "แน่น" → **32/100 ยังดิบ รออีก 3 วัน** (กินได้ 17–18 ธ.ค.) → เร่งสุกใส่ถุงกระดาษกับกล้วย
- **มะม่วงน้ำดอกไม้**: สี 0.85 กด "นิ่มนิดหน่อย" กลิ่น "หอมแรง" → **75/100 สุกพอดี กินภายใน 2 วัน**
- **แตงโม 3.2 กก.**: สีอย่างเดียวได้ 53 "ใกล้สุก" → เคาะ **120 Hz ก้อง 180 ms → "เสียงทุ้มก้อง สุกกำลังดี"** → มิเตอร์ขึ้น **66/100 สุกพอดี**; ราคา ฿80 = **฿25/กก. สมเหตุสมผล (+11%) ในฤดู**
- Eat Plan: วันนี้–พรุ่งนี้ กินมะม่วง + แตงโม, อะโวคาโดรอถึง 17 ธ.ค. → **"กินมะม่วงก่อน"**
- Diary 4 ครั้ง ทายถูก **3/4 (75%)** ใช้ไป ฿405

## Design tokens
พื้นครีมมะม่วง #FFF7E6, เขียวดิบ #6BBF59, เหลืองสุก #FFC93C, ส้มพอดี #FF8A3D, น้ำตาลสุกเกิน #8B5A2B, ม่วงเข้มตัวอักษร #2B2140, แดงเตือน #DC2626; ฟอนต์ Kanit/Noto Sans Thai; มุมมน 24; มิเตอร์ครึ่งวงกลมไล่สี เขียว→เหลือง→ส้ม→น้ำตาล เข็มกวาดพร้อมเสียง "ติ๊ง"; คลื่นเสียงเต้นตอน Knock Test

## Reel shot list (30 วิ · ถ่ายผลไม้และมือ ไม่ต้องเห็นหน้า)
- **0–3 วิ:** ผ่าอะโวคาโดแล้วแข็งโป๊ก ขึ้นข้อความ "ซื้อผลไม้แล้วดิบ/เละ บ่อยไหม?"
- **3–10 วิ:** ตัดต่อเร่งตอนใช้ AI สร้างแอปจากแพ็กนี้
- **10–22 วิ:**
  1. ส่องกล้องที่อะโวคาโด → เข็มมิเตอร์กวาดไปที่ 32 "ยังดิบ รออีก 3 วัน"
  2. ส่องมะม่วง → 75 "สุกพอดี" คอนเฟตตีสีเหลือง
  3. เคาะแตงโมใกล้มือถือ คลื่นเสียงเต้น → "เสียงทุ้มก้อง สุกกำลังดี" มิเตอร์ขยับขึ้น
  4. ใส่ ฿80 / 3.2 กก. → ป้ายเขียว "฿25/กก. สมเหตุสมผล"
  5. ตาราง Eat Plan สไลด์ขึ้น "กินมะม่วงก่อน"
- **22–30 วิ:** "คอมเมนต์ RIPE รับแพ็กฟรี"
- ปิดท้ายข้อความเล็ก "ค่าประมาณ · เห็นราหรือกลิ่นผิดปกติ ห้ามกิน"

## Guardrails
- **ค่าประมาณ ไม่ใช่การรับรองความปลอดภัยของอาหาร** — disclaimer ในทุกผล; เห็นรา/กลิ่นบูด/เนื้อเละผิดปกติ → stop ทิ้งทั้งลูก
- ราคาอ้างอิงเป็น **ค่าตัวอย่าง** ไม่ใช่ราคาตลาดจริง ไม่จัดอันดับหรือกล่าวหาร้าน/แม่ค้า ใช้คำว่า "ลองต่อราคา/เทียบร้านอื่น"
- Knock Test ประมวลผลเสียงบนเครื่อง ไม่อัดเก็บ ไม่ส่งขึ้นเซิร์ฟเวอร์
- รูปผลไม้ลบหลังประมวลผล (≤ 1 ชม.) ไม่เอาไปเทรน ไม่ต้องใช้รูปคน
- ทุเรียน: เตือนเรื่องแอลกอฮอล์ และผู้ป่วยเบาหวาน/โรคไตควรกินแต่น้อย (ไม่ใช่คำแนะนำแพทย์)
- ตัวอย่างและภาพปกเป็นบุคคลสมมติ/ภาพวาด

## Metrics
D1 สแกน ≥ 3 ลูก/คน, ใช้ Knock Test ≥ 30% ของคนที่สแกนแตงโม, บันทึก Diary ≥ 20% ของการสแกน, กลับมาใช้ใน 7 วัน ≥ 35%, แชร์การ์ด ≥ 8%
