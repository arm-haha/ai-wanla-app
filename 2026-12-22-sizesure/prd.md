# PRD — SizeSure (ถ่าย 2 รูป รู้ไซซ์ก่อนกดสั่ง)

## ปัญหา
คนไทยซื้อเสื้อผ้าออนไลน์กันทุกเดือน แต่ "ไซซ์ไม่พอดี" คือเหตุผลอันดับหนึ่งที่ต้องเปลี่ยนคืน เสียค่าส่งสองรอบ รอเป็นสัปดาห์ หรือหลายร้านไม่รับคืนเลย ตารางไซซ์ของแต่ละร้านไม่เหมือนกัน บางร้านเป็นนิ้ว บางร้านเป็นเซนติเมตร บางร้าน "วัดแบบวางราบ" (อก 18 นิ้ว = รอบอก 36 นิ้ว) แต่คนอ่านเทียบกับรอบอกตัวเองตรง ๆ แล้วสั่งเล็กไปสองไซซ์ ที่บ้านส่วนใหญ่ก็ไม่มีสายวัด หรือวัดเองแล้วไม่แน่ใจว่าวัดถูกจุด ช่วงปลายปีอยากซื้อเสื้อผ้า/รองเท้าเป็นของขวัญปีใหม่ให้พ่อแม่หรือแฟน ก็ไม่รู้ไซซ์เขา

## ผู้ใช้
สายช้อปออนไลน์ 18–45 ปี (Shopee/Lazada/TikTok Shop/ร้าน IG), คนรูปร่างไม่ตรงไซซ์มาตรฐาน (อกเล็กสะโพกใหญ่ ฯลฯ), คนซื้อของขวัญให้คนในครอบครัว, แม่ค้าที่อยากช่วยลูกค้าเลือกไซซ์ (แชร์ลิงก์วัดตัว), คนซื้อรองเท้าออนไลน์

## Must-have (core demo / Reel)
1. **Photo Measure** ⭐ wow moment — พิมพ์ส่วนสูง → ถ่ายหน้า + ข้าง (ไกด์โครงร่างบนจอ, เช็กแสง/เต็มตัว/ท่า/เสื้อผ้า/A4 → `photo_check`) → AI วัดความกว้างหน้าและความหนาด้านข้างเป็นพิกเซล (`AiBodyMeasure`) → สเกลจากส่วนสูง ตรวจซ้ำด้วย A4 → **รอบ = เส้นรอบวงรี (Ramanujan) × ค่าปรับ − เผื่อเสื้อผ้า** → รอบอก เอว สะโพก ไหล่ แขน ขาใน ±2 ซม. (`measure_body`, `ellipse_circ`); แตะแก้ด้วยสายวัดได้ (`override`)
2. **Size Chart Reader** — แคปตารางไซซ์ของร้าน → A2 อ่านเป็น JSON (`AiChartRead`) → แปลงนิ้ว ×2.54, **วางราบ ×2 เฉพาะรอบ (อก/เอว/สะโพก) ไม่คูณความยาว**, ค่าเดี่ยว → ช่วง (`normalize_chart`) แสดงป้าย "คูณ 2 ให้แล้ว"
3. **Size Pick + Fit Meter** — เลือกประเภท (เสื้อ/เดรส/กางเกง) ทรง (สลิม/ปกติ/โอเวอร์ไซซ์) ความยืด (ไม่ยืด/ยืดนิด/ยืดมาก) → ไซซ์แนะนำ + ไซซ์สำรอง + มิเตอร์รายจุด พอดี/คับ/หลวม พร้อมค่าเผื่อ (ease) เป็น ซม. + ความมั่นใจ + คำแนะนำภาษาคน "อยู่ระหว่าง S กับ M — แนะนำ M เพราะ S คับที่สะโพก" (`recommend`)
4. **Shoe Size on A4** — วางเท้าบนกระดาษ A4 ถ่ายจากด้านบน → ความยาวเท้า (A4 ยาว 29.7 ซม. เป็นไม้บรรทัด) + เผื่อ 0.5 ซม. ปัดขึ้นครึ่งเบอร์ → EU / US ผู้หญิง / US ผู้ชาย / UK + หน้าเท้าแคบ/ปกติ/กว้าง (`shoe_size`)
5. **Privacy & Safety Guard** — ต้องใส่เสื้อผ้า (A1 ตรวจ nudity → stop), อายุ < 18 ไม่ใช้รูป (กรอกสายวัดได้), วัดเฉพาะตัวเอง/คนที่ยินยอม, หลายคนในรูป = เตือน, เสื้อหลวม = เตือน ±5 ซม., ไม่มีคะแนนหุ่น/BMI, รูปลบทันทีหลังวัด (`privacy_check`, `safety_guard`)

## Nice-to-have (retention / viral)
6. **Size Passport (ทั้งบ้าน)** — การ์ดไซซ์ประจำตัว: ไซซ์เสื้อมาตรฐาน, เอวยีนส์เป็นนิ้วแบบที่ร้านไทยใช้, เบอร์รองเท้า, ตัวเลข cm/นิ้ว (ซ่อนได้) โปรไฟล์ได้หลายคน (`passport`)
7. **Gift Size Helper** — ซื้อของขวัญปีใหม่ให้พ่อแม่/แฟนจาก passport ที่เขาแชร์มา (แชร์เฉพาะไซซ์ ไม่แชร์ตัวเลข) โอเวอร์ไซซ์ขยับขึ้น 1 ไซซ์ + ทิปเรื่องเปลี่ยนไซซ์ (`gift_pick`)
8. **Return-Risk Check** — ก่อนกดสั่ง: ความเสี่ยงต่ำ/กลาง/สูง จากความมั่นใจ ระหว่างไซซ์ จุดคับ/หลวม และรีวิว "ไซซ์เล็ก/ใหญ่กว่าปกติ" + สิ่งที่ควรทำ (`return_risk`)
9. **Measurement Log** — บันทึกการวัด ดูการเปลี่ยนแปลงแบบเป็นกลาง ซ่อนตัวเลขได้ เตือนวัดใหม่ทุก 3 เดือนหรือก่อนช้อปใหญ่ (11.11/12.12) (`log_summary`)
10. **Share Card / Reel + Quota** — การ์ดไซซ์ / ก่อน-หลัง / มิเตอร์ 1080×1350 (ไม่มีตัวเลขสัดส่วน ไม่มีรูปตัว) (`share_card`) + Reel 9:16 15–30 วิ 6 ช็อต (`reel_plan`); ฟรีวัด 3 ครั้ง/วัน (`quota`)

## หน้าจอ / Flow
Home → Privacy gate (อายุ + วัดตัวเองไหม + ยืนยันใส่เสื้อผ้า) → ส่วนสูง → กล้องหน้า (โครงร่างไกด์ + นับถอยหลัง 5 วิ วางมือถือพิงผนัง) → กล้องข้าง → Photo QA → **Measurements** (wow: เส้นวัดวิ่งบนภาพโครงร่าง) → แคปตารางร้าน / ใช้ตารางมาตรฐาน → **Size Pick + Fit Meter** → Return-Risk → Passport · เมนูรอง: รองเท้า A4, Gift, Log, Share

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**พี่แพรว 28 ปี กรุงเทพฯ สูง 160 ซม.** เสื้อยืดพอดีตัว รูปคุณภาพ 97/100 A4 สเกลตรงกับส่วนสูง
- วัดได้: รอบอก 84.6 · เอว 68.0 · สะโพก 93.6 · ไหล่ 37.0 · แขน 54.0 · ขาใน 72.0 ซม. (±2)
- ร้านเสื้อครอป (นิ้ว, วางราบ): อก M 18" → รอบ 91.4 ซม. → **แนะนำ M** เผื่อ 6.8 ซม. พอดี ความมั่นใจสูง (ถ้าอ่านตารางตรง ๆ จะคิดว่าต้องใส่ไซซ์ใหญ่สุด)
- ร้านเดรสลินิน (ซม., วัดตัว): **อยู่ระหว่าง M กับ S — แนะนำ M เพราะ S คับที่สะโพก** · Return-Risk สูงถ้ารีวิวบอกไซซ์เล็ก
- ร้านยีนส์ (นิ้ว): สลิม ผ้ายืดนิด → **27** พอดีทุกจุด (ผ้าไม่ยืด → 27 คับสะโพก)
- เท้าบน A4: 23.5 ซม. → รองเท้า 24.0 ซม. = **EU 38** / US-W 7 / UK 4.5 หน้าเท้าปกติ
- Passport: เสื้อ S (ตารางมาตรฐาน) · ยีนส์ 27" · รองเท้า 38 · Gift แบบโอเวอร์ไซซ์ → M

## Reel shot list (20 วิ · ผู้สร้างคลิปใส่ชุดออกกำลังกายพอดีตัว หรือใช้หุ่นโครงร่างกราฟิก)
- **0–3 วิ:** แกะกล่องพัสดุ เสื้อคับจนติดไหล่ ข้อความ "สั่งออนไลน์ ไซซ์ไม่เคยพอดี?"
- **3–6 วิ:** ตัดต่อเร่งตอนสร้างแอปด้วย AI จากแพ็กนี้ (โชว์ prompts.md)
- **6–10 วิ:** ถ่ายหน้า + ข้าง → เส้นสายวัดสีเหลืองพันรอบตัวบนโครงร่าง ตัวเลขเด้ง 84.6 / 68.0 / 93.6
- **10–14 วิ:** แคปตารางร้าน "อก 18 นิ้ว" → ป้าย "วางราบ ×2 = 91.4 ซม." → ไฮไลต์ M (beat drop)
- **14–18 วิ:** มิเตอร์ พอดี/คับ/หลวม + เท้าบน A4 → EU 38 + Passport การ์ด
- **18–20 วิ:** CTA "คอมเมนต์ SIZE รับแพ็กฟรี"
- ตัวอักษรเล็กท้ายคลิป: "ค่าประมาณ ±2 ซม. · ใส่เสื้อผ้าพอดีตัวเท่านั้น · รูปลบทันทีหลังวัด"

## Risks & traps
| ความเสี่ยง / กับดัก | ผลกระทบ | วิธีลด |
|---|---|---|
| **กับดัก:** ตารางร้าน "วัดแบบวางราบ" แต่ผู้ใช้/แอปเทียบตรง ๆ | แนะนำเล็กไป 2 ไซซ์ คนด่าในคอมเมนต์ | A2 ต้องระบุ method; ถ้าค่าอก < 60 ซม. สำหรับผู้ใหญ่ → สันนิษฐานว่าวางราบและถามยืนยัน; ×2 เฉพาะรอบ ไม่คูณความยาว |
| **กับดัก:** ให้ AI "เดาตัวเลขจากรูป" ตรง ๆ ด้วย LLM | ตัวเลขมั่ว ไม่สม่ำเสมอ | AI ทำแค่หาเส้นขอบ/landmark เป็นพิกเซล ส่วนคณิตศาสตร์ (สเกล วงรี ค่าปรับ) เป็นโค้ด deterministic ทดสอบได้ |
| เสื้อผ้าหลวม/มุมกล้องเอียง | คลาด ±5 ซม. ขึ้นไป | photo_check บังคับชุดพอดีตัว, ไกด์มือถือระดับเอว, A4 ตรวจสเกล, margin แสดงชัด, แก้ด้วยสายวัดได้ |
| รูปโป๊/รูปเด็ก/รูปคนอื่น | ผิดกฎหมาย ความเป็นส่วนตัว | A1 nudity → stop, < 18 ห้ามใช้รูป (กรอกสายวัด), consent ตัวเอง, ประมวลผลบนเครื่องเป็นหลัก ลบรูปทันที เก็บแค่ตัวเลข |
| Body shaming / ความรู้สึกผู้ใช้ | ผู้ใช้รู้สึกแย่ ดราม่า | ไม่มี BMI/น้ำหนัก/คะแนนหุ่น, ภาษากลาง "ไซซ์นี้คับที่สะโพก" (โทษเสื้อ ไม่โทษตัว), ซ่อนตัวเลขได้, การ์ดแชร์ไม่มีตัวเลข |
| ตารางรองเท้าแต่ละแบรนด์ไม่ตรงกัน | ซื้อผิดครึ่งเบอร์ | แสดงความยาวเท้าเป็น ซม. เป็นหลัก (เทียบกับ "ซม." ในตารางแบรนด์) + ป้าย "ประมาณ" |

## Guardrails
- ใส่เสื้อผ้าพอดีตัวเสมอ ห้ามถ่ายแบบไม่ใส่เสื้อผ้า/ชุดชั้นในอย่างเดียว
- อายุต่ำกว่า 18 ปีไม่ใช้การวัดจากรูป ผู้ปกครองวัดด้วยสายวัดแล้วกรอกตัวเลข
- วัดได้เฉพาะตัวเอง หรือคนที่อยู่ด้วยและยินยอม ห้ามใช้รูปคนอื่นจากโซเชียล
- ไม่ให้คะแนนรูปร่าง ไม่คำนวณ BMI ไม่แนะนำลดน้ำหนัก
- ไม่ใช้แทนการวัดทางการแพทย์หรือการตัดชุดที่ต้องเป๊ะ
- ทุกตัวอย่างในแพ็กเป็นบุคคลและร้านสมมติ

## Metrics
- ความคลาดเคลื่อนเฉลี่ยเทียบสายวัด (เป้า ≤ 2.5 ซม. เมื่อใส่ชุดพอดีตัว)
- เวลาจากเปิดแอปถึงเห็นไซซ์แนะนำ (เป้า < 90 วินาที)
- % ผู้ใช้ที่แคปตารางร้านอย่างน้อย 1 ครั้งต่อสัปดาห์ (เป้า 35%)
- อัตราเปลี่ยนคืนเพราะไซซ์ที่ผู้ใช้รายงานเอง (เป้า ลดลงครึ่งหนึ่ง)
- จำนวน Passport ที่แชร์ให้ครอบครัว / share card ที่ติดลายน้ำ SizeSure
