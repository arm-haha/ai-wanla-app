# PRD — FixMate (ของพังซ่อมเอง) · AI วันละแอป 2026-10-27

**Hook:** "ถ่ายของพัง 1 รูป → AI บอกว่าเสียตรงไหน ซ่อมเองได้ไหม ใช้ของอะไร กี่บาท — หรืออันไหนห้ามแตะ"

## ผู้ใช้
คนเช่าคอนโด/หอ/บ้านหลังแรก ซ่อมไม่เป็น กลัวโดนช่างฟันราคา (18–35)

## ฟีเจอร์
### Must-have (core demo)
1. **Snap & Diagnose** — รูป/คลิป 5 วิ → การ์ดอาการ + pin บนรูป + สาเหตุเรียง % + ความยาก 1–5 + เวลา
2. **Safety Gate** — hazard tags (แก๊ส, รอยไหม้, ประกายไฟ, น้ำใกล้ไฟ, ฝ้าย้อย…) → จอแดง "อย่าซ่อมเอง" + ขั้นตอนปลอดภัย; ความมั่นใจ < 0.6 → ขอรูปเพิ่ม
3. **Fix Steps** — การ์ดทีละขั้นพร้อมลูกศรบนรูป จับเวลา ติ๊กเสร็จ % ความคืบหน้า
4. **Parts & Tools List** — ชื่ออะไหล่ไทย + คำค้นสำหรับร้าน/แอปช้อป, ติ๊กเครื่องมือที่มีแล้ว ราคาให้ผู้ใช้กรอก/ยืนยัน
5. **DIY vs เรียกช่าง** — เทียบค่าของ+เครื่องมือที่ขาด กับใบเสนอช่าง → verdict + "ประหยัด ฿…" + ปุ่มสร้างข้อความ LINE หาช่าง
### Nice-to-have (retention)
6. **Home Care Calendar** — ล้างฟิลเตอร์แอร์ ล้างท่อ เทสต์เครื่องตรวจควัน เตือนเกินกำหนด
7. **Saved Money Tally + Badge** — ยอดประหยัดสะสม, badge "มือใหม่ซ่อมเป็น" / "ช่างประจำบ้าน"
8. **Before/After Reel Card** — ก๊อกหยด 130 ลิตร/เดือน → 0
9. **ถามต่อ "ติดตรงนี้"** — แชตต่อจากขั้นที่ค้าง แนบรูปใหม่

## Wow moment
จอแบ่งครึ่ง: ช่าง ฿500 vs ซ่อมเอง ฿145 → ตัวเลข "ประหยัด ฿355" เด้ง + น้ำหยุดหยดจริงในคลิป

## หน้าจอ
Home (กล้องใหญ่ + Care due) → Diagnose → Safety (ถ้าแดง) → Verdict → Parts → Steps → Done/Reel Card · Calendar · Profile (เครื่องมือที่มี)

## Demo fixture (ข้อมูลสมมติ)
ต้น คอนโดชั้น 12 มีแค่ไขควง · ก๊อกหยด 60 หยด/นาที ≈ 130 ลิตร/เดือน · ยางรอง ฿25 + ประแจ ฿120 = ฿145 vs ช่าง ฿500 → ประหยัด ฿355 · ชักโครก ฿120 vs ฿600 → ฿480 · รวม ฿835 · ปลั๊กไหม้ → STOP · แอร์หยด conf 0.55 → ขอรูปเพิ่ม · ฟิลเตอร์แอร์เกิน 17 วัน
(ราคาเป็นตัวอย่าง ไม่ใช่ราคาตลาดจริง)

## Guardrails
ไม่ให้ขั้นตอน DIY กับงานไฟฟ้าตู้หลัก แก๊ส น้ำยาแอร์ โครงสร้าง; ทุกการ์ดมีปุ่ม "ไม่แน่ใจ → เรียกช่าง"; logic ความปลอดภัย/ราคาอยู่ฝั่งโค้ด ไม่ให้ LLM ตัดสิน
