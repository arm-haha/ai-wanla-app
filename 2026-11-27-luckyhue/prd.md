# PRD — LuckyHue (สีมงคลประจำวัน + วอลเปเปอร์สายมู)

## ปัญหา
อยากรู้สีมงคลตามวันเกิด แล้วไม่รู้จะหยิบเสื้อตัวไหนจากตู้ให้เข้ากับสีนั้น หาวอลเปเปอร์สวย ๆ ที่เข้าธีมก็ยาก และหลายแอปพูดเหมือนหมอดูจริง ทั้งที่สีประจำวันมีหลายสำนัก

## ผู้ใช้
คนอายุ 18–40 ที่ชอบสายมูแบบขำ ๆ, คนที่เลือกชุดเช้าไม่เป็น, คนที่อยากได้วอลเปเปอร์สีประจำวัน, คนที่อยากแชร์สีมงคลในกรุ๊ปเพื่อน

## Must-have (core demo / Reel)
1. **Color by birth day** ⭐ wow moment — ใส่วันเกิดหรือวันในสัปดาห์ → ได้สีมงคล รหัสสี และคำอวยพรสั้น (วันศุกร์ = ฟ้า #38BDF8)
2. **Outfit mixer** — ถ่ายตู้เสื้อผ้า แล้วจับคู่ชิ้นที่เข้าสีมงคลหรือสีกลาง พร้อมคะแนนและคำอธิบาย
3. **Wallpaper maker** — วอลเปเปอร์ตามพาเลตต์สีมงคล มีคำอวยพรและลายน้ำ ขนาด 1080×1920 / 1080×1080
4. **Weekly calendar** — สีทั้ง 7 วันในสัปดาห์ ไฮไลต์วันเกิด
5. **For-fun disclaimer** — ทุกผลบอกว่าไม่ใช่หมอดู ไม่รับประกันโชคชะตา และแหล่งที่มาของสีอาจต่างกัน

## Nice-to-have (retention)
6. **Wednesday night toggle** — สลับสีพุธกลางวันเขียว / กลางคืนแสด
7. **Today badge** — ถ้าวันนี้ตรงวันเกิด ติดป้าย "วันนี้สีมงคลของคุณ"
8. **Color library** — ดูทั้ง 7 วันพร้อมรหัสสี
9. **Share Card + Quota** — การ์ดสีมีลายน้ำ ฟรี 3 ครั้ง/วัน
10. **Safety Guard** — เตือนถ้าจะใช้สีไปตัดสินใจเรื่องเงิน สุขภาพ หรือความสัมพันธ์

## หน้าจอ / Flow
Home (วันเกิด + สีวันนี้) → ใส่วันเกิด → **การ์ดสีมงคล** → ถ่ายตู้เสื้อผ้า → มิกซ์ชุด + คะแนน → วอลเปเปอร์ → ปฏิทินสัปดาห์ → การ์ดแชร์

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**พี่เมย์ 28 ปี** กรุงเทพฯ เกิด **1 พ.ค. 1998 วันศุกร์**. วันนี้ 27 พ.ย. 2026 ก็วันศุกร์ → สีมงคล **ฟ้า #38BDF8** คำอวยพร "ขอให้วันนี้สบายและสิ่งดี ๆ เข้ามา". ถ่ายตู้เสื้อผ้าคุณภาพ **88** เจอ 5 ชิ้น → มิกซ์เสื้อเชิ้ตขาว + กระโปรงฟ้า + กระเป๋าเบจ คะแนน **67** ผล **แมตช์**. วอลเปเปอร์ 1080×1920. ปฏิทินสัปดาห์เริ่ม 23 พ.ย. ไฮไลต์วันศุกร์

## Design tokens
พื้นฟ้าอ่อน #E0F2FE, สีฟ้าหลัก #38BDF8, กรม #1F2937, ครีม #FFFBEB, ชมพู #EC4899; ฟอนต์ Kanit; มุมมน 20; การ์ดสีใหญ่ตัดกลางจอ ถ่ายขึ้น Reels ชัด (ตู้เสื้อผ้า → ชุดฟ้า + ฿ไม่มี โชว์สีฟ้าเต็มจอ)

## Guardrails
- **เพื่อความสนุก ไม่ใช่หมอดู** — ไม่รับประกันโชค ห้ามแนะนำการเงิน สุขภาพ ความสัมพันธ์จากสี
- แมปสีเป็นชุดตัวอย่าง แหล่งที่มาอาจต่างกัน โดยเฉพาะวันพุธ
- ความมั่นใจ < 0.6 ไม่นับชิ้นในตู้ ต้องถ่ายใหม่หรือเลือกเอง
- ตัวอย่างและภาพปกเป็นบุคคลสมมติ/ภาพวาด ไม่ใช้คนจริง

## Shot list Reel (30 วิ · ใช้ภาพประกอบ/เสื้อผ้าจำลองเท่านั้น ห้ามคนจริง ห้ามตู้จริงที่ระบุที่อยู่)
- **0–3 วิ:** ตู้เสื้อผ้าเปิดอยู่ ขึ้นข้อความ "เกิดวันศุกร์ วันนี้ควรใส่สีอะไร?"
- **3–10 วิ:** ตัดต่อเร่งตอนใช้ AI สร้างแอปจากแพ็กนี้
- **10–22 วิ:**
  1. ใส่วันเกิด บัตรสีฟ้าเด้ง "สีมงคลวันศุกร์คือสีฟ้า"
  2. ถ่ายตู้ กระโปรงฟ้าถูกเลือกอัตโนมัติ
  3. คะแนนชุด 67 ป้ายแมตช์
  4. วอลเปเปอร์สีฟ้ามีคำอวยพร
  5. ปฏิทินสัปดาห์ไฮไลต์วันศุกร์
- **22–30 วิ:** "คอมเมนต์ HUE รับแพ็กฟรี"
- ปิดท้ายมีข้อความเล็ก "เพื่อความสนุก ไม่ใช่หมอดู"
