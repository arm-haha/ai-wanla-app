## วิธีใช้กับ AI codegen (เช้านี้)

1. เปิด `prompts.md` ส่วน **A) Master prompt** วางเป็นคำสั่งหลัก
2. แนบบริบท: `prd.md` + `schemas.json` + `examples.json`
3. สั่งให้ `npm run dev` ผ่านและ **happy path ด้วยข้อมูลตัวอย่างจบก่อน** (น้ำหวาน → 25 🌧️ → การ์ด → หายใจ → 75 ⛅ → สวนอารมณ์ → แพทเทิร์น → แชร์)
4. ส่วน **D** ทำ `lib/mood.ts` + เทสต์ (หัวใจคลิป) · ส่วน **E** ทำ safety **ก่อน** UI
5. ค่อยต่อไมค์จริง / LLM (ส่วน **F** + **M**) · ก่อนถ่ายรันส่วน **K (QA)**

เป้าเวลา: ราว 7 ชม. (ตารางใน `prd.md` §20)

## กฎช่อง (อย่าพลาดตอนถ่าย)

- เปิดคลิปด้วย **หน้าเหนื่อยในห้องมืด + "วันนี้ใจฉันสีอะไร?"** ภายใน 3 วินาที
- โชว์อย่างน้อย **4 ฟีเจอร์** (Voice → Aura, Comfort/หายใจ/เช็กใจ, Garden, Triggers) + การ์ดแชร์แวบเดียว
- ใช้ **ข้อมูลตัวอย่างน้ำหวาน** (ตัวละครสมมติ) หรือเรื่องของตัวเองที่ไม่เป็นความลับ
- พูดว่า "สมุดบันทึกอารมณ์" / "ช่วยให้เห็นใจตัวเอง" **ห้าม**พูด "รักษาเครียด" "แทนจิตแพทย์" "วัดซึมเศร้า"
- caption ก่อน/หลังต้องมี "(จากคำที่คุณเล่าเอง)"
- **ห้าม**เอา Support Sheet (หน้าสายด่วน) มาทำเป็นมุก
- CTA: คอมเมนต์คำว่า **「สีใจ」**
