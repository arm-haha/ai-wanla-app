## 1) สรุปหนึ่งบรรทัด

สมุดบันทึกอารมณ์ด้วยเสียง: กดค้างพูดระบายเรื่องวันนี้ 30 วินาที → คำพูดลอยเข้าไปในลูกแก้ว → ลูกแก้วเปลี่ยนเป็น "สีใจ" + พยากรณ์อากาศใจ (☀️⛅☁️🌧️⛈️) → ได้การ์ดปลอบใจ + หายใจ 60 วิ → เช็กใจอีกรอบเห็นสีเปลี่ยน → ทุกวันกลายเป็นลูกแก้วในสวนอารมณ์ และแอปบอกว่า "อะไรชาร์จใจ / ดูดพลังคุณ"

**ฮุค Reel:** พูดระบายแค่ 30 วิ… AI บอกว่าวันนี้ใจคุณสีอะไร 🔮

## 2) ปัญหา

- คนทำงาน/นักศึกษาเครียดสะสมทุกวัน แต่ไม่มีที่ระบายสั้นๆ ที่ไม่ต้องคุยกับใคร
- แอปไดอารี่ต้องพิมพ์ยาว เลยเลิกใช้ภายใน 3 วัน · แอปเลือกอีโมจิอารมณ์ก็ตื้นเกินไป ไม่บอกอะไรกลับมา
- ไม่รู้ตัวว่าอะไรทำให้อารมณ์ดีหรือแย่ซ้ำๆ (งาน, นอนน้อย, รถติด, เจอเพื่อน, ออกกำลัง)

## 3) ทำไมไวรัลบน Reels

- **Visual wow ชัด:** คำพูดลอยเข้าลูกแก้วแล้วเปลี่ยนสี บนพื้นกลางคืนมืด = ภาพสวย จับตาในวินาทีแรก
- **ทุกคนอินได้:** "วันนี้เหนื่อยมาก" เป็นประโยคที่ทุกคนเคยพูด → คอมเมนต์ "ของฉันน่าจะ ⛈️" = engagement
- **Before/after:** 25 🌧️ → หายใจ 1 นาที → 75 ⛅ สีเปลี่ยนจากม่วงหม่นเป็นเขียวมิ้นต์
- **การ์ดแชร์สวยและไม่โป๊ข้อมูล:** แชร์แค่สีใจ + อากาศ ไม่ต้องแชร์สิ่งที่พูด → คนกล้าลงสตอรี่
- **กลับมาเปิดทุกคืน:** สตรีค + สวนอารมณ์ค่อยๆ เต็ม + แพทเทิร์นเริ่มโผล่หลัง 3 วัน
- **ภาษาไทยจริง:** ตัวตัดอารมณ์ภาษาไทยทำงานในเครื่องได้เลยแม้ไม่มี AI key

## 4) เป้าหมาย / ไม่ใช่เป้าหมาย

**เป้าหมาย**
- เล่าเสร็จ → เห็นสีใจภายใน ≤ 3 วินาที (lexicon ในเครื่อง)
- 5 ฟีเจอร์ must-have ใช้ได้ครบด้วยข้อมูลตัวอย่าง "น้ำหวาน" แบบ deterministic (ถ่ายกี่เทคก็ได้เลขเดิม)
- ใช้ได้ฟรี ไม่ต้องล็อกอิน ข้อมูลอยู่ในเครื่อง ไม่เก็บไฟล์เสียงเป็นค่าเริ่ม
- มีระบบความปลอดภัย: เจอคำเสี่ยง → ไม่ให้คะแนน แสดงช่องทางขอความช่วยเหลือทันที

**ไม่ใช่เป้าหมาย**
- ไม่วินิจฉัยโรคซึมเศร้า/วิตกกังวล ไม่ใช่แอปบำบัด ไม่ใช้คำว่า "รักษา"
- ไม่วิเคราะห์ "น้ำเสียง" (tone/pitch) เพื่อเดาอารมณ์ — ใช้เฉพาะคำที่ผู้ใช้พูดเอง (โปร่งใส อธิบายได้)
- ไม่มีฟีดโซเชียล ไม่มีบัญชี ไม่มี backend database

## 6) User stories

1. ในฐานะคนเหนื่อยหลังเลิกงาน ฉันอยากกดค้างแล้วพูดเลย ไม่ต้องพิมพ์ เพื่อระบายได้ทันที
2. ฉันอยากเห็นว่าวันนี้ใจฉัน "สีอะไร / อากาศแบบไหน" แบบเข้าใจใน 1 วิ
3. ฉันอยากได้คำปลอบที่ไม่เฟก + สิ่งเล็กๆ ทำได้ใน 1 นาที
4. ฉันอยากเห็นเดือนนี้ทั้งเดือนเป็นสีๆ ว่าช่วงไหนหนัก
5. ฉันอยากรู้ว่าอะไรทำให้ใจดีขึ้นหรือแย่ลงซ้ำๆ
6. ฉันอยากแชร์สีใจลงสตอรี่โดยไม่ต้องเผยสิ่งที่พูด
7. ถ้าฉันพูดอะไรที่น่าเป็นห่วง ฉันอยากเห็นทางขอความช่วยเหลือทันที ไม่ใช่คะแนน

## 8) กติกาอารมณ์ (`lib/mood.ts` — pure, deterministic)

ใช้ทั้งโหมดไม่มี key และเป็นตัว "ให้คะแนนสุดท้าย" เสมอ (LLM ช่วยแค่สรุป/คำปลอบ และเสนอ term เพิ่ม แต่สูตรคะแนนเดียวกัน)

1. **Lexicon** `examples.json → lexicon_th` (39 คำ, `th-2026.10`): term, valence (−3..3), energy (−3..3), theme
2. **Match:** เรียง term ยาว → สั้น หา occurrence แรกที่ไม่ทับช่วงที่ใช้ไปแล้ว นับ 1 ครั้งต่อ term
3. **Negation:** 3 ตัวอักษรก่อน term = `ไม่` และ term ไม่ได้ขึ้นต้นด้วย `ไม่` → valence กลับเครื่องหมาย, energy = 0
4. `v = clamp(Σvalence, −8, 8)` · `energy = round((clamp(Σenergy, −8, 8) + 8) / 16 × 10)`
5. `score = round((v + 8) / 16 × 100)` (round = `floor(x + 0.5)`)
6. **Quadrant:** v = 0 → neutral · v > 0 → energy ≥ 6 ? bright : calm · v < 0 → energy ≥ 6 ? tense : low
7. **อากาศใจ:** ≥80 ☀️ แดดจ้า · 60–79 ⛅ ฟ้าโปร่ง · 41–59 ☁️ เมฆครึ้ม · 21–40 🌧️ ฝนพรำ · 0–20 ⛈️ พายุเข้า
8. **สี:** bright `#FACC15` · calm `#34D399` · tense `#FB7185` · low `#818CF8` · neutral `#C4B5FD`
9. **วัน:** คะแนน = round(เฉลี่ยทุก entry) · สี = entry ล่าสุด
10. **Triggers:** theme ที่ entries_with ≥ 3 และ entries_without ≥ 1 → delta = avg(with) − avg(without) · ≥ +5 lifts · ≤ −5 drains · เรียงตาม |delta|

**ผลที่ต้องได้ (unit test):**
- เดโมน้ำหวาน 7 ต.ค. ครั้งแรก → 7 คำ, Σv = −4, Σe = −1 → **score 25, energy 4, low, 🌧️ ฝนพรำ**, themes = work, body, commute, pet
- เช็กใจอีกรอบ → ดีขึ้น/สบายใจ/ขอบคุณ → **score 75, energy 5, calm, ⛅** (delta +50)
- 15 entries (24 ก.ย.–7 ต.ค.) → triggers: work −21.0 · exercise +16.7 · sleep −12.2 · pet +9.0 · body +3.8 · family −1.7

## 9) Safety (สำคัญที่สุด — ทำก่อนอย่างอื่น)

- `lib/safety.ts` ตรวจ `safety_terms_th` (อยากตาย / ไม่อยากอยู่แล้ว / ฆ่าตัวตาย / ทำร้ายตัวเอง / จบชีวิต) **ก่อน** วิเคราะห์อารมณ์
- เจอ → `risk_level = urgent` → **ไม่คำนวณคะแนน ไม่แสดงอากาศใจ ไม่ให้แชร์** → เปิด Support Sheet: ข้อความอบอุ่น + ปุ่มโทร **1323** (สายด่วนสุขภาพจิต กรมสุขภาพจิต) + **1669** (เจ็บป่วยฉุกเฉิน) + ปุ่ม "ส่งข้อความหาคนที่ไว้ใจ" (เปิดแอปแชทเอง ไม่ส่งอัตโนมัติ)
- โหมด LLM: runtime prompt M4 ตรวจซ้ำได้ แต่ lexicon ฝั่งเครื่องตัดสินขั้นต่ำเสมอ (LLM ลด risk ไม่ได้ เพิ่มได้อย่างเดียว)
- เวลาถ่ายคลิป **ห้าม** โชว์ Support Sheet เป็นมุกหรือ demo แบบตลก
- ตรวจเบอร์ทั้งหมดอีกครั้งก่อนเผยแพร่ (`verify_before_launch: true`)

## 10) หน้าจอ

1. **Home / Record** — "วันนี้ใจคุณสีอะไร?" ลูกแก้วกลางจอเรืองแสงช้าๆ + ปุ่มไมค์ใหญ่ + ป้ายความเป็นส่วนตัว + "ลองข้อมูลตัวอย่าง (น้ำหวาน)"
2. **Listening** — วงคลื่นรอบลูกแก้ว + คำ interim ลอย + ตัวนับ 0:28 (สูงสุด 90 วิ)
3. **Result / Aura** — ลูกแก้วสีใจ + score นับขึ้น + อากาศใจ + label + chip ธีม + สรุป + "ดูว่าคำไหนทำให้เป็นสีนี้"
4. **Comfort** — การ์ด 3 ชั้น + ปุ่ม tiny action
5. **Breathe** — ลูกแก้วพอง/ยุบ + ข้อความ หายใจเข้า/ค้าง/ผ่อน + สั่น
6. **Re-check** — พูด 10 วิ → แผงก่อน/หลัง
7. **Mood Garden** — ปฏิทินเดือน + สตรีค
8. **Patterns** — Triggers + (Wrapped)
9. **Share** — พรีวิวการ์ด + สวิตช์ แสดงข้อความ / คะแนน / ธีม
10. **Support Sheet** (safety) · **Settings** (ภาษา, STT, AI key, เก็บเสียง, PIN, เตือน, ลบข้อมูลทั้งหมด)
