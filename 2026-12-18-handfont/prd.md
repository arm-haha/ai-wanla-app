# PRD — HandFont (เขียนลายมือแผ่นเดียว ได้ฟอนต์ของตัวเอง)

## ปัญหา
อยากเขียนการ์ดวันเกิด ส.ค.ส. โน้ตขอบคุณลูกค้า หรือแคปชันสตอรี่ "ด้วยลายมือตัวเอง" แต่เขียนทีละใบไม่ไหว ลายมือในมือถือก็ไม่มี ฟอนต์ลายมือสำเร็จรูปก็ซ้ำกับคนทั้งประเทศ ร้านออนไลน์อยากใส่โน้ตลายมือ 100 กล่องต่อวันก็มือหงิก ครูอยากทำใบงานเป็นลายมือครูเอง พ่อแม่อยากให้ลูกฝึกคัดลายมือแต่ไม่มีแบบฝึกที่วัดผลได้ และเครื่องมือทำฟอนต์ที่มีอยู่ภาษาอังกฤษล้วน วางสระ-วรรณยุกต์ไทยลอยมั่ว

## ผู้ใช้
นักเรียน/นักศึกษาสายจดโน้ต-ทำสตอรี่, แม่ค้าออนไลน์ที่ใส่การ์ดขอบคุณในกล่อง, ครูทำใบงาน/การ์ด, คู่รักที่อยากส่งข้อความลายมือ, ผู้ปกครองที่ให้ลูกฝึกคัดลายมือ, ผู้สูงอายุที่อยากเก็บ "ลายมือยาย/ลายมือพ่อ" ไว้ให้หลาน (โดยเจ้าของลายมือยินยอมเอง)

## Must-have (core demo / Reel)
1. **Sheet → Font** ⭐ wow moment — ดาวน์โหลดแบบฟอร์ม A4 (`template_sheet`: ไทยด่วน 72 ช่อง 1 แผ่น / ไทยครบ / อังกฤษ / ไทย+อังกฤษ 161 ช่อง) → เขียนด้วยปากกา → ถ่ายรูป 1 รูป → AI หามุมกระดาษ ตัดทีละช่อง (`AiGlyphExtract`) → vectorize เป็นเส้นโค้ง → ได้ไฟล์ **TTF/OTF/WOFF2** ชื่อ `HandFont-<ชื่อ>` (`font_build`) + ช่องพิมพ์ทดลอง "พิมพ์อะไรก็เป็นลายมือเรา" ทันที
2. **Scan & Glyph QA** — คะแนนรูป 0–100 (แสง เบลอ เอียง ความเข้มหมึก) พร้อมทิป (`scan_quality`); ตรวจทีละช่อง ok / ว่าง / จาง / ล้นกรอบ / เลอะ (`glyph_check`); สรุป % ครบ และสร้างได้เมื่อตัวหลัก ≥ 90% (`coverage`) — ถ่ายซ่อม "เฉพาะช่องที่พัง" ไม่ต้องเขียนใหม่ทั้งแผ่น
3. **Thai Mark Engine** — จุดขายที่แอปฝรั่งไม่มี: แยก cluster พยัญชนะ+สระบน/ล่าง+วรรณยุกต์ (`clusters`) แล้ววางตามกฎตัวพิมพ์ไทย (`mark_placement`): วรรณยุกต์ชิดต่ำเมื่อไม่มีสระบน ลอยสูงเมื่อมี (ที่ / ปี่), หลบหางตัวสูง ป ฝ ฟ ฬ, เลื่อนสระล่างพ้นหาง ฎ ฏ, ตัดเชิง ญ ฐ เมื่อมีสระล่าง
4. **Style Tuner + Natural Alternates** — น้ำหนัก บาง/ปกติ/หนา, เอียง ±15°, ความดิบ clean/natural/sketchy, ระยะห่างตัวอักษร, baseline jitter (`style_params`); ตัวเดียวกันสลับ 3 แบบอัตโนมัติไม่ให้ดูก๊อปวาง (`pick_alternates`)
5. **Card & Note Maker** — การ์ด 7 แบบ (วันเกิด / ขอบคุณ / โน้ตบอกรัก / อวยพรงานแต่ง / ส.ค.ส. / วันครู / โน้ตขอบคุณลูกค้า) เลือกกระดาษ 6 แบบ หมึก 6 สี ปรับขนาดตัวอักษรอัตโนมัติ เตือนข้อความยาวเกิน (`card_layout`, `text_preview`) → PDF พร้อมพิมพ์ / PNG ส่ง LINE
6. **Consent & Safety Guard** — ใช้ได้เฉพาะลายมือตัวเอง, ตรวจพบลายเซ็น → ไม่ทำ, ห้ามใช้ปลอมเอกสาร/ใบลา/ใบรับรอง, เด็กต่ำกว่า 13 ต้องมีผู้ปกครองยืนยัน, เบลอข้อมูลส่วนตัวบนแผ่น (`consent_check`, `safety_guard`)

## Nice-to-have (retention / viral)
7. **Sticker & Story Text** — พิมพ์ข้อความ → PNG พื้นใสลายมือเรา ใส่ IG Story / TikTok / LINE (`sticker_export`)
8. **Handwriting Practice (คัดลายมือ)** — สร้างแบบฝึก trace/copy/free เส้นไกด์ 4 เส้นสำหรับไทย (`practice_sheet`) + ถ่ายผลฝึกให้คะแนนความสม่ำเสมอ (ขนาด / ฐานบรรทัด / ช่องไฟ / ความเอียง) เกรด A–D และทิปจุดที่ควรแก้ (`practice_score`)
9. **Font Diary & Versions** — ฟอนต์ v1 → v2 หลังฝึก, สตรีคการฝึก, คะแนนดีขึ้นกี่แต้ม, นับการ์ด/สติกเกอร์ที่ทำ (`diary_summary`)
10. **Share Card / Reel Maker + Quota** — การ์ดก่อน/หลัง, กริดตัวอักษร, โน้ตที่พิมพ์ 1080×1350 (`share_card`) + Reel 9:16 15–30 วิ 6 ช็อต (`reel_plan`); ฟรีสร้างฟอนต์ 2 ครั้ง/วัน (`quota`)

## หน้าจอ / Flow
Home → Consent (ยืนยันว่าเป็นลายมือตัวเอง + อายุ) → เลือกแบบฟอร์ม → พิมพ์/เขียนบน iPad → ถ่ายรูปแผ่น (ไกด์ 4 มุม) → Scan QA (ช่องแดง = ซ่อม) → Style Tuner → **Type Test** (wow) → Export (TTF/OTF/WOFF2) → Card Maker / Sticker → Practice → Diary → Share / Reel

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**ครูมิ้นท์ 27 ปี นนทบุรี** แบบฟอร์ม "ไทยด่วน" 72 ช่อง ถ่ายรูปคุณภาพ 94/100
- Glyph QA: 69/72 ใช้ได้ (96%) ขาด ฃ (ว่าง) · ฬ (ล้นกรอบ) · ๆ (จาง) → ตัวหลัก 96% **สร้างได้** ใช้ตัวสำรองชั่วคราว
- Style: ปกติ เอียง 4° natural tracking +10 → **HandFont-Mint.ttf** 69 ตัว + 138 alternates ≈ 256 KB
- Thai Mark: "ปี่" → สระ ี และ ่ หลบหาง ป (dx −12) วรรณยุกต์ลอยเหนือสระ (dy +18)
- การ์ดวันครู: "สุขสันต์วันครูนะคะ ขอบคุณที่ตั้งใจสอนทุกวัน" 43/140 ตัวอักษร กระดาษมีเส้น หมึกปากกาน้ำเงิน 28pt 2 บรรทัด
- ฝึกคัดลายมือ 3 วันติด: 72 → 78 → 83 (เกรด B, จุดที่ควรแก้: ช่องไฟ) → สร้างฟอนต์ v2

## Design tokens
กระดาษครีม #FAF7EE, หมึกน้ำเงินปากกา #1C2E78, ชมพูพาสเทล #FDE7EC, ทองไฮไลต์ #FFC440, กราฟิตเข้ม #12101E, เส้นไกด์ #AABED7, เตือน #E5484D; ฟอนต์ UI Kanit / ตัวอย่างลายมือเป็นฟอนต์ของผู้ใช้เอง; มุมมน 24; กริดช่องอักษร 4 คอลัมน์; แอนิเมชันประกายสแกนวิ่งทีละช่อง; คีย์บอร์ดพรีวิวที่ปุ่มเป็นลายมือผู้ใช้

## Reel shot list (20 วิ · มือผู้สร้างคลิปเอง ไม่ต้องเห็นหน้า)
- **0–3 วิ:** กระดาษเปล่า + ปากกา ข้อความ "ลายมือเรา เป็นฟอนต์ได้ไหม?"
- **3–7 วิ:** ตัดต่อเร่งตอนสร้างแอปด้วย AI จากแพ็กนี้ + มือเขียน ก–ฮ สปีด x8
- **7–10 วิ:** ถ่ายรูปแผ่น ประกายสแกนวิ่งทีละช่อง "69/72 ✓"
- **10–15 วิ:** พิมพ์ในมือถือ "สุขสันต์วันเกิดนะแก" → ออกมาเป็นลายมือตัวเองเป๊ะ (จังหวะ beat drop)
- **15–18 วิ:** การ์ดวันเกิดพิมพ์ออกมา + สติกเกอร์ลายมือแปะ IG Story
- **18–20 วิ:** CTA "คอมเมนต์ FONT รับแพ็กฟรี"
- ตัวอักษรเล็กท้ายคลิป: "ใช้ได้เฉพาะลายมือตัวเอง · ไม่ใช่ลายเซ็น · ห้ามใช้ปลอมเอกสาร"

## Build plan (ประมาณ 1 วันด้วย AI codegen)
1. **ชม. 0–1:** P0 scaffold PWA + tokens + port `handfont.py` เป็น TS ให้ `tests.py` ผ่านทุกข้อ (37 tests)
2. **ชม. 1–2:** P1–P2 Consent + Template PDF generator (QR มุมกระดาษ 4 จุดช่วยหามุม)
3. **ชม. 2–4:** P3–P4 กล้อง + perspective warp + ตัดช่อง + A1 ตรวจช่อง/ลายเซ็น + Glyph QA
4. **ชม. 4–5:** P5–P6 vectorize (potrace/WASM) → opentype.js สร้าง TTF/OTF/WOFF2 + Thai mark anchors (GPOS mark/mkmk)
5. **ชม. 5–6:** P7–P9 Style tuner, Type Test, Card & Sticker
6. **ชม. 6–7:** P10–P12 Practice, Diary, Share/Reel, Quota/Guard, QA บนมือถือจริง + ถ่าย Reel ตาม shot list

## Risks & mitigations
| ความเสี่ยง | ผลกระทบ | วิธีลด |
|---|---|---|
| ใช้ปลอมลายมือคนอื่น/ลายเซ็น/เอกสาร | ผิดกฎหมาย ฉ้อโกง | Consent ทุกครั้ง, A1 ตรวจ `signature_like` → stop, ไม่มีช่องลายเซ็นในแบบฟอร์ม, guard `document_forgery`, ลายน้ำ metadata "HandFont personal" ในไฟล์ฟอนต์ |
| สระ/วรรณยุกต์ไทยลอยหรือซ้อนทับ | ฟอนต์ใช้ไม่ได้จริง ดราม่าในคอมเมนต์ | Thai Mark Engine + GPOS anchors, ทดสอบคำยาก (ที่ ปี่ ฟื้น ฎุ ญู กึ๋) ทุก build |
| รูปถ่ายเอียง/มืด/เงามือ | ตัดช่องผิด ตัวแหว่ง | scan_quality + ไกด์ 4 มุม + ซ่อมเฉพาะช่อง |
| ไฟล์ฟอนต์ติดตั้งไม่ได้บาง OS | ผู้ใช้ผิดหวัง | export ทั้ง TTF/OTF/WOFF2 + คู่มือติดตั้ง iOS (โปรไฟล์)/Android/Windows/Mac/Canva |
| ข้อมูลส่วนตัวบนแผ่น (ชื่อ เบอร์ ที่อยู่) | ความเป็นส่วนตัว | เบลอก่อนส่ง AI, ลบรูปต้นฉบับหลังประมวลผล ≤ 1 ชม., เก็บแค่ glyph vectors |
| เด็กใช้งาน | ความปลอดภัย | ต่ำกว่า 13 ต้องผู้ปกครองยืนยัน, โหมดฝึกคัดลายมือไม่ต้องอัปโหลดรูปหน้า |

## Guardrails
- ใช้ได้เฉพาะลายมือของผู้ใช้เอง (หรือของผู้ที่ยินยอมและอยู่ด้วยตอนสร้าง) — ห้ามทำจากลายมือคนดัง/คนอื่น
- ไม่ทำฟอนต์/สติกเกอร์จากลายเซ็น และฟอนต์นี้ไม่ใช่ลายเซ็นอิเล็กทรอนิกส์
- ห้ามใช้ปลอมเอกสาร ใบลา ใบรับรอง หรือเขียนแทนผู้อื่น
- ผลคะแนนคัดลายมือเป็นเกมฝึกความสม่ำเสมอ ไม่ใช่การวิเคราะห์นิสัยจากลายมือ (ไม่มี graphology)
- ทุกตัวอย่างในแพ็กเป็นบุคคลสมมติ

## Metrics
- % ผู้ใช้ที่ถ่ายแผ่นแล้วได้ฟอนต์ใน ≤ 2 ครั้ง (เป้า 70%)
- เวลาจากเปิดแอปถึงพิมพ์ทดลองครั้งแรก (เป้า < 15 นาทีรวมเวลาเขียน)
- การ์ด/สติกเกอร์ต่อผู้ใช้ใน 7 วัน (เป้า ≥ 3)
- D7 retention จากโหมดฝึกคัดลายมือ (เป้า 25%)
- จำนวน share card / Reel ที่ติดลายน้ำ HandFont
