# PRD — GlamTry (เซลฟี่เดียว ลองแต่งหน้าก่อนซื้อ)

## ปัญหา
อยากลองแต่งหน้าลุคใหม่ (เกาหลีผิวฉ่ำ ปาร์ตี้ เจ้าสาว) แต่ไม่รู้ว่าเข้ากับหน้าตัวเองไหม ดูคลิปรีวิวก็เป็นหน้าคนอื่น สีผิวคนอื่น ซื้อลิป/รองพื้นมาผิดเฉดเสียเงินฟรีซ้ำ ๆ ไม่รู้ว่าอันเดอร์โทนตัวเองอุ่นหรือเย็น ไม่รู้ต้องใช้ของอะไรบ้าง ต้องจ่ายเท่าไหร่ถึงจะได้ลุคนั้น มีงานแต่งเพื่อนอาทิตย์หน้าก็ไม่รู้ต้องเตรียมอะไร และลองของใหม่วันงานแล้วแพ้

## ผู้ใช้
นักศึกษา/First jobber ที่เพิ่งเริ่มแต่งหน้า, สาวออฟฟิศที่อยากได้ลุคเร็ว ๆ 15 นาที, ว่าที่เจ้าสาวที่อยากเห็นลุคก่อนคุยช่างแต่งหน้า, คนไปคอนเสิร์ต/ปาร์ตี้ที่อยากลองลุคจัดเต็ม, สายช้อปที่อยากรู้ว่าต้องซื้ออะไรก่อนกดตะกร้า

## Must-have (core demo / Reel)
1. **Look Try-On** ⭐ wow moment — เซลฟี่หน้าสด 1 รูป → AI อ่านใบหน้า (`AiFaceExtract`) → ได้ภาพจำลอง **6 ลุคพร้อมกัน** (เนเชอรัลหน้าสด / เกาหลีผิวฉ่ำ / เจ้าสาวไทย / ปาร์ตี้จัดเต็ม / สาวออฟฟิศ / Y2K) บนหน้าตัวเอง (`six_looks`, `look_spec`) ปัดซ้าย-ขวาเปลี่ยนลุค สไลเดอร์ ก่อน/หลัง ปรับความเข้ม ซอฟต์ / กลาง / จัดเต็ม; คงรูปหน้า สีผิว เนื้อผิวเดิม 100%
2. **Shade Match** — วัดสีจากแก้ม (cheek patch) → ระดับสีผิว 5 ระดับ × อันเดอร์โทน 4 แบบ (เย็น/กลาง/อุ่น/มะกอก) → โค้ดเฉด เช่น **2W** + สีลิป 3 สีที่เข้ากัน + ความมั่นใจตามคุณภาพแสง ติดป้าย "ค่าประมาณ" เสมอ (`shade_match`); ปรับสีลิป/บลัชทุกลุคตามอันเดอร์โทนอัตโนมัติ (`look_palette`)
3. **Step-by-Step Tutorial** — การ์ดสอนแต่งทีละขั้นของลุคที่เลือก: ลำดับ, บริเวณ, ประเภทเครื่องสำอาง, สี HEX ที่ต้องหา, เคล็ดลับ, เวลาโดยประมาณ; มือใหม่ (skill 1) ได้เวอร์ชันง่ายตัดขนตาปลอม/อายไลเนอร์/กลิตเตอร์ (`tutorial`)
4. **Budget Kit & Dupe Finder** — ชุดของที่ต้องใช้ 3 ระดับราคา (ประหยัด / กลาง / ไฮเอนด์) ช่วงราคาประมาณเป็นบาท ติ๊ก "มีแล้ว" ไม่ต้องซื้อซ้ำ แสดงว่าประหยัดกว่าเซ็ตไฮเอนด์เท่าไหร่ + เคล็ดลับหาของแทน (เทียบ HEX/เนื้อสัมผัส) — **เป็นประเภทสินค้าทั่วไป ไม่อ้างแบรนด์** (`budget_kit`)
5. **Consent Guard** — ก่อนประมวลผลทุกครั้ง: ต้องเป็นเซลฟี่ตัวเอง, อายุ 13+ (ต่ำกว่าบล็อก), ไม่ใช่รูปดารา/ไม่แต่งให้เหมือนใคร, หน้าเดียว, ไม่ขอทำผิวขาว/ดัดหน้า (`consent_check`)
6. **Occasion Planner** — เลือกงาน (ทำงาน / สัมภาษณ์ / เดต / งานแต่งเพื่อน / งานแต่งตัวเอง / ปาร์ตี้ / คอนเสิร์ต / รับปริญญา) + วันที่ → ลุคแนะนำ, ชุดเติมหน้า (สเปรย์ล็อก/กระดาษซับมัน/ลิปเติม) ตามอากาศร้อนชื้นและชั่วโมงที่ต้องอยู่, ไทม์ไลน์ ลองแต่ง 7 วันก่อน · patch test 2 วันก่อน · เริ่มแต่งกี่นาทีก่อนออก (`occasion_plan`)

## Nice-to-have (retention / viral)
7. **Patch-Test Helper** — ของใหม่ทุกชิ้นได้ขั้นตอน patch test ทั่วไป (24–48 ชม.), ของรอบดวงตาเตือนเพิ่ม, ใส่สิ่งที่เคยแพ้ให้เช็กฉลาก (`patch_test`) + ข้อความ "ไม่ใช่คำแนะนำทางการแพทย์"
8. **Makeup Diary** — บันทึก ลอง/ใส่จริง/ซื้อ/เปิดใช้/รูป → ลุคที่ลอง ลุคโปรด ค่าใช้จ่ายรวม และวันควรเปลี่ยนของหลังเปิด (มาสคาร่าประมาณ 3 เดือน ฯลฯ ค่าประมาณทั่วไป) (`diary_summary`)
9. **Share Card / Reel Maker** — การ์ด ก่อน/หลัง หรือกริด 6 ลุค 1080×1350 / 1080×1920 + คลิป 9:16 15–30 วิ 5 ช็อต (before → scan → swipe 6 ลุค → compare + ชุดของ → CTA) ลายน้ำ (`share_card`, `reel_plan`)
10. **Quota + Safety Guard** — ฟรี 3 เซลฟี่/วัน (เซลฟี่ละ 6 ลุค); guard: รูปคนอื่น/ดารา/อายุต่ำกว่า 13/ไม่พบหน้า/ขอทำผิวขาว (stop), หลายหน้า/เปิดฟิลเตอร์ (warn) (`quota`, `safety_guard`)

## หน้าจอ / Flow
Home → Consent (ยืนยันหน้าตัวเอง + อายุ) → ถ่ายเซลฟี่ (ไกด์แสงหน้าต่าง ปิดฟิลเตอร์ หน้าตรง) → Shade Match → กริด 6 ลุค → Look Detail (สไลเดอร์ ก่อน/หลัง + ความเข้ม) → Tutorial → Budget Kit → Occasion Planner → Share / Reel → Makeup Diary

## Risks & mitigations
| ความเสี่ยง | ผลกระทบ | วิธีลด |
|---|---|---|
| image-edit เปลี่ยนหน้า/ทำผิวขาว/หน้าเรียว | ผิดจริยธรรม คนไม่เชื่อ | prompt บังคับ "keep identity, skin tone… no whitening, no slimming", ใช้ mask เฉพาะปาก/แก้ม/เปลือกตา, ทดสอบเทียบค่าสีผิวก่อน-หลังต้องไม่สว่างขึ้นเกินเกณฑ์ |
| เฉดผิวจากรูปคลาด (แสง/กล้อง/ฟิลเตอร์) | ซื้อรองพื้นผิดเฉด | light check + filter warn, ความมั่นใจต่ำบอกตรง ๆ, ป้าย "ค่าประมาณ", แนะนำทาเทสต์ที่กรอบหน้า |
| ใช้รูปคนอื่น/ดารา/เด็ก | ความเป็นส่วนตัว ภาพปลอม | Consent Guard, ตรวจ celebrity_like → stop, อายุต่ำกว่า 13 บล็อก, ลบรูปหลังประมวลผล |
| อ้างแบรนด์/ราคาผิด | ปัญหาทางการค้า | ใช้ "ประเภทสินค้า" + ช่วงราคาประมาณเท่านั้น ไม่มีชื่อแบรนด์/ลิงก์ร้าน |
| ผู้ใช้แพ้เครื่องสำอาง | อันตรายต่อผิว | Patch-Test Helper, ไทม์ไลน์ 2 วันก่อนงาน, ข้อความไม่ใช่คำแนะนำทางการแพทย์ |
| ประเด็นสีผิว (colorism) | ดราม่า | ไม่มีโหมดผิวขาว, guard `whitening_request` stop, ข้อความ "ทุกสีผิวสวยในแบบของตัวเอง", ตัวอย่างครบ 5 ระดับสีผิว |
| ต้นทุน image-edit 6 ภาพ/เซลฟี่ | ค่าใช้จ่ายบาน | โควตา 3 เซลฟี่/วัน, พรีวิวสวอตช์ offline ก่อน, แคชตาม (รูป, ลุค, ความเข้ม) |

## Guardrails
- **Consent Guard:** ใช้ได้เฉพาะเซลฟี่ของตัวเอง; อายุต่ำกว่า 13 ปีบล็อก; ไม่รองรับรูปดารา/คนดังหรือ "แต่งให้เหมือน…"; เจอหลายหน้าให้ครอปเหลือคนเดียว
- **ไม่ทำผิวขาว ไม่ดัด/เรียวหน้า ไม่เปลี่ยนเชื้อชาติ** — แต่งหน้าเท่านั้น คงสีผิวและรูปหน้าเดิม
- **ภาพจำลอง/ค่าประมาณ:** ทุกหน้าผลแสดง disclaimer; เฉดผิวและราคาติดป้าย "ค่าประมาณ"; ไม่อ้างแบรนด์ ไม่รับรองผลิตภัณฑ์
- **แพ้/patch test:** ข้อมูลทั่วไป ไม่ใช่คำแนะนำทางการแพทย์ แนะนำทดสอบ 24–48 ชม. ก่อนใช้ของใหม่ ถ้าแพ้หยุดใช้และปรึกษาแพทย์/เภสัชกร
- รูปเซลฟี่ลบหลังประมวลผล (≤ 1 ชม.) ไม่เอาไปเทรน; ภาพที่แชร์มีลายน้ำ "ภาพจำลอง"
- ตัวอย่างและภาพปกเป็นบุคคลสมมติ/ภาพวาด

## Metrics
D1 ดู ≥ 4 ลุค/คน, เปิด Shade Match ≥ 60%, เปิด Tutorial ≥ 35%, เปิด Budget Kit ≥ 30%, สร้าง Reel/แชร์การ์ด ≥ 12%, ใช้ Occasion Planner ≥ 10%, กลับมาลองลุคใหม่ใน 30 วัน ≥ 20%
