# PRD — ScamScan (มิจฉาสแกน)

**ช่อง:** AI วันละแอป · **วันที่:** 2026-10-16 · **สถานะ:** พร้อม gen วันนี้
**ฮุค Reel:** แม่ส่ง SMS "บัญชีถูกระงับ" มาถาม… วางปุ๊บ มิเตอร์แดง 90/100 พร้อมชี้ว่าหลอกตรงไหน 🚨

---

## 1) ปัญหา
- SMS / LINE / สายโทรหลอกมาทุกวัน: "บัญชีถูกระงับ", "พัสดุค้างส่ง", "คืนภาษี", "ตำรวจโทรมา"
- พ่อแม่ผู้สูงอายุแยกไม่ออก ต้องส่งมาถามลูกทีละข้อความ ลูกก็ไม่ว่างตอบทันที
- ข้อมูลเตือนภัยมีเยอะ แต่ไม่มีอะไรที่ "วางข้อความแล้วบอกเลย" แบบภาษาบ้าน ๆ

## 2) ทำไมไวรัล
- ทุกบ้านเคยเจอ → ดูแล้วนึกถึงพ่อแม่ทันที = **แชร์ให้ครอบครัว** (ไวรัลแบบ "ส่งต่อให้คนที่รัก")
- Before/after ชัดมาก: ข้อความดูจริง → มิเตอร์วิ่งแดง + คำหลอกถูกไฮไลต์ทีละคำ
- Link X-Ray ทำให้คนดู "เห็น" ความปลอม (kbank-verify-th.top vs kasikornbank.com) = save ไว้ดูซ้ำ
- ต่อยอดคอนเทนต์ได้ไม่จบ: "ส่ง SMS หลอกที่คุณเจอมา เดี๋ยวสแกนให้ดู" + เกม "จริงหรือหลอก?"

## 3) เป้าหมาย / ตัวชี้วัด
| เป้า | วัดจาก |
|---|---|
| เข้าใจใน 15 วิ | เห็น วางข้อความ → มิเตอร์แดง ภายใน 14 วิแรก |
| ใช้ได้ทันที ไม่ต้องสมัคร | demo กดครั้งเดียวได้คะแนนตรง `expect_locked` (90/85/55/0) |
| เปิดซ้ำ | Quiz วันละ 5 ข้อ + streak · History · Wrapped รายเดือน |
| แชร์ | Family Card PNG 1080×1350 + ข้อความส่ง LINE |

## 4) Persona (สมมติ)
- **ป้าแดง 62 ปี** ใช้ LINE ทุกวัน ได้ SMS ธนาคารปลอมบ่อย ตัวหนังสือเล็กอ่านยาก
- **มิ้นท์ (ลูกสาว) 30 ปี** คนลงแอปให้แม่ ตั้งตัวหนังสือใหญ่ + อ่านออกเสียง แล้วรับ Family Card เวลามีของน่าสงสัย

## 5) ฟีเจอร์
### Must-have (คอร์เดโม — 5 ข้อ)
1. **Paste → Scam Meter** (⭐ wow moment): วาง/แชร์ข้อความ (หรือแคปหน้าจอ → OCR) → มิเตอร์ครึ่งวงกลมวิ่ง 0→คะแนน สีเขียว→แดง ไซเรนกระพริบเมื่อ ≥75 ระดับ: low 0–24 · caution 25–49 · risky 50–74 · scam 75–100
2. **Red-Flag Highlighter**: ไฮไลต์คำอันตรายในข้อความทีละจุด (เร่งรีบ / ขอ OTP / ให้โอน / ดีเกินจริง / อ้างเจ้าหน้าที่ / ให้แอดไลน์-ลงแอป) แตะแต่ละจุดเห็นคำอธิบายภาษาบ้าน ๆ
3. **Link X-Ray**: แตกลิงก์เป็นชิ้น (scheme · host · โดเมนหลัก · นามสกุล) เทียบ allowlist เว็บทางการ → "ปลอมตัวเป็นกสิกรไทย — เว็บจริงคือ kasikornbank.com" จับลิงก์ย่อ, .top/.xyz, http, xn--, IP **ไม่เปิดลิงก์จริงเด็ดขาด** (วิเคราะห์จากตัวอักษรเท่านั้น)
4. **ทำแบบนี้เลย (Action Card)**: ขั้นตอนตามระดับ + คำตอบปลอดภัยคัดลอกได้ + ปุ่มโทรเบอร์ทางการ (ให้ผู้ใช้หาเอง/เบอร์หลังบัตร) + ช่องแจ้ง AOC 1441 เมื่อเผลอกด/โอนแล้ว
5. **Family Alert Card → LINE**: การ์ดเตือนสีเข้มอ่านง่าย "แม่ ระวังข้อความนี้นะ" + ข้อความสั้นส่ง LINE ได้ทันที (หรือแม่ส่งถามลูก)

### Nice-to-have (รีเทนชัน)
6. **จริงหรือหลอก? Quiz**: ปัดซ้าย/ขวา วันละ 5 ข้อจาก deck (seeded) + streak + badge
7. **Call Shield**: กำลังคุยสายอยู่ → ติ๊กสิ่งที่ได้ยิน (อ้างตำรวจ, ห้ามวางสาย, ให้โอนไปตรวจสอบ…) → คะแนน + ประโยคพูดตัดบท
8. **History + Shield Wrapped**: ประวัติการสแกน + สรุปเดือน "เช็ก 8 ข้อความ เจอเสี่ยง 6 · แบรนด์ที่โดนปลอมบ่อยสุด"
9. **Grandparent Mode**: ตัวหนังสือใหญ่ 1.3× + อ่านออกเสียง (Web Speech th-TH) + ปุ่มใหญ่
10. **AI อธิบายเพิ่ม (optional)**: สรุป 1–3 บรรทัดสำหรับผู้สูงอายุ — **ห้ามเปลี่ยนคะแนน**

## 6) กติกาคอร์ (deterministic — ดู `reference/scam.py`)
- คะแนน = ผลรวมน้ำหนัก rule ที่เจอ (นับครั้งเดียวต่อ rule) + **combo +10** ถ้ามีลิงก์คู่กับ (ขอรหัส หรือ ขอเงิน) · cap 100
- น้ำหนัก: brand_mismatch 25 · credential 20 · off_platform 20 · urgency/money/too_good/authority/punycode/ip_link 15 · link/shortener/bad_tld 10 · no_https 5
- brand_mismatch: ข้อความ/ผู้ส่ง/host อ้างแบรนด์ แต่โดเมนหลักไม่อยู่ใน `official` ของแบรนด์นั้น (ยกเว้นลิงก์ย่อ → verdict hidden)
- โดเมนหลัก: 2 ส่วนท้าย ยกเว้น `*.co.th / or.th / go.th / in.th / ac.th / net.th / mi.th` ใช้ 3 ส่วน
- highlight ไม่ทับกัน และ `text[start:end] == highlight.text` เสมอ
- AI (OCR / explain) เป็นตัวเสริม ไม่มี key แอปยังทำงาน 100% (วางข้อความ + demo)

## 8) หน้าจอ
1. **Home** — ช่องวางข้อความใหญ่ + ปุ่มแคปหน้าจอ + "ลองกล่องข้อความป้าแดง" + Quiz วันนี้
2. **Scanning** — เส้นสแกนวิ่งผ่านข้อความ 1.2 วิ
3. **Result** — มิเตอร์ → ข้อความที่ไฮไลต์ → รายการ flag → Link X-Ray → Action Card → ปุ่ม Family Card
4. **Link X-Ray (เต็มจอ)** — URL แตกเป็นบล็อกสี เทียบเว็บจริง
5. **Family Card** — preview PNG + ปุ่มส่ง LINE / บันทึกรูป
6. **Quiz** — การ์ดปัด 5 ใบ + ผล + streak
7. **Call Shield** — checklist ใหญ่ + คะแนนสด + ประโยคตัดบท
8. **History / Wrapped** — รายการ + การ์ดสรุปเดือน
9. **Settings** — ตัวหนังสือใหญ่ · อ่านออกเสียง · ครอบครัว · allowlist แบรนด์ (แก้ได้) · ลบข้อมูลทั้งหมด

## 11) ความปลอดภัย / ความเป็นส่วนตัว
- **ไม่เปิด / ไม่ fetch ลิงก์ในข้อความ** (กันโดน tracking/ดาวน์โหลดมัลแวร์) — วิเคราะห์จากตัวอักษรเท่านั้น
- ข้อความเก็บในเครื่องเท่านั้น ส่ง AI เฉพาะเมื่อเปิด `ai_explain` และตัดเลขบัญชี/เบอร์โทรเป็น `***` ก่อนส่ง
- ทุกหน้าผลมี disclaimer: เป็นสัญญาณเตือน ไม่ใช่คำตัดสิน
- ไม่ฝังเบอร์โทรธนาคารในแอป (กันข้อมูลผิด/ล้าสมัย) → ให้ "ดูเบอร์หลังบัตร/ในแอปทางการ"
- allowlist โดเมน + เบอร์ AOC 1441 ต้องตรวจกับเว็บทางการก่อนปล่อย (`verified:false` ใน examples)

## 13) ความเสี่ยง
- **False negative** (หลอกแต่ได้คะแนนต่ำ) → คนเชื่อว่าปลอดภัย: ระดับ low ใช้คำว่า "ยังไม่เจอสัญญาณอันตราย" ไม่ใช่ "ปลอดภัย"
- **False positive** กับข้อความจริง (เช่น แต้มหมดอายุ) → ไฮไลต์ได้ แต่คะแนนต่ำ ไม่ขู่เกินเหตุ
- มิจฉาเปลี่ยนมุกเร็ว → rules เป็น JSON อัปเดตได้, Quiz deck เติมจากคอมเมนต์คนดู
- เนื้อหา Reel: อย่าใช้โลโก้ธนาคารจริง ใช้ชื่อเป็นตัวหนังสือ + บอกว่าเป็นข้อความตัวอย่าง
