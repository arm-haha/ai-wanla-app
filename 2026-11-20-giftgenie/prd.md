# PRD — GiftGenie (คิดของขวัญไม่ออก ตอบ 5 ข้อได้ไอเดียตามงบ)

## ปัญหา
ใกล้วันเกิดแฟน เพื่อนขึ้นบ้านใหม่ หรือต้องขอบคุณหัวหน้า แล้วยืนเลือกของในห้างจนหมดเวลา ของที่คิดได้มักแพงกว่างบ หรือไม่เข้ากับคนรับ และยังต้องเขียนการ์ดกับห่อของในคืนเดียวกัน

## ผู้ใช้
คนอายุ 20–45 ที่ต้องซื้อของขวัญบ่อยแต่คิดไม่ออก, คู่รัก, เพื่อนร่วมงาน, พี่เลี้ยงหลาน, คนที่ตั้งงบชัดเป็นบาทและไม่อยากเดาของเกินงบ

## Must-have (core demo / Reel)
1. **Persona Quiz** ⭐ wow moment — ตอบ 5 ข้อ (ความสัมพันธ์ ช่วงอายุ โทน ความชอบ โอกาส) + งบ → คะแนนความเหมาะ 0–100
2. **Budget Picks** — ไอเดีย 5 ชิ้นในงบ เรียงคะแนน แสดงช่วงราคา ฿ และเหตุผลสั้น ๆ
3. **Card Message Writer** — ข้อความการ์ด 4 โทน (หวาน ขำ สุภาพ สั้น) ตามโอกาส
4. **Occasion Calendar** — บันทึกวันเกิด/ขึ้นบ้านใหม่/ครบรอบ เตือนสถานะ ok / soon / due
5. **Wrap Ideas** — ไอเดียห่อของตามช่วงงบ (ต่ำกว่า ฿500 / ถึง ฿1,500 / ถึง ฿3,000 / สูงกว่า)

## Nice-to-have (retention)
6. **Already-has Swap** — กด "มีอยู่แล้ว" แล้วได้ตัวทดแทนในงบเดียวกัน
7. **Last-minute filter** — กรองของที่ไม่ต้องสั่งล่วงหน้าในคลังตัวอย่าง (ของใช้ทั่วไป)
8. **Experience vs thing** — สลับไปของที่เป็นประสบการณ์ เช่น บัตรคาเฟ่
9. **Share Card + Quota** — การ์ดไอเดียมีลายน้ำ ฟรี 3 ครั้ง/วัน
10. **Safety Guard** — บล็อกของสำหรับผู้ใหญ่เมื่อผู้รับเป็นเด็ก ไม่โชว์ว่าเป็นคูปองจริง

## หน้าจอ / Flow
Home (ควิซ 5 ข้อ + งบ) → กำลังคิดคะแนน → **รายการไอเดียเรียงคะแนน** → เลือกชิ้น → ข้อความการ์ด → ไอเดียห่อของ → บันทึกวันในปฏิทิน → แชร์การ์ด / สลับของที่มีแล้ว

## Demo fixture (ข้อมูลสมมติเท่านั้น)
**พี่บิ๋ม 31 ปี** กรุงเทพฯ ซื้อของวันเกิดให้แฟนชื่อต้น อายุช่วง 25–34 โทนสบาย ชอบคาเฟ่กับเสื้อโอเวอร์ไซส์ งบ **฿1,500**. ผล: 1) เสื้อโอเวอร์ไซส์ FictoSoft ฿890 คะแนน **100** 2) ชุดชงชา FictoTea ฿750 / 100 3) บัตรคาเฟ่ FictoBean 2 ที่ ฿650 / 90 4) กล่องกาแฟดริป ฿550 / 90 5) หนังสือภาพคาเฟ่ ฿420 / 90. ข้อความโทนหวาน: "สุขสันต์วันเกิดนะ ขอให้ปีนี้มีวันที่สบายใจมากกว่าเดิม". ห่องบกลาง: กล่องคราฟท์ + ดอกไม้แห้ง + การ์ดเขียนมือ. ปฏิทิน: วันเกิดต้น 8 ธ.ค. 2026 อีก 18 วัน (soon) และวันเกิดแม่ 25 พ.ย. อีก 5 วัน (due)

## Design tokens
พื้นชมพูอุ่น #3B1D2A, ครีม #F8EFE6, ชมพูของขวัญ #E85A71, ทองป้าย #E0B25E, เขียวพอดี #2A9D8F, หมึก #2B1A1F; ฟอนต์ Kanit; มุมมน 20; การ์ดของขวัญถ่ายขึ้น Reels ชัด ตัดก่อน/หลัง (คนคิดไม่ออก → ไอเดียในงบ)

## Guardrails
- **ไม่ใช่ร้านค้า** — ห้ามอ้างว่ามีของขายหรือมีคูปองจริง ราคาเป็นช่วงประมาณ
- **เด็ก** — ช่วงอายุ 0–12 และ 13–17 ไม่เสนอของ `adult_only` (เช่น ชุดไวน์) และมีคำเตือนเรื่องของมีคม/ของเล็ก
- ไม่แนะนำของผิดกฎหมาย ยา หรืออุปกรณ์ทางการแพทย์
- ข้อความการ์ดโทนไว้ทุกข์ต้องสุภาพ ไม่ล้อเลียน
- ตัวอย่างและภาพปกเป็นบุคคล/สินค้าสมมติ ภาพวาด ไม่ใช้รูปคนจริง

## Shot list Reel (30 วิ)
- **0–3 วิ:** คนยืนในห้าง มองของแล้วถอย ขึ้นข้อความ "คิดของขวัญไม่ออกอีกแล้ว?"
- **3–10 วิ:** ตัดต่อเร่งตอนใช้ AI สร้างแอป / ตอบควิซ 5 ข้อแป๊บเดียว
- **10–22 วิ:**
  1. ใส่งบ ฿1,500 แล้วไอเดียเด้ง เสื้อโอเวอร์ไซส์คะแนน 100
  2. เลื่อนดูบัตรคาเฟ่และชุดชงชาในงบเดียวกัน
  3. กดโทนหวาน ได้ข้อความการ์ดทันที
  4. เลือกไอเดียห่อ กล่องคราฟท์ + ดอกไม้แห้ง
  5. ปฏิทินเด้งเตือนวันเกิดในอีก 18 วัน
- **22–30 วิ:** "คอมเมนต์ GIFT รับแพ็กฟรี"
- ใช้ตัวละครและสินค้าสมมติเท่านั้น ไม่ใช้คนจริง แบรนด์จริง หรือราคาโปรจริง
