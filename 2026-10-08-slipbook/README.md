## วิธีใช้กับ AI codegen (เช้านี้)

1. เปิด `prompts.md` ส่วน **A) Master prompt** วางเป็นคำสั่งหลัก
2. แนบบริบท: `prd.md` + `schemas.json` + `examples.json` + `reference/slip.py`
3. สั่งให้ happy path ด้วยข้อมูลตัวอย่างจบก่อน (18 สลิป → 17/1/2 → ฿6,584.50 → แพรวาคือใคร → ฿563/วัน → ฿10,776/ปี → Wrapped → แชร์)
4. ส่วน **D** ทำ `lib/parse.ts` + เทสต์ให้ผ่านก่อน UI (หัวใจคลิป) · ส่วน **E** ทำเลขทั้งหมด
5. ค่อยต่อ OCR จริง (ส่วน **F**) แล้วลองสลิปตัวเอง 3 ธนาคาร · ก่อนถ่ายรันส่วน **K (QA)**

เป้าเวลา: ราว 7 ชม. (ตารางใน `prd.md` §21)

## สแต็กแนะนำ (สรุป)

- Next.js 14 App Router + TypeScript + Tailwind + shadcn/ui + framer-motion · PWA · Vercel
- OCR ในเครื่อง: `tesseract.js` `tha+eng` ใน Web Worker · `lib/parse.ts` regex ไทย (ไม่มี key ก็ใช้ได้จริง)
