## 1) สรุปหนึ่งบรรทัด

โยนสลิปโอนเงินจากแกลเลอรี่เข้าแอปทีเดียว 18 ใบ → 3 วินาทีกลายเป็นบัญชีรายจ่าย แยกหมวดให้เอง ข้ามสลิปซ้ำให้เอง บอกว่าเงินไหลไปไหน เหลือใช้ได้วันละเท่าไหร่ อะไรตัดเงินทุกเดือน แล้วสรุปเป็น Wrapped ไว้แชร์

**ฮุค Reel:** สลิปเต็มเครื่องแต่ไม่รู้เงินหายไปไหน? โยนเข้าแอปนี้ 3 วิ… รู้หมดเลย 😳

## 2) ปัญหา

- คนไทยจ่ายผ่านพร้อมเพย์/สแกนจ่ายแทบทุกอย่าง แล้วแอปธนาคารเซฟสลิปลงแกลเลอรี่อัตโนมัติ → แกลเลอรี่เต็มไปด้วยสลิปหลายร้อยใบ
- แอปรายรับรายจ่ายทั่วไปต้องพิมพ์ทีละรายการ → ใช้ได้ 3 วันเลิก
- มีหลายบัญชีหลายธนาคาร ดูรวมไม่ได้ ปลายเดือนเลยงงว่าเงินหายไปไหน
- สมาชิกรายเดือนเล็กๆ ตัดเงินเงียบๆ จนลืม

## 3) ทำไมไวรัลบน Reels

- **ภาพที่ทุกคนเจอเอง:** เลื่อนแกลเลอรี่ที่มีแต่สลิป คนดูรู้สึกว่า "นี่มันเราเลย" ใน 2 วินาทีแรก
- **ก่อน/หลังชัดมาก:** กองสลิปรกๆ → โดนัทหมวดหมู่สวยๆ + ตัวเลขเดียวว่า "ใช้ได้อีกวันละ ฿563"
- **ตัวเลขช็อก:** "ตัดทุกเดือน ปีละ ฿10,776" และ "กาแฟเดือนนี้ = ข้าวมันไก่ 8 จาน" คนชอบแคปไปแท็กเพื่อน
- **เซฟไว้ทำตาม:** เรื่องเงินคือหมวดที่คนกดเซฟเยอะ และแอปนี้ใช้ได้ทันทีกับสลิปที่มีอยู่แล้ว ไม่ต้องเริ่มจดใหม่
- **Wrapped การ์ด** = ผู้ใช้แชร์ต่อเอง (ซ่อนตัวเลขได้) เป็นโฆษณาฟรีให้ช่อง

## 4) เป้าหมาย / ไม่ใช่เป้าหมาย

**เป้าหมาย**
- เดโมจบใน 30 วิ: เลือกสลิป → บัญชี → แดชบอร์ด → งบ → Wrapped
- อ่านสลิปไทยได้หลายรูปแบบ (วันที่ไทย/อังกฤษ/ทับ, พ.ศ./ค.ศ., มีคอมมาหลักพัน) แบบไม่ต้องมี API key
- ข้อมูลอยู่ในเครื่อง ไม่เก็บรูปสลิป ปิดเลขบัญชีอัตโนมัติ

**ไม่ใช่เป้าหมาย (v1)**
- ไม่เชื่อมบัญชีธนาคาร ไม่ดึงรายการจากธนาคาร
- **ไม่ตรวจว่าสลิปจริงหรือปลอม** (ห้ามโฆษณาแบบนั้น)
- ไม่ใช่แอปทำภาษี/บัญชีบริษัท ไม่ใช่คำแนะนำการลงทุน
- ไม่มีบัญชีผู้ใช้/คลาวด์ซิงก์

## 5) ผู้ใช้หลัก

- **วัยทำงานต้นๆ (22–32)** สแกนจ่ายทุกวัน อยากรู้ว่าเงินเดือนหายไปไหน (ตัวละครเดโม: "ต้นกล้า" — สมมติ)
- **นักศึกษา** ได้เงินรายเดือน อยากคุมงบให้ถึงสิ้นเดือน
- **คนที่หารบิลกับเพื่อนบ่อย** อยากรู้ว่าโอนเพื่อนไปเท่าไหร่ / ใครคืนแล้ว

## 6) User stories

1. ฉันเลือกสลิปหลายใบจากแกลเลอรี่ครั้งเดียว แล้วได้รายการบัญชีครบโดยไม่ต้องพิมพ์
2. ถ้าฉันเผลอเลือกสลิปเดิมซ้ำ แอปต้องไม่นับซ้ำ
3. ร้านที่รู้จัก (เซเว่น, Grab, Shopee) ต้องถูกจัดหมวดเอง ส่วนชื่อคนแอปถามฉันครั้งเดียวแล้วจำ
4. ฉันอยากเห็นว่าเดือนนี้เงินไปหมวดไหนกี่เปอร์เซ็นต์ และวันไหนใช้หนัก
5. ฉันตั้งงบแต่ละหมวด แล้วอยากรู้ว่าวันนี้ยังใช้ได้อีกเท่าไหร่
6. ฉันอยากรู้ว่ามีอะไรตัดเงินทุกเดือน รวมแล้วปีละเท่าไหร่
7. สิ้นเดือนฉันอยากได้สรุปสนุกๆ ไว้แชร์ โดยซ่อนตัวเลขได้

## 8) กติกาอ่านสลิป (`lib/parse.ts` — pure, deterministic)

ต้นฉบับอ้างอิง: `reference/slip.py` → `parse_slip()` ผลต้องตรงกับ `examples.json → parsed_slips` ทุกช่อง

1. **จำนวนเงิน** ลองตามลำดับ: `(จำนวนเงิน|จำนวน|ยอดเงิน|Amount):? (฿|THB)? 1,234.56` → `฿ 1,234.56` → `1,234.56 (บาท|THB)` · ตัดคอมมา · ต้องมีทศนิยม 2 ตำแหน่ง
2. **วันที่** ลองตามลำดับ: ไทยย่อ `1 ต.ค. 69` → อังกฤษ `01 Oct 2026` → ทับ `01/10/2569` · ปี 2 หลัก: ≥ 50 = พ.ศ. 25xx, < 50 = ค.ศ. 20xx · ปี > 2400 ลบ 543
3. **เวลา** `HH:MM(:SS)? น.?` ตัวแรกในข้อความ
4. **เลขอ้างอิง** หลัง `รหัสอ้างอิง|เลขที่รายการ|หมายเลขอ้างอิง|Ref No.|Transaction ID` ตัวอักษร/ตัวเลข 8–30 ตัว
5. **ทิศทาง** เงินเข้าเมื่อ: ข้อความมี `รับเงิน|เงินเข้า|ได้รับเงิน|Received` **หรือ** บรรทัด "ไปยัง/ถึง/ผู้รับ" มีชื่อเจ้าของ (`settings.owner_names`) → คู่รายการ = บรรทัด "จาก"
6. **คู่รายการ** บรรทัดหลัง `ไปยัง|ถึง|ผู้รับ|To` (หรือ `จาก|From` ถ้าเงินเข้า) · ตัดส่วนเลขบัญชี `xxx-x-x1234-x` ไปเก็บใน `counterparty_account_masked`
7. **ธนาคาร** จากคำใบ้ (K PLUS/SCB/Krungthai/…) — ใช้แสดงไอคอนตัวอักษรเท่านั้น ห้ามใช้โลโก้จริง
8. **ความมั่นใจ** = amount .35 + date .20 + time .10 + ref .20 + counterparty .15 · < 0.85 → `needs_review` (`missing_fields`)
9. **กันซ้ำ** `ref:<เลขอ้างอิง>` ถ้ามี ไม่งั้น `fp:<date>|<time>|<amount 2 ตำแหน่ง>|<ชื่อ normalize>` · เจอซ้ำในชุดเดียวกันหรือในบัญชีเดิม → `duplicate` ไม่เพิ่ม
10. **ไม่เดา:** อ่านไม่ได้ให้เป็น `null` แล้วถาม ห้ามเติมตัวเลขเอง · โหมด AI (ถ้ามี key) ใช้ได้เฉพาะสลิปที่ `confidence < 0.85` และผลต้องผ่าน schema `AiParseResponse`

## 9) กติกาจัดหมวด + เงิน (`lib/categorize.ts`, `lib/money.ts`)

- **ลำดับ:** เงินเข้า → `income` · memory (ชื่อ normalize = ตัวเล็ก ช่องว่างเดียว) → กฎคีย์เวิร์ดตามลำดับ (ตัวแรกที่ match ชนะ, `grab food` ต้องมาก่อน `grab`) → ชื่อคน → `friends` confidence 0.5 + ถาม → อื่นๆ 0.3
- confidence หมวด < 0.6 → ชิป `who_is_this`
- **แดชบอร์ด:** เฉพาะ `direction=out` ของเดือน · % = ยอดหมวด ÷ ยอดรวม × 100 ปัด 1 ตำแหน่ง · เรียงยอดมาก → น้อย
- **ความร้อนรายวัน:** r = ยอดวัน ÷ ยอดวันสูงสุดของเดือน · ≤ .25 → 1 · ≤ .5 → 2 · ≤ .75 → 3 · มากกว่า → 4 · ไม่มี → 0
- **โหล:** percent = round(ใช้ ÷ งบ × 100) (round = floor(x + 0.5)) · เกินงบ → over · ≥ 80 → warn · ไม่งั้น ok
- **ใช้ได้อีกวันละ** = round((งบรวม − ใช้รวม) ÷ (วันในเดือน − วันนี้ + 1)) · ติดลบ → 0 + ข้อความ "เกินงบรวมแล้ว ฿x"
- **ตัดทุกเดือน:** ตามข้อ Nice-to-have ด้านบน · yearly = ยอด × 12

**ผลที่ต้องได้ (unit test — ตรงกับ `test_vectors`):**
- โยน 18 สลิป → **เพิ่ม 17 · ข้ามซ้ำ 1 (s09 = s08) · รอเช็ก 2 (s07 ชื่อคน, s14 ไม่มีเลขอ้างอิง)** · เงินออก ฿6,584.50 · เงินเข้า ฿150
- ต.ค. (1–8): ใช้ **฿6,584.50 / 16 รายการ** · ครอบครัว 45.6% · บิล 19.5% · ของกิน 8.5%
- งบรวม ฿20,100 เหลือ ฿13,515.50 ÷ 24 วัน → **ใช้ได้อีกวันละ ฿563** · โหลครอบครัว 100% (warn)
- ตัดทุกเดือน: มือถือรายเดือน ฿599 (฿7,188/ปี) · MOVIEMAX ฿299 (฿3,588/ปี) → **รวม ฿10,776/ปี**
- Wrapped ก.ย.: **฿10,533 จาก 31 สลิป** · Café Amazon 8 ครั้ง ฿520 ≈ ข้าวมันไก่ 8 จาน · วันหนักสุด 8 ก.ย. ฿3,050 · ไม่จ่ายเลย 4 วัน

## 10) ความเป็นส่วนตัว + ความปลอดภัย (ทำก่อน UI)

- อ่านสลิปในเครื่องเป็นค่าเริ่ม · **ไม่เก็บรูป** (`keep_images: false`) — เก็บแค่ข้อมูลที่แยกแล้ว
- ปิดเลขบัญชีเสมอ ห้ามบันทึกเลขเต็ม (schema `MaskedAccount`)
- โหมด AI ส่งเฉพาะข้อความ OCR ที่ปิดเลขบัญชีแล้วไป `/api/ai` ฝั่ง server · ต้องเปิดเองใน Settings และมีป้ายบอก
- การ์ดแชร์ไม่มีชื่อคน ไม่มีเลขอ้างอิง ไม่มีเลขบัญชี
- Disclaimer ใต้แดชบอร์ด + Settings: "ช่วยจดรายจ่ายจากสลิป ไม่ได้ตรวจสอบว่าสลิปจริงหรือปลอม และไม่เชื่อมบัญชีธนาคาร"
- ปุ่ม "ลบข้อมูลทั้งหมด" ยืนยัน 2 ชั้น

## 11) หน้าจอ

1. **Home / Drop** — "สลิปเต็มแกลเลอรี่?" กองสลิปลอยเบาๆ + ปุ่มใหญ่ "เลือกสลิปจากแกลเลอรี่" + ลากวาง + ป้ายความเป็นส่วนตัว + "ลองข้อมูลตัวอย่าง (ต้นกล้า)"
2. **Importing** — สลิปบินเข้ากองทีละใบ + "กำลังอ่าน 12/18" + ตัวนับยอดวิ่ง
3. **Import Result** — "เพิ่ม 17 · ข้ามสลิปซ้ำ 1 · รอเช็ก 2" + รายการ (ชิปซ้ำสีเทา, ชิปรอเช็กสีเหลือง)
4. **Review Sheet** — แก้ยอด/วัน/ผู้รับ/หมวด + "จำไว้"
5. **Dashboard** (แท็บหลัก) — ยอดรวม + โดนัท + ปฏิทินความร้อน + ท็อปผู้รับ + เงินเข้า
6. **Ledger** — รายการทั้งหมดจัดกลุ่มตามวัน + ค้นหา/กรองหมวด
7. **Budget** — โหลแก้ว 11 หมวด + "ใช้ได้อีกวันละ" + ตั้งงบ
8. **Recurring** — ตัดเงินทุกเดือน + ยอดต่อปี
9. **Wrapped** — สไลด์ 6 หน้า แตะซ้าย/ขวา
10. **Share** — พรีวิวการ์ด + สวิตช์ซ่อนตัวเลข
11. **Settings** — ชื่อเจ้าของบัญชี (ใช้แยกเงินเข้า), OCR/AI, เก็บรูป, PIN, เตือน, ส่งออก CSV, ลบทั้งหมด

## 12) Core flows

- **Happy path (คลิป):** Home → เลือก 18 สลิป (หรือโหลดเดโม) → Importing 3 วิ → Result 17/1/2 → แตะ "แพรวา ส. คือใคร?" → เพื่อน + จำไว้ → Dashboard ฿6,584.50 → Budget ฿563/วัน → Recurring ฿10,776/ปี → Wrapped ก.ย. → Share
- **OCR อ่านไม่ออก/ไม่ใช่สลิป:** แถว `failed` "รูปนี้ไม่เหมือนสลิป" + ปุ่ม เพิ่มเอง / ข้าม (ไม่ใช่ error เต็มจอ)
- **สลิปซ้ำกับของเดิมในบัญชี:** ชิป "มีแล้วตั้งแต่ 4 ต.ค." ไม่เพิ่ม
- **ไม่ได้ตั้งชื่อเจ้าของ:** ถามครั้งแรกก่อน import ("ชื่อคุณบนสลิปคือ?") — ใช้แยกเงินเข้า
- **เดือนว่าง:** "ยังไม่มีสลิปเดือนนี้ — ลองโยนเข้ามาสัก 3 ใบ"

## 14) Tech

- Next.js 14 App Router + TypeScript + Tailwind + shadcn/ui + framer-motion · PWA · Vercel · ไม่มี auth/DB
- OCR: `tesseract.js` v5 ภาษา `tha+eng` ใน Web Worker (preload ตอนเปิดแอป) · ย่อรูปด้านยาว 1600px + grayscale ก่อน OCR
- `lib/parse.ts` / `lib/categorize.ts` / `lib/money.ts` / `lib/recurring.ts` / `lib/wrapped.ts` = pure + vitest (เทียบ `examples.json`)
- AI (ทางเลือก): `/api/ai/parse` + `/api/ai/wrapped` ฝั่ง server env `AI_API_KEY` — ไม่มี key แอปยังใช้ได้ครบ
- ข้อมูล: IndexedDB (`idb`) stores `txns`, `imports` · localStorage `slipbook:v1` (settings/budgets/memory)
- การ์ด: `html-to-image` → PNG + `navigator.share({files})` + fallback ดาวน์โหลด

## 18) ความเสี่ยง / กับดัก

| ความเสี่ยง | ทางแก้ |
|---|---|
| OCR ไทยพลาด (ตัวเลข 8↔3, ฟอนต์ธนาคารต่างกัน) | ย่อ+grayscale ก่อน OCR · regex ยืดหยุ่น · confidence < 0.85 ถาม · โหมด AI เฉพาะสลิปที่ไม่ชัด · เดโมใช้ fixture ให้ผลนิ่ง |
