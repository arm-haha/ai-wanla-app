**ช่อง:** AI วันละแอป
**สถานะ:** พร้อม gen วันนี้

มินิสวีทเรซูเม่สำหรับคนไทย: เทโน้ตมั่วๆ (พิมพ์ / พูด / ถ่ายรูปเรซูเม่เก่า) → ได้เรซูเม่ A4 หน้าเดียวสวยพร้อมส่ง → ปัดเปลี่ยน 6 เทมเพลต → วางประกาศงาน → คะแนนเข้ากันพุ่ง **63 → 87** → แตะ ✨ ให้ประโยคธรรมดากลายเป็นประโยคที่มีผลงาน → ส่งออก PDF + การ์ดก่อน/หลัง

## วิธีใช้กับ AI codegen (เช้านี้)

1. เปิด `prompts.md` ส่วน **A) Master prompt** วางเป็นคำสั่งหลัก
2. แนบบริบท: `prd.md` + `schemas.json` + `examples.json`
3. สั่งให้ `npm run dev` ผ่านและ **happy path ด้วยข้อมูลตัวอย่างจบก่อน** (มายด์ → ปัดเทมเพลต → วางประกาศ → 63 → ปรับ → 87 → ✨ → PDF → แชร์)
4. ส่วน **D** ทำ `lib/score.ts` + เทสต์ 63/87 (หัวใจคลิป) · ส่วน **E** ทำกันแต่งเรื่อง
5. ค่อยต่อ LLM / OCR / เสียงจริง (ส่วน **H** + **M**) · ก่อนถ่ายรันส่วน **K (QA)**

เป้าเวลา: ราว 7.5 ชม. (ตารางใน `prd.md` §20)

## กฎช่อง (อย่าพลาดตอนถ่าย)

- เปิดคลิปด้วย **โน้ตมั่วใน LINE + เรซูเม่กระดาษยับ** ภายใน 3 วินาที
- โชว์อย่างน้อย **4 ฟีเจอร์** (Brain Dump, Template Flip, Job Match 63 → 87, Glow-up) + PDF แวบเดียว
- ใช้ **ข้อมูลตัวอย่างมายด์ + ประกาศ Kinjai** (ตัวละคร/บริษัทสมมติ) เท่านั้น ห้ามโชว์เรซูเม่คนจริง
- พูดว่า "ตรงงานขึ้น" / "HR อ่านง่ายขึ้น" ห้ามพูด "ผ่าน ATS แน่นอน" หรือ "ได้งานชัวร์"
- โชว์ให้เห็นว่าแอป **ถามก่อน** ไม่เติม Meta Business Suite เอง = ความน่าเชื่อถือ
- CTA: คอมเมนต์คำว่า **「เรซูเม่」**

## สแต็กแนะนำ (สรุป)

- Next.js 14 App Router + TypeScript + Tailwind + shadcn/ui + framer-motion
- `lib/score.ts` pure + เทสต์ · `lib/grounding.ts` กันแต่งเรื่อง · `lib/fit.ts` auto-fit หน้าเดียว
- LLM ผ่าน `/api/ai` (env `AI_API_KEY`) ไม่มี key = โหมดตัวอย่าง · OCR Tesseract.js สำรอง · Web Speech `th-TH`
- PDF ผ่าน print CSS (ฟอนต์ไทยถูกสุด) · การ์ดแชร์ html-to-image · ข้อมูลใน localStorage/IndexedDB
- Deploy: Vercel (PWA)
- สี: พื้น `#F5F8FF` · ฟ้า `#2563EB` · หมึก `#0F172A` · ไฮไลต์ `#FDE047` · เขียว `#22C55E` · ส้ม `#F97316`
