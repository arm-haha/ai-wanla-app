# PRD — MenuMate (อ่านเมนูไม่ออก)

**Hook:** "ถ่ายเมนูญี่ปุ่น 1 รูป → กลายเป็นเมนูไทยพร้อมราคาบาท แล้วสั่งได้เลยโดยไม่ต้องพูดสักคำ"

## ปัญหา
คนไทยเที่ยวญี่ปุ่น/เกาหลี/จีน/ไต้หวันเยอะมาก แต่เมนูร้านท้องถิ่นอ่านไม่ออก รูปไม่มี กลัวสั่งผิด กลัวแพ้อาหาร กลัวเกินงบ และกลัวโดนบิลงง Google Lens แปลได้ก็จริง แต่แปลตรงตัว ไม่บอกว่าอันไหนเด็ด อันไหนมีหมู อันไหนเผ็ด และไม่ช่วยสั่ง

## ผู้ใช้
- สายเที่ยวญี่ปุ่น/เกาหลีครั้งแรก (18–40)
- คนแพ้อาหาร / ไม่ทานหมู-เนื้อ / ฮาลาล / มังสวิรัติ
- แก๊งเพื่อนที่ต้องหารบิล

## Must-have (ตัวที่ถ่าย Reel)
1. **Menu Snap → Thai Menu** (WOW) — ถ่ายเมนู แล้ว AI แปลงทุกบรรทัดเป็นการ์ดไทย: ชื่อไทย คำอธิบายสั้น อีโมจิ ราคาเดิม + ราคาบาท ป้าย "เด็ด"
2. **Safe-to-Eat Flags** — ตั้งค่าแพ้อาหาร/ศาสนา/ระดับเผ็ดครั้งเดียว แล้วทุกเมนูขึ้นป้าย เขียว/เหลือง/แดง พร้อมเหตุผล อันไหน AI อ่านไม่ชัดขึ้นเหลือง "ถามพนักงานก่อน"
3. **Budget Order Builder** — ใส่งบ + จำนวนคน → แอปจัดชุดให้ (main ครบทุกคน แล้วเติม side/drink) แสดงเงินเหลือ
4. **Point-to-Order Card** — การ์ดเต็มจอเป็นภาษาท้องถิ่น (ใช้ชื่อเมนูต้นฉบับจากรูป ไม่ใช่คำแปลย้อน) + โน้ตแพ้อาหาร ยื่นให้พนักงานดูได้เลย
5. **Bill Check + Split** — ถ่ายใบเสร็จ เทียบกับที่สั่ง จับรายการเกิน/ราคาไม่ตรง แล้วหารต่อคนเป็นบาท

## Nice-to-have (ให้กลับมาเปิดซ้ำ)
6. **Allergy Card** ภาษาท้องถิ่น พกไว้ยื่นทุกร้าน
7. **Phrase Pocket** 10 ประโยคในร้านอาหาร พร้อมคำอ่าน + ปุ่มเล่นเสียง (TTS)
8. **Food Diary / Trip Wrapped** — สรุปทริป: กินกี่เมนู หลบของแพ้ได้กี่ครั้ง ใช้ไปกี่บาท → การ์ดแชร์
9. **Rate ตั้งเอง** + ออฟไลน์ cache เมนูที่สแกนแล้ว

## หน้าจอ
Onboarding (ประเทศ + แพ้อะไร + เผ็ดแค่ไหน + rate) → Home (ปุ่มกล้องใหญ่) → Scan Result (รูปเมนูเบลอด้านหลัง การ์ดไทยเลื่อนขึ้นทีละใบ) → Item Detail → Order Builder → Point Card (เต็มจอ ตัวใหญ่) → Bill Check → Split → Wrapped → Settings

## Demo fixture (ข้อมูลตัวอย่าง)
ร้านราเมงสมมติที่โอซาก้า 8 เมนู, เจนแพ้กุ้ง เผ็ดได้ระดับ 1, 2 คน งบ ¥3,000, rate ตัวอย่าง 0.23 ฿/¥
- ราเมงกุ้ง → แดง (แพ้กุ้ง), มิโสะเผ็ด → เหลือง (เผ็ด 2), เส้นเติม → เหลือง (AI อ่านไม่ชัด 0.55)
- Order: ทงคตสึ + โชยุ + เกี๊ยวซ่า + คาราอาเกะ = ¥2,830 ≈ ฿651 เหลือ ¥170, คนละ ¥1,415 ≈ ฿325
- Bill Check: จับ ライス ¥200 ที่ไม่ได้สั่ง
- Wrapped: 3 มื้อ 12 เมนู หลบกุ้ง 3 ครั้ง ¥8,930 ≈ ฿2,054

## ขอบเขต / ไม่ทำ
ไม่สั่งอาหารออนไลน์ ไม่จองร้าน ไม่รีวิวร้าน ไม่การันตีความปลอดภัยด้านแพ้อาหาร

## Success metric (ช่อง)
Reel: save rate > 5%, คอมเมนต์ "ขอลิงก์" · แอป: สแกน ≥ 3 เมนูต่อผู้ใช้ในวันแรก, เปิดซ้ำวันที่ 2 ≥ 30%
