# PRD — WorthIt (คุ้มไหมก่อนกดซื้อ) · AI วันละแอป 2026-10-29

## ปัญหา / Hook
คนไทยไถแอปช้อปตอนดึกแล้วกดซื้อเพราะ "ลดวันนี้วันเดียว" แอปนี้แปลงราคาให้เป็น **ชั่วโมงชีวิตที่ต้องทำงานแลก** ก่อนกดจ่าย
Reel hook: "กระเป๋า ฿3,990 = ทำงาน 28 ชั่วโมง… ยังอยากได้อยู่ไหม?"

## ผู้ใช้
มนุษย์เงินเดือน/ฟรีแลนซ์/นักศึกษา 18–35 ที่ช้อปออนไลน์บ่อย ใส่รายได้ต่อเดือนครั้งเดียว (เก็บในเครื่องเท่านั้น)

## Must-have (core demo)
1. **Snap → Work Hours** (WOW) — ถ่าย/แคปหน้าสินค้า หรือพิมพ์ราคา → AI อ่านชื่อ+ราคา → ตัวเลขราคาหมุนกลายเป็นนาฬิกา "28 ชม. 5 นาที · 3.5 วันทำงาน · 16% ของเงินเดือน"
2. **Cost-per-Use** — สไลด์ "ใช้เดือนละกี่ครั้ง × กี่เดือน" → ราคาต่อครั้ง + สีเขียว/เหลือง/แดง (≤฿20 / ≤฿100 / มากกว่า)
3. **คุ้มไหม Quiz 5 ข้อ** — swipe ใช่/ไม่ → คะแนน 0–100 → ซื้อได้ / รอก่อน / ข้ามไป (คะแนนคิดแบบ deterministic ไม่ให้ AI ตัดสิน)
4. **Cool-off Timer** — ของ ≥฿1,000 หรือ ≥5% เงินเดือน ล็อก 24 ชม., ≥฿10,000 หรือ ≥30% ล็อก 72 ชม. → แจ้งเตือนตอนครบ "ยังอยากได้ไหม?"
5. **Skip Jar (โหลเงินที่ไม่ได้ซื้อ)** — ทุกครั้งที่กด "ไม่ซื้อ" เหรียญหล่นลงโหล วิ่งเข้าเป้าหมาย เช่น "ตั๋วญี่ปุ่น ฿15,000"

## Nice-to-have (retention)
6. **Habit Math** — ของเล็กซื้อซ้ำ (ลาเต้ ฿75 × 5 วัน/สัปดาห์) → ฿1,625/เดือน, ฿19,500/ปี = ทำงาน 137 ชม./ปี
7. **Monthly Report** — ซื้อกี่ชิ้น ข้ามกี่ชิ้น เงิน+ชั่วโมงที่ได้คืน, ชิ้นใหญ่สุดที่ข้าม
8. **Dupe Hunt** — AI ให้ "คำค้น" หาของคล้ายถูกกว่า (ไม่เดาราคา/ไม่อ้างร้าน)
9. **Share Card 9:16** — work_hours / verdict / skip_jar / month_report / cooloff_win

## หน้าจอ
Onboarding (รายได้, วัน/ชม.ทำงาน, เป้าโหล) → Home (ปุ่มกล้องใหญ่ + โหล) → Result (นาฬิกา + CPU + ปุ่ม Quiz) → Quiz (swipe 5 การ์ด) → Verdict (ซื้อ/รอ/ข้าม) → Wishlist + Timers → Jar → Report → Settings

## Flow หลัก
Snap → VisionExtract (confidence < 0.7 → ให้ผู้ใช้ยืนยัน/แก้ราคา) → work_time → cost_per_use → quiz → verdict → (wait → cooloff) / (skip → jar) / (buy → log)

## Demo fixture (ข้อมูลสมมติ)
มายด์ รายได้ ฿25,000, 22 วัน × 8 ชม. → ฿142.05/ชม.
- กระเป๋า ฿3,990 → 28 ชม. 5 นาที, 3.5 วัน, 16% · CPU ฿166.25 แดง · คะแนน 5 → ข้าม · Cool-off 24 ชม.
- รองเท้าวิ่ง ฿2,890 → 20 ชม. 21 นาที · CPU ฿20.07 เหลือง · คะแนน 95 → ซื้อได้
- มือถือ ฿32,900 → 231 ชม. 37 นาที (131.6% ของเดือน) · คะแนน 30 → ข้าม · Cool-off 72 ชม.
- โหล: ข้าม 3 ชิ้น ฿6,870 = 45.8% ของตั๋วญี่ปุ่น, ได้เวลาคืน 48.4 ชม.

## Guardrails
- รายได้เก็บใน localStorage เท่านั้น ไม่ส่งขึ้นเซิร์ฟเวอร์ ไม่ส่งไปให้ AI (AI อ่านแค่รูปสินค้า)
- ไม่ใช่คำแนะนำทางการเงิน ไม่แนะนำลงทุน/สินเชื่อ ไม่ทำ affiliate ในเวอร์ชันแจก
- AI ห้ามเดาราคาที่อ่านไม่ออก → คืน null + needs_confirm
- น้ำเสียงไม่ตัดสินคนซื้อ ("ซื้อได้" ต้องรู้สึกดีด้วย)
